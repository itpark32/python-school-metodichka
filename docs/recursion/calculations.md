Рекурсию не угадывают: строят цепочку или дерево вызовов.
!!! abstract "Фокус"
    - **Нужно уметь:** раскрывать вызовы до базовых значений.
```python
def f(n):
    if n <= 2:
        return n
    return f(n - 1) + f(n - 2)
```
`f(5)=f(4)+f(3)=(f(3)+f(2))+(f(2)+f(1))`. Сначала дорисуйте дерево до базы, затем складывайте снизу вверх. При `print(n)` до вызова числа появляются на спуске, после вызова — на возврате.
## Мини-практика
1. Вычислите `f(5)`. 2. Посчитайте число вызовов. 3. Исследуйте вывод до и после вложенного вызова.
