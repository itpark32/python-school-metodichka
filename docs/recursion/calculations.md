Рекурсию не угадывают: строят цепочку или дерево вызовов.
!!! abstract "Фокус"
    - **Нужно уметь:** раскрывать вызовы до базовых значений.
```python
def f(n):
    if n <= 2:
        return n
    return f(n - 1) + f(n - 2)
```
`f(5)=f(4)+f(3)=(f(3)+f(2))+(f(2)+f(1))`. Сначала дорисуйте дерево до базы, затем складывайте снизу вверх. При `print(n)` до вызова числа появляются на спуске, после вызова — на возврате.

## Цепочка и дерево

Если функция делает один рекурсивный вызов, достаточно цепочки кадров. Два вызова создают дерево: одинаковые значения аргумента могут вычисляться несколько раз. Каждый узел подписывайте аргументом, а листья — значениями базовых случаев.

В выражении `return f(n - 1) + f(n - 2)` сложение откладывается, пока оба вложенных вызова не вернут результаты. Поэтому вычисление идёт в две фазы: раскрытие сверху вниз и сбор ответа снизу вверх.

## Порядок печати

```python
def countdown(n):
    if n == 0:
        print("старт")
        return
    print("вниз", n)
    countdown(n - 1)
    print("вверх", n)
```

До вложенного вызова выводятся `3, 2, 1`, затем база, после вызова — `1, 2, 3`. У каждого незавершённого вызова сохраняется своё значение `n`.

На экзамене сначала вычислите значения базы, затем небольшие значения по возрастанию. Таблица часто компактнее полного дерева, если нужны только результаты.
## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Таблица значений функции

#### Условие

Функция определена так: F(0) = 2; при n > 0 F(n) = F(n - 1) + 3. Введите n от 0 до 20 и выведите F(n). Для n = 3 выпишите таблицу до запуска.

#### Как рассуждать

Для каждого нового значения нужен только предыдущий результат. Таблица начинается с базы: F(0)=2, F(1)=5, F(2)=8, F(3)=11. Рекурсивный код должен повторять именно это определение.

#### Алгоритм

1. Верните 2 для нуля.
2. Иначе вызовите F для предыдущего аргумента и прибавьте 3.
3. Выведите результат для введённого n.

#### Решение

```python
def f(n):
    if n == 0:
        return 2
    return f(n - 1) + 3

n = int(input())
print(f(n))
```

#### Разбор решения

Сложение выполняется после возврата меньшего вызова. Базовое значение 2 не равно количеству вызовов: при n = 3 создаётся четыре вызова с аргументами 3, 2, 1, 0.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3: 2 → 5 → 8 → 11 | обычный случай | 11 |
| 0 | только база | 2 |
| 1 | один шаг над базой | 5 |

**Ответ:** для первого теста — 11.

---

### Задача 2. Печать на спуске и возврате

#### Условие

Введите n от 0 до 5. Функция для положительного n печатает `вниз n`, вызывает себя для n - 1, затем печатает `вверх n`. При n = 0 ничего не печатает. Предскажите весь вывод.

#### Как рассуждать

Каждый вызов приостанавливается в точке рекурсии со своим n. Поэтому спуск идёт от большого к малому, а возврат — от малого к большому. Одинаковые аргументы не перезаписывают друг друга.

#### Алгоритм

1. Проверьте базу.
2. Напечатайте строку спуска.
3. Вызовите меньшую задачу.
4. После возврата напечатайте строку подъёма.

#### Решение

```python
def walk(n):
    if n == 0:
        return
    print("вниз", n)
    walk(n - 1)
    print("вверх", n)

n = int(input())
walk(n)
```

#### Разбор решения

Для n = 2 вызов walk(2) ждёт окончания walk(1). Поэтому «вверх 1» появляется раньше «вверх 2». Число строк равно 2*n: базовый вызов не печатает.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 2 | обычный случай | вниз 2<br>вниз 1<br>вверх 1<br>вверх 2 |
| 1 | одна пара строк | вниз 1<br>вверх 1 |
| 0 | база без печати | нет строк вывода |

**Ответ:** для первого теста — вниз 2; вниз 1; вверх 1; вверх 2.

### Задача 3. Дерево двух вызовов

#### Условие

Задано F(0)=0, F(1)=1, а для n ≥ 2: F(n)=F(n-1)+2*F(n-2). Введите n от 0 до 12 и вычислите F(n). Для n = 4 сначала постройте таблицу значений.

#### Как рассуждать

Ветви дерева зависят от двух предыдущих аргументов. Перед сложением должны завершиться оба вызова. Таблица даёт F(2)=1, F(3)=3, F(4)=5; она помогает проверить дерево без угадывания.

#### Алгоритм

1. Опишите две базы через n < 2.
2. Для остальных аргументов выполните два меньших вызова.
3. Умножьте второй результат на 2, сложите и верните.

#### Решение

```python
def f(n):
    if n < 2:
        return n
    return f(n - 1) + 2 * f(n - 2)

n = int(input())
print(f(n))
```

#### Разбор решения

Коэффициент 2 умножает результат второго вызова, а не его аргумент. Значения некоторых аргументов вычисляются повторно: например, F(2) нужен в обеих ветвях F(4). Ограничение до 12 сохраняет небольшой объём прямой рекурсии; для больших n нужна таблица или запоминание.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 4: 0, 1, 1, 3, 5 | обычный случай | 5 |
| 0 | первая база | 0 |
| 1 | вторая база | 1 |
| 5 | следующий шаг таблицы | 11 |

**Ответ:** для первого теста — 5.
