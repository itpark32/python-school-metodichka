# Основы рекурсии

Рекурсивная функция вызывает себя для более простой версии задачи.
!!! abstract "Фокус"
    - **Нужно знать:** базовый случай, рекурсивный шаг, приближение к остановке.
```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```
Для `4` вызовы идут до `1`, затем ответы собираются: `1 → 2 → 6 → 24`. Без базового случая или уменьшения `n` получится бесконечная рекурсия.
## Мини-практика
1. Рекурсивный отсчёт до нуля. 2. Сумма от 1 до N. 3. Протрассируйте `factorial(5)`.
