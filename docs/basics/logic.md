# Логические выражения

<p class="reading-time">Чтение: 12–15 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag">8 класс</span><span class="tag tag--oge">ОГЭ</span><span class="tag tag--ege">ЕГЭ</span></div>

Логическое выражение отвечает «да» или «нет» и получает значение `True` либо `False`.

В программе такое выражение играет роль вопроса: «число подходит?», «индекс ещё внутри списка?», «пользователь ввёл допустимое значение?». Чем точнее вопрос переведён с русского языка на Python, тем проще условие и меньше случайных ошибок.

!!! abstract "Фокус"
    - **Нужно знать:** сравнения, `and`, `or`, `not`.
    - **Нужно уметь:** переводить условие задачи в выражение.
    - **Полезно знать:** цепочка `10 <= x <= 20` читается как в математике.

## 1. Сравнения и связки

```python
number % 2 == 0 and number > 100
age < 14 or age > 18
not (x > 10)
10 <= x <= 20
```

`and` требует истинности обеих частей. `or` — хотя бы одной. `not` меняет истину на ложь. Скобки делают порядок явным.

| Запись | Смысл |
|---|---|
| `x == 5` | равно |
| `x != 5` | не равно |
| `a <= x <= b` | внутри отрезка |
| `x < a or x > b` | вне отрезка |

## 2. Перевод условия задачи

Не пытайтесь сразу печатать длинную строку кода. Сначала выделите простые утверждения. Например: «число двузначное и делится на 7, но не делится на 5».

1. Двузначное положительное: `10 <= number <= 99`.
2. Делится на 7: `number % 7 == 0`.
3. Не делится на 5: `number % 5 != 0`.

```python
fits = (10 <= number <= 99
        and number % 7 == 0
        and number % 5 != 0)
```

Промежуточная переменная `fits` не обязательна, но делает смысл видимым. Это особенно полезно при отладке длинного фильтра.

Следите за словами «строго», «не менее» и «не более»:

| фраза | Python |
|---|---|
| больше 10 | `x > 10` |
| не меньше 10 | `x >= 10` |
| от 10 до 20 включительно | `10 <= x <= 20` |
| вне отрезка | `x < 10 or x > 20` |

Отрицание всего условия требует скобок. `not (10 <= x <= 20)` также означает, что `x` находится вне отрезка.

## 3. Разбор

Для `number = 112`: условие `number % 2 == 0` истинно и `number > 100` истинно, значит всё выражение с `and` истинно. Для `99` вторая часть ложна — результат `False`.

Проверяйте выражение на заведомо подходящем, неподходящем и пограничном значениях. Для диапазона `[10; 20]` возьмите `15`, `7`, `10` и `20`: границы быстро обнаруживают путаницу между `<` и `<=`.

## 4. Частые ошибки

- `=` вместо `==`;
- путать «оба» (`and`) и «хотя бы один» (`or`);
- писать `x == 3 or 5` вместо `x == 3 or x == 5`;
- отрицать сложное условие без скобок.

## 5. Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Число на отрезке

#### Условие

Введите целое число. Выведите True, если оно лежит от 10 до 20 включительно, иначе False.

#### Как рассуждать

Нужны одновременно нижняя и верхняя границы. Равенство допустимо на обоих концах, поэтому используем `<=`. Результат сравнения уже является логическим значением, отдельный `if` не нужен.

#### Алгоритм

1. Прочитайте число.
2. Запишите двойное сравнение.
3. Выведите логическое значение.

#### Решение

```python
number = int(input())
fits = 10 <= number <= 20
print(fits)
```

#### Разбор решения

Цепочка `10 <= number <= 20` требует выполнения обоих сравнений. Случай 9 не проходит нижнюю границу, а 21 — верхнюю. Числа 10 и 20 должны пройти.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 10 | левая граница | True |
| 20 | правая граница | True |
| 9 | перед отрезком | False |
| 21 | после отрезка | False |

**Ответ:** для первого теста — True.

---

### Задача 2. Ровно одно положительное

#### Условие

Введите два целых числа с разных строк. Выведите True, если ровно одно положительно. Ноль положительным не считается.

#### Как рассуждать

Нужны два разных случая: первое положительное, второе неположительное; либо наоборот. Внутри каждого случая должны совпасть два признака, между случаями достаточно одного.

#### Алгоритм

1. Прочитайте a и b.
2. Составьте два случая с and.
3. Соедините случаи через or и выведите результат.

#### Решение

```python
a = int(input())
b = int(input())
fits = (a > 0 and b <= 0) or (a <= 0 and b > 0)
print(fits)
```

#### Разбор решения

Простой `a > 0 or b > 0` пропустил бы два положительных числа, хотя требуется ровно одно. Скобки показывают два допустимых случая. Проверка `<= 0` включает и отрицательные значения, и ноль.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3; 0 | ноль не положительный | True |
| -2; 5 | второй допустимый случай | True |
| 3; 5 | оба положительны | False |
| 0; -1 | положительных нет | False |

**Ответ:** для первого теста — True.

### Задача 3. Проверка экзаменационного высказывания

#### Условие

Найдите наибольшее целое x, для которого истинно «НЕ (x ≥ 30) И (x кратно 4)». Напишите программу проверки одного введённого кандидата с выводом True или False.

#### Как рассуждать

Отрицание `x ≥ 30` означает строго `x < 30`. Ближайшее меньшее 30 кратное четырём — 28: следующее кратное, 32, уже не подходит. Проверяющая программа должна требовать оба признака сразу.

#### Алгоритм

1. Прочитайте кандидата.
2. Проверьте границу и остаток от деления.
3. Выведите результат; отдельно обоснуйте максимум.

#### Решение

```python
x = int(input())
fits = not (x >= 30) and x % 4 == 0
print(fits)
```

#### Разбор решения

`not` применяется только к сравнению в скобках. `and` не позволяет пройти числу 29 только из-за границы или числу 32 только из-за делимости. Программа проверяет кандидата, а максимальность 28 следует из шага между соседними кратными.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 28 | обычный случай | True |
| 29 | граница подходит, делимость нет | False |
| 30 | исключённая граница | False |
| 32 | делимость подходит, граница нет | False |

**Ответ:** для первого теста — True.
