# `//`, `%` и работа с цифрами

<p class="reading-time">Чтение: 12–15 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag">8 класс</span><span class="tag tag--oge">ОГЭ</span><span class="tag tag--ege">ЕГЭ</span></div>

Целочисленное деление и остаток помогают исследовать делимость и доставать цифры числа.

Представьте число как стопку цифр. Операция `% 10` позволяет посмотреть на последнюю цифру, а `// 10` снимает её со стопки. Из этих двух действий собираются алгоритмы для суммы цифр, проверки записи числа и многих задач ОГЭ и ЕГЭ.

!!! abstract "Фокус"
    - **Нужно знать:** `27 // 10 == 2`, `27 % 10 == 7`.
    - **Нужно уметь:** проверить чётность и извлечь цифры.
    - **Полезно знать:** цикл позволяет обработать число любой длины.

## 1. Цифры справа налево

```python
number = 538
last = number % 10
tens = number // 10 % 10
hundreds = number // 100
```

Остаток от деления на 10 — последняя цифра. `number // 10` удаляет её. Число чётное, если `number % 2 == 0`, и делится на 7, если остаток равен нулю.

### Как устроено извлечение

| выражение | результат для 538 | что узнали |
|---|---:|---|
| `number % 10` | 8 | последняя цифра |
| `number // 10` | 53 | число без последней цифры |
| `number // 10 % 10` | 3 | цифра десятков |
| `number // 100` | 5 | цифра сотен |

Для цифры десятков сначала отбрасываем единицы, затем берём остаток от деления на 10. По той же схеме `number // 1000 % 10` извлечёт цифру тысяч.

Число делится на `d`, если `number % d == 0`. Последняя цифра сразу помогает проверить чётность и кратность 5. Но признак делимости на 3 через одну последнюю цифру проверить нельзя: понадобится сумма всех цифр.

## 2. Число произвольной длины

```python
number = 53842
digit_sum = 0

while number > 0:
    digit_sum += number % 10
    number //= 10

print(digit_sum)
```

На каждом шаге берём последнюю цифру и отбрасываем её. Для числа `0` сумму нужно обработать отдельно только если задача требует считать количество цифр.

| шаг | `number` до шага | цифра | сумма после шага |
|---:|---:|---:|---:|
| 1 | 53842 | 2 | 2 |
| 2 | 5384 | 4 | 6 |
| 3 | 538 | 8 | 14 |
| 4 | 53 | 3 | 17 |
| 5 | 5 | 5 | 22 |

Переменная `number` разрушается. Если исходное значение ещё понадобится, сохраните `copy = number`. Для отрицательного ввода часто удобно начать с `number = abs(number)`. По этому каркасу можно считать количество цифр, искать максимальную цифру или собирать число в обратном порядке.

## 3. Частые ошибки

- писать `number / 10` и получать дробь;
- проверять делимость как `number % d == d`;
- забывать менять `number` внутри `while`;
- терять исходное число: сохраните копию, если оно понадобится после цикла.

## 4. Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Последние две цифры

#### Условие

Введите целое число от 10 до 9999. Выведите отдельно цифру десятков и цифру единиц через пробел.

#### Как рассуждать

Единицы остаются после деления на 10 с остатком. Для десятков сначала уберём единицы целочисленным делением, затем возьмём последнюю цифру полученного числа. Старшие разряды не должны попасть в ответ.

#### Алгоритм

1. Прочитайте число.
2. Вычислите десятки через // 10 и % 10.
3. Вычислите единицы и выведите обе цифры.

#### Решение

```python
number = int(input())
tens = number // 10 % 10
units = number % 10
print(tens, units)
```

#### Разбор решения

`number // 10` может быть многозначным: для 538 это 53. Поэтому дополнительное `% 10` обязательно, если нужна именно цифра. Нулевые десятки и единицы выводятся как обычный ноль.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 538 | обычный случай | 3 8 |
| 100 | нули в обоих разрядах | 0 0 |
| 10 | минимальное число | 1 0 |

**Ответ:** для первого теста — 3 8.

### Задача 2. Цифры трёхзначного числа

#### Условие

Введите целое число от 100 до 999. Найдите сумму его цифр.

#### Как рассуждать

Длина числа известна, поэтому цикл не нужен. Сотни получаем делением на 100, десятки — отбрасыванием единиц и остатком от деления на 10, единицы — остатком исходного числа.

#### Алгоритм

1. Прочитайте трёхзначное число.
2. Выделите три цифры.
3. Сложите цифры и выведите сумму.

#### Решение

```python
number = int(input())
hundreds = number // 100
tens = number // 10 % 10
units = number % 10
print(hundreds + tens + units)
```

#### Разбор решения

Благодаря ограничению до 999 выражение `number // 100` даёт ровно одну цифру. Суммируем цифры, а не части числа: без `% 10` в десятках сумма оказалась бы завышенной.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 538 | обычный случай | 16 |
| 100 | нулевые младшие цифры | 1 |
| 999 | максимальное допустимое число | 27 |

**Ответ:** для первого теста — 16.

### Задача 3. Перестановка разрядов

#### Условие

Введите трёхзначное число. Постройте число с теми же цифрами в обратном порядке и выведите разность исходного и полученного числа. Ведущие нули результата не сохраняются.

#### Как рассуждать

Это подготовка к задачам об алгоритмах преобразования чисел. Нужно не просто поменять порядок вывода цифр, а собрать новое числовое значение: прежние единицы станут сотнями.

#### Алгоритм

1. Выделите сотни, десятки и единицы.
2. Соберите обратное число по разрядным весам.
3. Вычтите его из исходного и выведите разность.

#### Решение

```python
number = int(input())
a = number // 100
b = number // 10 % 10
c = number % 10
reversed_number = 100 * c + 10 * b + a
print(number - reversed_number)
```

#### Разбор решения

Умножение на 100 и 10 задаёт новые разряды. Для 120 обратное число равно 21, поэтому разность 99. Исходное `number` не меняется: оно понадобится при вычитании.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 321 | обычный случай | 198 |
| 120 | обратная запись начинается с нуля | 99 |
| 101 | число не изменилось | 0 |

**Ответ:** для первого теста — 198.
