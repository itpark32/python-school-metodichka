# Условия

Программа не всегда должна выполнять одни и те же команды. Например, положительную температуру и мороз нужно описать по-разному, а скидку следует применять только при выполнении условия. Для такого выбора в Python используется команда `if`.

!!! abstract "Фокус"
    - **Нужно знать:** как работают `if`, `elif`, `else` и отступы.
    - **Нужно уметь:** составить условие, расположить ветви в правильном порядке и выбрать между несколькими `if` и цепочкой `elif`.
    - **Полезно знать:** сложное условие часто можно упростить с помощью логических операторов и проверки границ.

## 1. Как программа принимает решение

После `if` записывают логическое выражение, результатом которого будет `True` или `False`.

```python
temperature = int(input())

if temperature < 0:
    print("На улице мороз")
```

Если пользователь введёт `-7`, выражение `temperature < 0` истинно, поэтому команда с отступом выполнится. При вводе `5` условие ложно, и программа пропустит `print`.

У команды `if` есть три важные части:

1. условие после ключевого слова `if`;
2. двоеточие `:` в конце строки;
3. блок команд с одинаковым отступом.

```python
if temperature < 0:
    print("Наденьте куртку")
    print("Будьте осторожны на льду")

print("Прогноз обработан")
```

Первые две команды принадлежат условию. Последняя стоит без отступа и выполняется всегда.

## 2. Два варианта: `if` и `else`

Если требуется выбрать ровно один из двух вариантов, добавляют `else`.

```python
age = int(input())

if age >= 14:
    print("Можно получить паспорт")
else:
    print("Пока рано получать паспорт")
```

Сначала Python проверяет `age >= 14`. Если условие истинно, выполняется первый блок. В противном случае выполняется блок `else`. Одновременно обе ветви выполниться не могут.

Так можно найти максимум из двух чисел без готовой функции `max`:

```python
a = int(input())
b = int(input())

if a > b:
    maximum = a
else:
    maximum = b

print(maximum)
```

Если числа равны, программа попадёт в `else`, но результат всё равно будет правильным: `a` и `b` имеют одно значение.

## 3. Несколько вариантов: `if`, `elif`, `else`

Для трёх и более взаимоисключающих вариантов используют цепочку `elif`. Python проверяет условия сверху вниз и останавливается на первой подходящей ветви.

```python
temperature = int(input())

if temperature < 0:
    print("мороз")
elif temperature < 15:
    print("прохладно")
elif temperature < 25:
    print("тепло")
else:
    print("жарко")
```

Проследим выполнение для разных значений.

| Температура | `< 0` | `< 15` | `< 25` | Результат |
|---:|:---:|:---:|:---:|---|
| `-4` | да | не проверяется | не проверяется | мороз |
| `10` | нет | да | не проверяется | прохладно |
| `20` | нет | нет | да | тепло |
| `30` | нет | нет | нет | жарко |

В ветви `elif temperature < 15` не требуется дополнительно писать `temperature >= 0`. До неё программа доходит только тогда, когда первая проверка уже оказалась ложной.

Порядок условий важен. Если сначала написать `temperature < 25`, то значения `-4`, `10` и `20` попадут в одну и ту же ветвь. Более узкие границы в такой задаче должны идти раньше широких.

## 4. Независимые проверки или одна цепочка

Несколько отдельных `if` проверяются независимо и могут выполнить несколько блоков.

```python
number = int(input())

if number % 2 == 0:
    print("делится на 2")

if number % 3 == 0:
    print("делится на 3")
```

Для числа `12` появятся обе строки. Это правильно: число одновременно делится на 2 и на 3.

Если заменить второй `if` на `elif`, программа напечатает только первую характеристику. Значит, выбор зависит от смысла задачи:

- отдельные `if` нужны, когда подходят сразу несколько признаков;
- цепочка `if/elif/else` нужна, когда выбирается только один вариант.

## 5. Составные и вложенные условия

Логические операторы позволяют объединить проверки в одной строке.

```python
number = int(input())

if number > 0 and number % 5 == 0:
    print("Положительное число, кратное 5")
```

Иногда вторую проверку удобно делать только после первой. Тогда используют вложенный `if`.

```python
login = input()

if login == "student":
    password = input()
    if password == "python":
        print("Доступ разрешён")
    else:
        print("Неверный пароль")
else:
    print("Неизвестный пользователь")
```

Вложенность помогает показать последовательность решений, но слишком много уровней затрудняет чтение. Если проверки равноправны, выражение с `and` обычно понятнее.

## 6. Типовой алгоритм: размер скидки

Пусть до 1000 рублей скидки нет, от 1000 до 4999 рублей действует скидка 5%, а начиная с 5000 рублей — 10%.

```python
price = int(input())

if price >= 5000:
    discount = 10
elif price >= 1000:
    discount = 5
else:
    discount = 0

final_price = price * (100 - discount) / 100
print(final_price)
```

Проверка начинается с самой большой границы. При цене `6000` программа сразу выбирает скидку 10%. При цене `3000` первая проверка ложна, а вторая истинна. Значения меньше `1000` попадают в `else`.

!!! tip "Проверяйте граничные значения"
    Для этой программы полезно протестировать `999`, `1000`, `4999` и `5000`. Ошибки в условиях чаще всего обнаруживаются именно на границах диапазонов.

## 7. Частые ошибки

### Присваивание вместо сравнения

```python
# Ошибка
if number = 10:
    print("десять")
```

Один знак `=` присваивает значение. Для сравнения нужны два знака: `number == 10`.

### Неправильные отступы

```python
# Ошибка: вторая строка оказалась вне условия
if score >= 60:
    print("зачёт")
print("работа принята")
```

Код синтаксически допустим, но вторая строка выполняется при любом результате. Сначала определите, какие команды должны относиться к ветви, и только потом расставляйте отступы.

### Потерянная граница

Условие `score > 60` не включает значение `60`. Если зачёт начинается с 60 баллов, нужно написать `score >= 60`.

### Неверный порядок `elif`

Сначала проверяйте условие, которое точнее отделяет нужный диапазон. После написания цепочки подберите по одному тесту для каждой ветви и для каждой границы.

## 8. Разбор задач

Разберём три задачи: сначала выберем одну ветвь, затем совместим несколько проверок и перейдём к экзаменационному типу. В каждой задаче сначала составим план, а потом напишем код.

### Задача 1. Возрастная группа

#### Условие

Вводится возраст — целое неотрицательное число лет. В возрасте меньше 7 лет человек относится к дошкольникам, от 7 до 17 лет включительно — к школьникам, с 18 лет — ко взрослым. Выведите одно слово: `дошкольник`, `школьник` или `взрослый`.

#### Как рассуждать

Дано одно число, а получить нужно одну из трёх категорий. Возраст не может одновременно относиться к двум группам, поэтому подойдёт цепочка `if/elif/else`.

Сначала отделим возраст меньше 7. Если первая проверка не подошла, человеку уже как минимум 7 лет. Тогда достаточно проверить, что возраст меньше 18. Всё остальное относится к последней группе.

#### Алгоритм

1. Считываем возраст.
2. Если он меньше 7, выводим `дошкольник`.
3. Иначе, если он меньше 18, выводим `школьник`.
4. Иначе выводим `взрослый`.

#### Решение

```python
age = int(input())

if age < 7:
    print("дошкольник")
elif age < 18:
    print("школьник")
else:
    print("взрослый")
```

#### Разбор решения

`int(input())` превращает введённый текст в целое число. Условие `age < 7` выделяет первую группу. До `elif age < 18` программа доходит только при `age >= 7`, поэтому повторять нижнюю границу не нужно.

Порядок важен: если начать с `age < 18`, дошкольники тоже попадут в эту ветвь и получат неверную категорию. `else` срабатывает, когда обе проверки ложны: возраст не меньше 18.

#### Проверка

| Ввод | Почему проверяем | Результат |
|---:|---|---|
| `6` | перед первой границей | `дошкольник` |
| `7` | первая граница | `школьник` |
| `17` | перед второй границей | `школьник` |
| `18` | вторая граница, обе проверки ложны | `взрослый` |

Сразу после границ, при `8` и `19`, получим `школьник` и `взрослый`. Минимальный допустимый возраст `0` даст `дошкольник`.

**Ответ:** программа выводит ровно одну возрастную группу; например, для `7` — `школьник`.

### Задача 2. Несколько признаков числа

#### Условие

Вводится целое число. Если оно положительное и делится на 2, выведите `положительное, делится на 2`. Если оно положительное и делится на 3, выведите `положительное, делится на 3`. Если подходят оба признака, выведите обе строки в указанном порядке. Если ни один не подходит, выведите `нет подходящих признаков`.

#### Как рассуждать

Дано число, а получить нужно все подходящие сообщения. У каждого признака две части: число должно быть положительным и делиться на нужный делитель без остатка. Здесь нужен `and`.

Признаки могут выполняться одновременно: например, `6` положительно и делится и на 2, и на 3. Поэтому сделаем два независимых `if`. Для сообщения об отсутствии признаков отдельно проверим, что число неположительное или не делится ни на 2, ни на 3.

#### Алгоритм

1. Считываем целое число.
2. Проверяем положительность и делимость на 2; при успехе выводим первую строку.
3. Независимо проверяем положительность и делимость на 3; при успехе выводим вторую строку.
4. Если не подошёл ни один признак, выводим сообщение об этом.

#### Решение

```python
number = int(input())

if number > 0 and number % 2 == 0:
    print("положительное, делится на 2")

if number > 0 and number % 3 == 0:
    print("положительное, делится на 3")

if number <= 0 or (number % 2 != 0 and number % 3 != 0):
    print("нет подходящих признаков")
```

#### Разбор решения

`number % 2 == 0` означает, что остаток от деления на 2 равен нулю. Аналогично проверяется делимость на 3. В первых двух условиях `and` требует выполнения обеих частей: одной делимости недостаточно, число должно быть положительным.

Два отдельных `if` позволяют вывести оба сообщения для `6`. Если заменить второй `if` на `elif`, после успешной первой проверки вторая будет пропущена. Ученик потеряет один подходящий признак.

В последнем условии `or` объединяет две причины отсутствия признаков. Первая — число не больше нуля. Вторая — оно не делится ни на 2, ни на 3. Внутри скобок стоит `and`: должны не подходить оба делителя. Порядок первых двух проверок определяет порядок строк, но не мешает выполниться каждой из них.

#### Проверка

| Ввод | Почему проверяем | Результат |
|---:|---|---|
| `0` | граница положительности; делимость сама по себе не подходит | `нет подходящих признаков` |
| `1` | сразу после границы, не подходит ни один делитель | `нет подходящих признаков` |
| `2` | подходит только первый признак | `положительное, делится на 2` |
| `6` | подходят оба признака | `положительное, делится на 2`<br>`положительное, делится на 3` |

Перед границей, при `-1`, получим `нет подходящих признаков`. Для `3` появится только `положительное, делится на 3`: вторая проверка работает и без успеха первой.

**Ответ:** для `6` выводятся две строки; для `0` — только сообщение об отсутствии подходящих признаков.

### Задача 3. Шаг к экзаменационным задачам

#### Условие

Найдите наименьшее целое число `x`, для которого истинно высказывание:

> НЕ (x ≤ 20) И (x делится на 6).

Затем напишите программу, которая считывает одно целое число и выводит `подходит`, если оно удовлетворяет высказыванию, иначе — `не подходит`. Программа проверяет введённое число; наименьшее значение найдём рассуждением.

Это адаптация типа задач на поиск значения переменной по логическому выражению: числа изменены, добавлена проверка кандидата на Python.

#### Как рассуждать

Нужно одновременно выполнить два требования. `НЕ (x ≤ 20)` означает `x > 20`. Вторая часть требует нулевого остатка при делении на 6. Связка «И» превращается в `and`.

Сначала найдём ответ без кода. `18` делится на 6, но не больше 20. Следующее кратное 6 — `24`. Числа `21`, `22` и `23` на 6 не делятся, поэтому меньше подходящего числа уже нет.

Теперь используем `if/else`, чтобы проверить любое введённое число. Возможны только два ответа, и они исключают друг друга.

#### Алгоритм

1. Считываем целое число `x`.
2. Проверяем, что оно больше 20 и делится на 6 без остатка.
3. Если обе части истинны, выводим `подходит`.
4. Иначе выводим `не подходит`.

#### Решение

```python
x = int(input())

if x > 20 and x % 6 == 0:
    print("подходит")
else:
    print("не подходит")
```

#### Разбор решения

`x > 20` — запись первой части после снятия отрицания. Граница строгая: само число `20` не допускается. `x % 6 == 0` проверяет делимость. Оператор `and` требует, чтобы совпали оба признака; порядок этих двух проверок не меняет ответ.

Здесь нельзя заменить `and` на `or`: тогда, например, `21` подошло бы только потому, что оно больше 20. `else` нужен для всех случаев, когда хотя бы одна часть ложна.

Вывод `подходит` ещё не доказывает минимальность: `30` тоже подходит. Ответ `24` обоснован отдельным рассуждением о ближайших кратных.

#### Проверка

| Ввод | Почему проверяем | Результат |
|---:|---|---|
| `20` | граница исключена, оба требования ложны | `не подходит` |
| `23` | перед найденным ответом; нет делимости | `не подходит` |
| `24` | найденный минимум; обе части истинны | `подходит` |
| `25` | после ответа; одной величины числа недостаточно | `не подходит` |

Около строгой границы `19` и `21` тоже дадут `не подходит`. Для `18` делимость выполняется, но первая часть ложна: это дополнительно проверяет смысл `and`.

**Ответ:** `24` — наименьшее целое число, удовлетворяющее высказыванию.

В подборке есть поиск наибольшего и наименьшего числа с проверкой границ и делимости. Здесь используются сравнения, отрицание, `and`, `%` и выбор `if/else`.
