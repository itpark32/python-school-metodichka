Условие выбирает, какой фрагмент программы выполнить.

!!! abstract "Фокус"
    - **Нужно знать:** `if`, `elif`, `else` и отступы.
    - **Нужно уметь:** выбрать независимые проверки или цепочку вариантов.
    - **Полезно знать:** вложенность лучше ограничивать понятными условиями.

## 1. Формы ветвления

```python
temperature = int(input())

if temperature < 0:
    print("мороз")
elif temperature < 15:
    print("прохладно")
else:
    print("тепло")
```

Python проверяет ветви сверху вниз и выполняет только первую подходящую. Отступ показывает, какие команды принадлежат ветви.

Два независимых `if` могут выполнить оба блока. Цепочка `if/elif/else` выбирает один вариант.

```python
a = int(input())
b = int(input())

if a > b:
    maximum = a
else:
    maximum = b

print(maximum)
```

## 2. Частые ошибки

- забытый `:`;
- разные отступы;
- неверный порядок диапазонов в `elif`;
- использование нескольких `if`, когда варианты взаимоисключающие;
- путаница `=` и `==`.
