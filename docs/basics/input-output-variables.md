# Ввод, вывод и переменные

<p class="reading-time">Чтение: 12–15 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag">8 класс</span><span class="tag tag--oge">ОГЭ</span><span class="tag tag--ege">ЕГЭ</span></div>

Программа получает данные, выполняет команды и сообщает результат. Например, калькулятор получает цену и количество товаров, вычисляет стоимость и выводит её. Переменные позволяют сохранить каждое введённое и вычисленное значение под понятным именем.

!!! abstract "Фокус"
    - **Нужно знать:** `print`, `input`, присваивание `=`.
    - **Нужно уметь:** прочитать данные, изменить значение, вывести результат.
    - **Полезно знать:** f-строки делают вывод понятнее.

## 1. Первая программа

```python
name = input("Имя: ")
age = int(input("Возраст: "))
print(f"{name}, через год тебе будет {age + 1}")
```

`input()` всегда возвращает строку. Поэтому возраст превращаем в целое число функцией `int`. В фигурных скобках f-строки можно писать переменные и выражения.

Разберём выполнение по строкам:

1. `input("Имя: ")` показывает приглашение и ждёт ввод пользователя;
2. введённый текст сохраняется в переменной `name`;
3. второй `input` тоже возвращает текст, а `int` преобразует его в целое число;
4. `print` собирает итоговую фразу и выводит её.

Если ввести имя `Маша` и возраст `13`, программа напечатает `Маша, через год тебе будет 14`.

Для учебных и экзаменационных задач приглашения обычно не используют: проверяющая система ожидает только ответ.

```python
length = int(input())
width = int(input())
area = length * width
print(area)
```

При вводе `6` и `4` программа выводит только `24`. Каждое значение вводится с новой строки.

## 2. Присваивание — не равенство

```python
x = 5
x = x + 2
x = x * 3
print(x)
```

После каждой строки старое значение `x` заменяется новым: `5 → 7 → 21`. Запись `x = x + 2` — команда «взять старое `x`, прибавить 2 и сохранить обратно».

Знак `=` здесь не утверждает, что левая и правая части равны. Он сначала вычисляет выражение справа, а затем записывает результат в переменную слева.

| Выполненная строка | Новое значение `x` |
|---|---:|
| `x = 5` | `5` |
| `x = x + 2` | `7` |
| `x = x * 3` | `21` |

Переменная появляется после первого присваивания. Команда `print(score)` завершится ошибкой, если до неё не было строки вроде `score = 0`.

Имена чувствительны к регистру: `score`, `Score` и `SCORE` считаются разными переменными. Хорошее имя описывает смысл значения:

```python
ticket_price = 350
ticket_count = 4
total_price = ticket_price * ticket_count
```

Такие имена помогают читать программу без дополнительных пояснений.

## 3. Типовые задачи

```python
price = int(input())
count = int(input())
total = price * count
print(total)
```

Здесь ввод, вычисление и вывод разделены. Это удобно при отладке: можно временно вывести `price`, `count` или `total` и проверить каждый этап.

Ещё один частый сценарий — поменять местами значения двух переменных:

```python
first = int(input())
second = int(input())

first, second = second, first

print(first, second)
```

`print` может выводить несколько значений через пробел. Для поясняющего вывода подходят f-строки:

```python
distance = 120
time = 2
speed = distance / time
print(f"Скорость: {speed} км/ч")
```

В задачах с автоматической проверкой текст `Скорость:` добавляют только тогда, когда он указан в формате ответа.

## 4. Частые ошибки

- `"2" + "3"` даёт строку `"23"`, а не число `5`. Для сложения чисел нужен `int(input())`;
- `=` присваивает, а `==` сравнивает;
- переменную нельзя читать до первого присваивания;
- результат вычислен, но не передан в `print`;
- в ответ добавлен лишний поясняющий текст, которого не ждёт проверяющая система;
- имена `a`, `b` допустимы в короткой формуле, но `price` и `count` понятнее в большой программе.

!!! tip "Проверяйте программу вручную"
    До запуска подставьте простые значения и вычислите ответ на бумаге. Для цены `100` и количества `3` должно получиться `300`. Если программа выводит другое значение, проверяйте строки сверху вниз.

## 5. Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Личная карточка

#### Условие

Введите имя и название класса с двух строк. Выведите фразу вида `Маша учится в 8А`.

#### Как рассуждать

Оба значения — текст: вычислять с ними ничего не нужно. Сохраним их отдельно, затем подставим в одну фразу. Числовое преобразование для класса вроде `8А` не подходит.

#### Алгоритм

1. Прочитайте имя.
2. Прочитайте класс.
3. Соберите и выведите фразу.

#### Решение

```python
name = input()
school_class = input()
print(f"{name} учится в {school_class}")
```

#### Разбор решения

Каждый `input()` читает свою строку. Имена переменных показывают назначение текста. В f-строке подстановки заключены в фигурные скобки; пробелы между словами записаны явно.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| Маша; 8А | обычный случай | Маша учится в 8А |
| Лев; 11Б | короткое имя и двузначный номер класса | Лев учится в 11Б |

**Ответ:** для первого теста — Маша учится в 8А.

---

### Задача 2. Касса кружка

#### Условие

Введите целые неотрицательные цену одного набора, количество наборов и стоимость доставки, каждое с новой строки. Выведите общую стоимость.

#### Как рассуждать

Сначала найдём стоимость всех наборов умножением. Доставку оплачивают один раз за заказ, поэтому прибавим её после умножения. Промежуточный результат поможет проверить расчёт.

#### Алгоритм

1. Прочитайте три числа.
2. Умножьте цену на количество.
3. Прибавьте доставку и выведите итог.

#### Решение

```python
price = int(input())
count = int(input())
delivery = int(input())
goods = price * count
total = goods + delivery
print(total)
```

#### Разбор решения

`int` нужен для арифметики, иначе ввод останется текстом. `goods` хранит стоимость товаров, `total` — всего заказа. Выражение `price * (count + delivery)` было бы неверным: стоимость доставки не является количеством наборов.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 120; 3; 50 | обычный случай | 410 |
| 120; 1; 0 | один набор и бесплатная доставка | 120 |

**Ответ:** для первого теста — 410.

### Задача 3. Восстановление значений

#### Условие

Введите целые `a` и `b`. Выполните по порядку команды `a = a + b`, `b = a - b`, `a = a - b`. Выведите конечные `a` и `b` через пробел.

#### Как рассуждать

Это школьный тип задачи на последовательность присваиваний. После каждой команды правая часть использует уже обновлённые значения. Для исходных 4 и 9 получаем сначала пару 13 и 9, затем 13 и 4, затем 9 и 4.

#### Алгоритм

1. Прочитайте два числа.
2. Выполните три присваивания в заданном порядке.
3. Выведите конечную пару.

#### Решение

```python
a = int(input())
b = int(input())
a = a + b
b = a - b
a = a - b
print(a, b)
```

#### Разбор решения

Первое присваивание сохраняет сумму в `a`. Второе вычитает из суммы прежнее `b` и получает прежнее `a`. Третье оставляет в `a` прежнее `b`. Переменные меняются местами без потери исходных значений.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 4; 9 | обычный случай | 9 4 |
| 5; 5 | равные значения | 5 5 |
| -2; 0 | отрицательное число и ноль | 0 -2 |

**Ответ:** для первого теста — 9 4.

Третья задача использует школьный тип «определить значения после присваиваний»; похожие задания есть в подборке [Полякова](https://kpolyakov.spb.ru/school/test8a/py19x.htm). Последовательность команд и тестовые данные здесь учебные.
