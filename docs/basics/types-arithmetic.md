# Типы данных и арифметика

Тип данных говорит Python, что хранится в значении и какие операции с ним допустимы. Числа можно складывать, строки — соединять, а логические значения помогают принимать решения.

!!! abstract "Фокус"
    - **Нужно знать:** `int`, `float`, `str`, `bool`; `+ - * / // % **`.
    - **Нужно уметь:** преобразовать ввод и расставить скобки.
    - **Полезно знать:** десятичные дроби хранятся приблизительно.

## 1. Четыре основных типа

```python
students = 24       # int — целое
temperature = 18.5 # float — дробное
city = "Брянск"    # str — строка
is_ready = True    # bool — истина/ложь
```

Преобразования записывают как `int("42")`, `float("3.5")`, `str(42)`. Невозможное преобразование, например `int("три")`, завершится ошибкой.

Функция `type` помогает увидеть тип значения:

```python
print(type(42))       # <class 'int'>
print(type(3.5))      # <class 'float'>
print(type("42"))    # <class 'str'>
print(type(True))     # <class 'bool'>
```

Кавычки полностью меняют смысл: `42` — число, а `"42"` — два текстовых символа. Поэтому результаты двух программ различаются:

```python
print(2 + 3)      # 5
print("2" + "3")  # 23
```

Оператор `+` складывает числа, но соединяет строки. Операция выбирается по типам значений.

## 2. Преобразование данных

`input()` всегда возвращает `str`, даже если пользователь набрал цифры. Перед вычислениями текст преобразуют.

```python
price_text = input()
price = int(price_text)
print(price * 2)
```

Чаще эти действия объединяют: `price = int(input())`. Дробное число читают через `float(input())`. В Python дробная часть отделяется точкой: `3.14`, а не запятой.

Преобразование не меняет исходную переменную автоматически:

```python
text = "25"
number = int(text)

print(text)    # "25" осталось строкой
print(number)  # 25 — новое целое число
```

## 3. Арифметические операции

| Оператор | Действие | Пример | Результат |
|---|---|---|---:|
| `+` | сложение | `7 + 3` | `10` |
| `-` | вычитание | `7 - 3` | `4` |
| `*` | умножение | `7 * 3` | `21` |
| `/` | обычное деление | `7 / 2` | `3.5` |
| `//` | целая часть частного | `7 // 2` | `3` |
| `%` | остаток | `7 % 2` | `1` |
| `**` | степень | `2 ** 3` | `8` |

Операторы `/`, `//` и `%` похожи, но отвечают на разные вопросы. Если семь конфет разделить поровну между двумя детьми, каждый получит `7 // 2`, то есть три конфеты, а `7 % 2`, то есть одна конфета, останется.

## 4. Порядок действий

Python использует привычный математический порядок: скобки, степень, умножение и деление, затем сложение и вычитание.

```python
print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
print(2 ** 3 * 4)     # 32
```

Если порядок может быть непонятен читателю, поставьте скобки. Они делают намерение явным, даже когда формально не обязательны.

Среднее двух чисел вычисляют так:

```python
a = int(input())
b = int(input())
average = (a + b) / 2
print(average)
```

Без скобок выражение `a + b / 2` сначала разделит `b` на два и только потом прибавит `a`.

## 5. Разбор задачи со временем

```python
seconds = int(input())
hours = seconds // 3600
minutes = seconds % 3600 // 60
rest = seconds % 60
print(hours, minutes, rest)
```

Пусть введено `7385` секунд.

1. `7385 // 3600` даёт `2` полных часа.
2. `7385 % 3600` оставляет `185` секунд после выделения часов.
3. `185 // 60` даёт `3` полные минуты.
4. `7385 % 60` даёт `5` оставшихся секунд.

Ответ: `2 3 5`.

## 6. Точность `float`

```python
print(0.1 + 0.2)  # может быть 0.30000000000000004
```

Это свойство двоичного хранения дробей. В школьной задаче обычно достаточно округления: `round(value, 2)`.

```python
price = 199.9
count = 3
total = round(price * count, 2)
print(total)
```

Для задач, где все величины целые, лучше оставаться с `int`. Не преобразуйте каждое число во `float` без необходимости.

## 7. Частые ошибки

- путать `/` и `//`;
- забывать скобки в среднем: `(a + b) / 2`;
- складывать строку и число;
- ожидать абсолютно точных вычислений с `float`;
- вводить десятичную дробь через запятую;
- считать, что `int(3.9)` округлит число. Результатом будет `3`, потому что дробная часть отбрасывается.

### Задача 1. Средняя температура

#### Условие

Введите три температуры через `float(input())`, каждую с новой строки. Выведите их среднее арифметическое.

#### Как рассуждать

Температуры могут быть дробными и отрицательными, поэтому нужен `float`. Все три измерения равноправны: сначала складываем их, затем делим всю сумму на три.

#### Алгоритм

1. Прочитайте три температуры.
2. Вычислите сумму в скобках и разделите на 3.
3. Выведите среднее.

#### Решение

```python
a = float(input())
b = float(input())
c = float(input())
average = (a + b + c) / 3
print(average)
```

#### Разбор решения

Скобки не дают делению примениться только к последней температуре. Оператор `/` сохраняет дробную часть. Формат ввода — с точкой, например `2.5`.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 1; 2; 3 | обычный случай | 2.0 |
| -2.5; 0; 2.5 | отрицательное и дробное значения | 0.0 |

**Ответ:** для первого теста — 2.0.

### Задача 2. Цена после скидки

#### Условие

Введите цену товара и процент скидки, каждое с новой строки. Цена неотрицательна, процент от 0 до 100. Выведите цену после скидки, округлив до двух знаков после точки.

#### Как рассуждать

Скидка — часть исходной цены. Если скидка 20%, заплатить нужно 80% цены. Сначала найдём оставшийся процент; после расчёта округлим денежный результат.

#### Алгоритм

1. Прочитайте цену и процент.
2. Умножьте цену на оставшийся процент и разделите на 100.
3. Примените round и выведите результат.

#### Решение

```python
price = float(input())
percent = float(input())
result = price * (100 - percent) / 100
print(round(result, 2))
```

#### Разбор решения

`100 - percent` — процент к оплате, а не размер самой скидки. `round(result, 2)` округляет число, но не дописывает нули: цена `80.0` допустима. На границах 0% и 100% получаем исходную цену и ноль.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 200; 15 | обычный случай | 170.0 |
| 80; 0 | скидки нет | 80.0 |
| 80; 100 | полная скидка | 0.0 |

**Ответ:** для первого теста — 170.0.

### Задача 3. Сколько рейсов понадобится

#### Условие

Введите число учеников `n ≥ 0` и число мест `k > 0` в автобусе. Найдите минимальное число рейсов, чтобы перевезти всех; неполный последний автобус тоже делает рейс.

#### Как рассуждать

Обычное деление даёт дробное число рейсов, а `n // k` теряет неполный остаток. Для целых чисел округление вверх можно получить как `(n + k - 1) // k`: добавка заставляет неполную группу занять ещё один рейс.

#### Алгоритм

1. Прочитайте n и k.
2. Прибавьте к n число k - 1.
3. Разделите на k нацело и выведите результат.

#### Решение

```python
n = int(input())
k = int(input())
trips = (n + k - 1) // k
print(trips)
```

#### Разбор решения

При `n = 20`, `k = 10` получаем `29 // 10 = 2`; при 21 ученике — `30 // 10 = 3`. Прибавка меньше `k`, поэтому точное число полных групп не получает лишнего рейса. Условия и округление через `float` здесь не нужны.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 21; 10 | обычный случай | 3 |
| 20; 10 | деление без остатка | 2 |
| 0; 10 | никого перевозить не надо | 0 |

**Ответ:** для первого теста — 3.
