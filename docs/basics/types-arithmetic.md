Тип говорит Python, что хранится в значении и какие операции с ним допустимы.

!!! abstract "Фокус"
    - **Нужно знать:** `int`, `float`, `str`, `bool`; `+ - * / // % **`.
    - **Нужно уметь:** преобразовать ввод и расставить скобки.
    - **Полезно знать:** десятичные дроби хранятся приблизительно.

## 1. Четыре основных типа

```python
students = 24       # int — целое
temperature = 18.5 # float — дробное
city = "Брянск"    # str — строка
is_ready = True    # bool — истина/ложь
```

Преобразования записывают как `int("42")`, `float("3.5")`, `str(42)`. Невозможное преобразование, например `int("три")`, завершится ошибкой.

## 2. Операции

`/` всегда даёт дробный результат, `//` — целую часть частного, `%` — остаток, `**` — степень. Сначала выполняются скобки, затем степень, умножение и деление, потом сложение и вычитание.

```python
seconds = int(input())
hours = seconds // 3600
minutes = seconds % 3600 // 60
rest = seconds % 60
print(hours, minutes, rest)
```

## 3. Точность float

```python
print(0.1 + 0.2)  # может быть 0.30000000000000004
```

Это свойство двоичного хранения дробей. В школьной задаче обычно достаточно округления: `round(value, 2)`.

## 4. Частые ошибки

- путать `/` и `//`;
- забывать скобки в среднем: `(a + b) / 2`;
- складывать строку и число;
- ожидать абсолютно точных вычислений с `float`.
