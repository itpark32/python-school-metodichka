# Линейный и бинарный поиск

<p class="reading-time">Чтение: 8 минут · Практика: 20 минут</p>
<div class="tags"><span class="tag">9–11 класс</span><span class="tag tag--ege">ЕГЭ</span><span class="tag tag--plus">Углублённый уровень</span></div>

Линейный поиск проверяет все элементы. Бинарный сравнивает с серединой и каждый раз отбрасывает половину — но требует сортировки.

!!! abstract "Фокус"
    - **Нужно знать:** границы `left`, `right`, середина.
    - **Нужно уметь:** объяснить, почему поиск завершается.

```python
left = 0
right = len(numbers) - 1
target = 42
position = -1

while left <= right:
    middle = (left + right) // 2
    if numbers[middle] == target:
        position = middle
        break
    if numbers[middle] < target:
        left = middle + 1
    else:
        right = middle - 1
```

При неравенстве середину уже проверили, поэтому новая граница сдвигается на один. Для миллиона элементов бинарному поиску нужно около 20 сравнений, линейному — до миллиона.

!!! info "Python+"
    Модуль `bisect` выполняет бинарный поиск позиции вставки, но сначала важно понять границы вручную.
