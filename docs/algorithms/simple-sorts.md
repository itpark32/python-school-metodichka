# Простые алгоритмы сортировки

<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>
<div class="tags"><span class="tag">9–11 класс</span></div>

Сортировка переставляет элементы по порядку. Школьные алгоритмы нужны для понимания, хотя в обычном Python используют встроенную сортировку.

!!! abstract "Фокус"
    - **Нужно знать:** пузырёк, выбор и вставки.
    - **Нужно уметь:** объяснить одну итерацию каждого алгоритма.

```python
# Пузырьковая: большой элемент всплывает вправо
for end in range(len(numbers) - 1, 0, -1):
    for i in range(end):
        if numbers[i] > numbers[i + 1]:
            numbers[i], numbers[i + 1] = numbers[i + 1], numbers[i]
```

```python
# Выбором: ставим минимум на очередное место
for left in range(len(numbers)):
    minimum = left
    for i in range(left + 1, len(numbers)):
        if numbers[i] < numbers[minimum]:
            minimum = i
    numbers[left], numbers[minimum] = numbers[minimum], numbers[left]
```

```python
# Вставками: вставляем элемент в отсортированный префикс
for i in range(1, len(numbers)):
    value, j = numbers[i], i
    while j > 0 and numbers[j - 1] > value:
        numbers[j] = numbers[j - 1]
        j -= 1
    numbers[j] = value
```

Все три в худшем случае требуют порядка `n²` действий.

## Что гарантирует внешний шаг

После прохода пузырька наибольший элемент неотсортированной части оказывается справа. После шага выбора в позиции `left` стоит минимум оставшегося хвоста. У вставок часть слева от `i` уже отсортирована, а новый элемент вставляется в правильное место.

Эти утверждения — инварианты алгоритмов. С ними легче восстановить код и доказать результат, чем запоминать строки.

Для списка `[4, 1, 3]` первый проход пузырька даёт `[1, 3, 4]`: сначала меняются 4 и 1, затем 4 и 3. Сортировка выбором сначала найдёт минимум 1 и поставит его в начало: `[1, 4, 3]`. Вставки начинают с отсортированной части `[4]`, вставляют 1, затем 3.

## Сравнение алгоритмов

Все три просты для обучения, но по-разному ведут себя на почти отсортированных данных. Вставки могут сделать мало сдвигов, а выбор всё равно ищет минимум во всём хвосте. В прикладном коде используют встроенную сортировку: она быстрее и лучше протестирована.

Проверяйте пустой список, один элемент, уже отсортированный, обратный порядок и повторы. Перестановка должна сохранять все исходные элементы.

## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

Если данные заданы прямо в коде, для дополнительных тестов заменяйте начальные значения на данные из таблицы.

### Задача 1. Пузырёк по возрастанию

#### Условие

Отсортируйте список `numbers = [4, 1, 3]` пузырьковым алгоритмом и выведите его. Не используйте sort или sorted.

#### Как рассуждать

Сравнение соседей переносит более крупное значение вправо. После полного прохода последний элемент уже стоит на месте, поэтому следующему проходу нужен более короткий участок.

#### Алгоритм

1. Перебирайте правую границу неготовой части справа налево.
2. Сравнивайте соседей до этой границы.
3. Меняйте неверно стоящую пару местами и выведите итог.

#### Решение

```python
numbers = [4, 1, 3]
for end in range(len(numbers) - 1, 0, -1):
    for i in range(end):
        if numbers[i] > numbers[i + 1]:
            numbers[i], numbers[i + 1] = numbers[i + 1], numbers[i]
print(numbers)
```

#### Разбор решения

Первый проход для примера даёт `[1, 3, 4]`. Даже если порядок уже готов, остальные сравнения безопасны. Обмен сохраняет оба исходных значения; два последовательных присваивания без временного хранения могли бы потерять одно из них.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [4, 1, 3] | обычный случай | [1, 3, 4] |
| [2, 2, 1] | повторы сохраняются | [1, 2, 2] |
| [] | нет сравнений | [] |

**Ответ:** для первого теста — [1, 3, 4].

### Задача 2. Выбор максимума в начало

#### Условие

Отсортируйте `numbers = [3, 1, 5, 3]` по убыванию сортировкой выбором.

#### Как рассуждать

На каждом шаге ищем максимум ещё неготового хвоста и ставим в его начало. Готовая левая часть увеличивается на один элемент. Для убывания выбирается именно максимум, а не минимум.

#### Алгоритм

1. Переберите левые границы хвоста.
2. Найдите индекс максимума хвоста.
3. Обменяйте его с левой позицией и выведите список.

#### Решение

```python
numbers = [3, 1, 5, 3]
for left in range(len(numbers)):
    best = left
    for i in range(left + 1, len(numbers)):
        if numbers[i] > numbers[best]:
            best = i
    numbers[left], numbers[best] = numbers[best], numbers[left]
print(numbers)
```

#### Разбор решения

best хранит индекс, чтобы затем выполнить обмен. Начальный кандидат left гарантированно принадлежит хвосту. Если максимум уже на своём месте, обмен элемента с собой ничего не портит.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [3, 1, 5, 3] | обычный случай | [5, 3, 3, 1] |
| [-4, -1] | отрицательные числа | [-1, -4] |
| [7] | единственный элемент | [7] |

**Ответ:** для первого теста — [5, 3, 3, 1].

### Задача 3. Сортировка вставками с подсчётом сдвигов

#### Условие

Отсортируйте `numbers = [3, 1, 2]` вставками по возрастанию. Выведите список и количество сдвигов элементов вправо. Постановку сохранённого value на место сдвигом не считайте.

#### Как рассуждать

Слева от текущей позиции уже есть отсортированный участок. Сохраняем вставляемое число, затем сдвигаем большие элементы вправо, пока не освободится его место. Счётчик увеличиваем ровно в строке сдвига.

#### Алгоритм

1. Начните с второго элемента и сохраните его значение.
2. Сдвигайте вправо большие элементы слева.
3. Поставьте сохранённое число в освободившуюся позицию.
4. Выведите результат и число сдвигов.

#### Решение

```python
numbers = [3, 1, 2]
shifts = 0
for i in range(1, len(numbers)):
    value = numbers[i]
    j = i
    while j > 0 and numbers[j - 1] > value:
        numbers[j] = numbers[j - 1]
        shifts += 1
        j -= 1
    numbers[j] = value
print(numbers)
print(shifts)
```

#### Разбор решения

Для `[3, 1, 2]` тройка сдвигается по разу при вставке 1 и 2: всего 2. Проверка `j > 0` стоит первой и не даёт читать отрицательную позицию вместо выхода за левую границу. Равные значения не сдвигаются.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [3, 1, 2] | обычный случай | [1, 2, 3]<br>2 |
| [1, 2, 3] | уже отсортировано | [1, 2, 3]<br>0 |
| [3, 2, 1] | обратный порядок | [1, 2, 3]<br>3 |
| [] | пустой список | []<br>0 |

**Ответ:** для первого теста — [1, 2, 3]; 2.
