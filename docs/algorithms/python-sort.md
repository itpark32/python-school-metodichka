# `sort` и `sorted`

<p class="reading-time">Чтение: 12–15 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag">9–11 класс</span><span class="tag tag--ege">ЕГЭ</span><span class="tag tag--plus">Python+</span></div>

`list.sort()` меняет список, `sorted(iterable)` возвращает новый. Оба поддерживают обратный порядок и ключ.

!!! abstract "Фокус"
    - **Нужно уметь:** выбрать между изменением списка и новой копией.

```python
students = [("Маша", 78), ("Петя", 91), ("Ира", 85)]

def get_score(student):
    return student[1]

students.sort(key=get_score, reverse=True)
```

Ключ вычисляется для каждого элемента и определяет порядок. Сортировка кортежей без ключа сравнивает сначала первый компонент, затем следующий. Не сохраняйте `result = numbers.sort()`: результатом будет `None`.

## Изменить или сохранить исходное

`numbers.sort()` уместен, когда прежний порядок больше не нужен. `ordered = sorted(numbers)` создаёт новый список и оставляет исходный. Это решение лучше принять до вызова, чтобы случайно не потерять значимый порядок данных.

Функция `key` не сравнивает элементы сама: она возвращает признак сортировки. По длине слова: `sorted(words, key=len)`. Для нескольких критериев ключ может быть кортежем:

```python
def student_key(student):
    name, score = student
    return -score, name

ordered = sorted(students, key=student_key)
```

Сначала сравнивается отрицательный балл — большие баллы идут раньше, при равенстве имена идут по алфавиту. Такая запись яснее общего `reverse=True`, когда направления критериев различаются.

### Задача 1. Новый порядок без изменения исходного

#### Условие

Для `numbers = [3, 8, 1, 8]` создайте новый список по убыванию. Выведите новый и исходный списки.

#### Как рассуждать

Нужно сохранить старый порядок, поэтому выбираем sorted, а не метод sort. Параметр reverse=True задаёт убывание. Повторы должны сохраниться: множество здесь не подходит.

#### Алгоритм

1. Вызовите sorted с reverse=True.
2. Сохраните новый список отдельно.
3. Выведите оба списка.

#### Решение

```python
numbers = [3, 8, 1, 8]
ordered = sorted(numbers, reverse=True)
print(ordered)
print(numbers)
```

#### Разбор решения

`sorted` возвращает новый объект. `numbers.sort()` изменил бы исходный и вернул None. Одинаковые восьмёрки остаются двумя элементами.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [3, 8, 1, 8] | обычный случай | [8, 8, 3, 1]<br>[3, 8, 1, 8] |
| [] | пустая копия | []<br>[] |

**Ответ:** для первого теста — [8, 8, 3, 1]; [3, 8, 1, 8].

### Задача 2. Рейтинг с правилом равенства

#### Условие

Дан список пар имя–балл: `students = [("Вера", 80), ("Анна", 90), ("Борис", 90)]`. Выведите участников по убыванию балла, а при равенстве — по имени по возрастанию. Каждого выводите отдельной строкой: имя и балл.

#### Как рассуждать

У критериев разные направления. Ключ из отрицательного балла и имени позволяет оба компонента сортировать обычным возрастанием: большие баллы станут меньшими отрицательными числами.

#### Алгоритм

1. Опишите функцию-ключ, возвращающую (-балл, имя).
2. Создайте отсортированный список.
3. Выведите записи по порядку.

#### Решение

```python
students = [("Вера", 80), ("Анна", 90), ("Борис", 90)]
def rating_key(student):
    name, score = student
    return -score, name

ordered = sorted(students, key=rating_key)
for name, score in ordered:
    print(name, score)
```

#### Разбор решения

Глобальное `reverse=True` развернуло бы и имена, что неверно. Кортеж-ключ сначала сравнивает балл со знаком минус, затем имя. Имена здесь записаны в одном регистре, чтобы порядок был предсказуем.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| Вера 80, Анна 90, Борис 90 | обычный случай | Анна 90<br>Борис 90<br>Вера 80 |
| один участник | минимальный список | Яна 0 |
| [] | никого не выводим | нет строк вывода |

**Ответ:** для первого теста — Анна 90; Борис 90; Вера 80.

### Задача 3. Больше покупок на бюджет

#### Условие

Даны положительные целые цены `prices = [8, 3, 5, 2]` и неотрицательный бюджет `budget = 10`. Каждый товар можно купить один раз. Найдите максимальное количество покупок и минимальную стоимость такого количества товаров.

#### Как рассуждать

Чтобы купить как можно больше, берём самые дешёвые товары первыми. Любой набор из k товаров стоит не меньше k самых дешёвых, значит такая стратегия не теряет лучший ответ. Если очередная цена уже не помещается, все дальнейшие ещё не дешевле.

#### Алгоритм

1. Отсортируйте цены по возрастанию.
2. Добавляйте цену, пока общая сумма не превосходит бюджет.
3. Остановитесь на первой невозможной покупке.
4. Выведите количество и потраченную сумму.

#### Решение

```python
prices = [8, 3, 5, 2]
budget = 10
count = 0
total = 0
for price in sorted(prices):
    if total + price > budget:
        break
    total += price
    count += 1
print(count, total)
```

#### Разбор решения

Равенство бюджету допускается: остановка только при `>`. Для примера порядок цен 2, 3, 5, 8, поэтому выбираются первые три за 10. В этой задаче не нужно максимизировать самый дорогой выбранный товар — такой дополнительный критерий встречается в полных экзаменационных вариантах.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| цены [8,3,5,2], бюджет 10 | обычный случай | 3 10 |
| бюджет 1 | ни одна покупка не помещается | 0 0 |
| цены [], бюджет 10 | товаров нет | 0 0 |
| бюджет 18 | все товары и точная граница | 4 18 |

**Ответ:** для первого теста — 3 10.
