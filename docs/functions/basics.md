# Функции, параметры и `return`
<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>
<div class="tags"><span class="tag">9–11 класс</span><span class="tag tag--ege">ЕГЭ</span></div>
Функция даёт имя законченному действию и позволяет использовать его повторно.
!!! abstract "Фокус"
    - **Нужно знать:** `def`, параметры, аргументы, `return`.
    - **Нужно уметь:** отличать возврат результата от печати.
```python
def square(number):
    return number ** 2

result = square(5)
print(result)
```
Параметр `number` получает аргумент `5`. `return` отдаёт значение месту вызова и завершает функцию. `print` лишь показывает текст и обычно возвращает `None`.

## Контракт функции

Перед написанием определите три вещи: какие данные функция получает, что возвращает и при каких ограничениях работает. Хорошее имя описывает действие или результат.

```python
def is_even(number):
    return number % 2 == 0

if is_even(14):
    print("чётное")
```

Логической функции не нужен лишний `if`: результат сравнения уже равен `True` или `False`.

Функция может иметь несколько параметров и несколько точек `return`. Как только выполнен `return`, оставшиеся строки этого вызова не исполняются.

```python
def safe_divide(a, b):
    if b == 0:
        return None
    return a / b
```

Вызывающий код обязан обработать договорённое значение `None`. В другой задаче правильнее запретить нулевой делитель — контракт зависит от условия.

## Проверяем отдельно

Функцию удобно тестировать короткими вызовами с обычными и граничными аргументами. Чистая вычислительная функция без `input` внутри легче проверяется и повторно используется. Ввод и вывод обычно остаются в основной части программы.

### Задача 1. Максимум двух аргументов

#### Условие

Напишите функцию larger(a, b), возвращающую большее из двух целых чисел без max. Считайте два числа с разных строк и выведите результат вызова.

#### Как рассуждать

Вычислительная функция должна вернуть число, а не напечатать его. Тогда результат можно сохранить или использовать в другом выражении. При равенстве подойдёт любой из двух одинаковых аргументов.

#### Алгоритм

1. Опишите функцию с двумя параметрами.
2. Верните a, если оно больше, иначе b.
3. Прочитайте аргументы и напечатайте возвращённое значение.

#### Решение

```python
def larger(a, b):
    if a > b:
        return a
    return b

a = int(input())
b = int(input())
print(larger(a, b))
```

#### Разбор решения

Первый return завершает вызов, поэтому после него else не обязателен. Ввод находится снаружи: одну функцию можно проверять разными аргументами без повторного чтения. Отрицательные числа сравниваются тем же способом.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3; 8 | обычный случай | 8 |
| 5; 5 | равенство | 5 |
| -4; -9 | оба отрицательны | -4 |

**Ответ:** для первого теста — 8.

### Задача 2. Сумма цифр как функция

#### Условие

Напишите digit_sum(number) для целого неотрицательного числа. Затем считайте два таких числа и выведите сумму их сумм цифр.

#### Как рассуждать

Алгоритм обработки цифр повторяется дважды, поэтому дадим ему имя. Локальный накопитель создаётся заново при каждом вызове. Ноль не требует отдельного цикла: его сумма цифр тоже ноль.

#### Алгоритм

1. В функции обнулите сумму.
2. Отделяйте последнюю цифру и уменьшайте число.
3. Верните сумму.
4. В основной части сложите результаты двух вызовов.

#### Решение

```python
def digit_sum(number):
    total = 0
    while number > 0:
        total += number % 10
        number //= 10
    return total

a = int(input())
b = int(input())
print(digit_sum(a) + digit_sum(b))
```

#### Разбор решения

Изменяется локальный параметр number, а не a или b снаружи. `return total` расположен после цикла, иначе функция закончилась бы после одной цифры. Два результата складываются как обычные числа.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 123; 90 | обычный случай | 15 |
| 0; 0 | оба цикла пусты | 0 |
| 100; 5 | нули внутри записи | 6 |

**Ответ:** для первого теста — 15.

### Задача 3. Отбор с функцией-признаком

#### Условие

Для списка `numbers = [12, 18, 20, 21]` посчитайте числа от 10 до 99 включительно, кратные 3 и не кратные 2. Вынесите проверку в fits(number).

#### Как рассуждать

Нужно объединить диапазон и два признака делимости. Функция возвращает True или False для одного числа, а основной цикл только считает подходящие. Это позволяет отдельно проверять правило и обработку набора.

#### Алгоритм

1. Опишите логическую функцию fits.
2. Обойдите список и вызывайте fits для каждого числа.
3. Увеличивайте счётчик и выведите его.

#### Решение

```python
def fits(number):
    return 10 <= number <= 99 and number % 3 == 0 and number % 2 != 0

numbers = [12, 18, 20, 21]
count = 0
for number in numbers:
    if fits(number):
        count += 1
print(count)
```

#### Разбор решения

Сравнения сами дают логическое значение, поэтому внутри функции не требуется ветвление с возвратом True и False. Один и тот же фильтр вызывается без копирования длинного условия. В исходном списке подходит только 21.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [12, 18, 20, 21] | обычный случай | 1 |
| [9, 10, 99, 100] | границы диапазона | 1 |
| [] | нет данных | 0 |

**Ответ:** для первого теста — 1.
