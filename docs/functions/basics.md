# Функции, параметры и `return`

Функция даёт имя законченному действию и позволяет использовать его повторно.
!!! abstract "Фокус"
    - **Нужно знать:** `def`, параметры, аргументы, `return`.
    - **Нужно уметь:** отличать возврат результата от печати.
```python
def square(number):
    return number ** 2

result = square(5)
print(result)
```
Параметр `number` получает аргумент `5`. `return` отдаёт значение месту вызова и завершает функцию. `print` лишь показывает текст и обычно возвращает `None`.

## Контракт функции

Перед написанием определите три вещи: какие данные функция получает, что возвращает и при каких ограничениях работает. Хорошее имя описывает действие или результат.

```python
def is_even(number):
    return number % 2 == 0

if is_even(14):
    print("чётное")
```

Логической функции не нужен лишний `if`: результат сравнения уже равен `True` или `False`.

Функция может иметь несколько параметров и несколько точек `return`. Как только выполнен `return`, оставшиеся строки этого вызова не исполняются.

```python
def safe_divide(a, b):
    if b == 0:
        return None
    return a / b
```

Вызывающий код обязан обработать договорённое значение `None`. В другой задаче правильнее запретить нулевой делитель — контракт зависит от условия.

## Проверяем отдельно

Функцию удобно тестировать короткими вызовами с обычными и граничными аргументами. Чистая вычислительная функция без `input` внутри легче проверяется и повторно используется. Ввод и вывод обычно остаются в основной части программы.
