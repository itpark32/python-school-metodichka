Локальная переменная существует внутри вызова функции. Разбиение задачи на функции уменьшает объём, который надо держать в голове.
!!! abstract "Фокус"
    - **Нужно уметь:** передавать данные параметрами и возвращать результат.
```python
def calculate_result(numbers):
    return sum(numbers)

def main():
    numbers = [3, 5, 7]
    result = calculate_result(numbers)
    print(result)

main()
```
Одинаковые имена внутри и снаружи могут обозначать разные переменные. Глобальное изменяемое состояние затрудняет проверку: предпочитайте параметры и `return`.

## Один вызов — одна локальная область

При каждом вызове создаются свои параметры и локальные переменные. После завершения вызова они больше не нужны. Изменение локального числа не меняет одноимённую переменную снаружи.

```python
value = 10

def increase(value):
    value += 1
    return value

new_value = increase(value)
print(value, new_value)  # 10 11
```

Со списками важно помнить об изменяемости: метод `append` меняет переданный объект. Если функция не должна иметь побочных эффектов, создайте копию или явно опишите изменение в её назначении.

## Как разбивать задачу

Выносите действие в функцию, если оно имеет понятное имя, повторяется или его можно проверить отдельно. Для задачи с файлом естественны части `read_numbers`, `calculate_answer`, `print_answer`. Не дробите каждую строку: функция должна представлять законченную мысль.

Сигнал удачной декомпозиции — вычислительная функция получает данные параметрами и возвращает ответ, не зная имени файла и формата вывода.
## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

Если данные заданы прямо в коде, для дополнительных тестов заменяйте начальные значения на данные из таблицы.

### Задача 1. Независимые вызовы

#### Условие

Напишите increase(value), возвращающую число на 1 больше аргумента. Для внешнего value = 10 вызовите её дважды с тем же исходным аргументом и выведите исходное число и два результата.

#### Как рассуждать

Числовой параметр каждого вызова локален. Если результат не присваивать обратно внешней переменной, она остаётся равной 10. Второй вызов снова получает 10, а не результат первого.

#### Алгоритм

1. Опишите функцию с локальным увеличением.
2. Сохраните результаты двух вызовов.
3. Выведите исходное и оба новых значения.

#### Решение

```python
def increase(value):
    value += 1
    return value

value = 10
first = increase(value)
second = increase(value)
print(value, first, second)
```

#### Разбор решения

Одинаковое имя value внутри и снаружи не означает общую изменяемую переменную. `first` и `second` хранят возвращённые результаты. Для цепочки увеличений нужно было бы явно передать first во второй вызов.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| value = 10 | обычный случай | 10 11 11 |
| value = -1 | переход через ноль | -1 0 0 |

**Ответ:** для первого теста — 10 11 11.

### Задача 2. Фильтр без побочного эффекта

#### Условие

Напишите positive_copy(numbers), возвращающую новый список положительных элементов без изменения исходного. Для `numbers = [-1, 2, 0, 3]` выведите результат и исходный список.

#### Как рассуждать

Переданный список — изменяемый объект. Чтобы функция случайно не исправила входные данные, не вызываем у него удаление и не присваиваем в его позиции. Все находки добавляем в отдельный локальный список.

#### Алгоритм

1. Внутри функции создайте пустой результат.
2. Добавляйте в него только положительные значения.
3. Верните результат и проверьте исходный список снаружи.

#### Решение

```python
def positive_copy(numbers):
    result = []
    for number in numbers:
        if number > 0:
            result.append(number)
    return result

numbers = [-1, 2, 0, 3]
print(positive_copy(numbers))
print(numbers)
```

#### Разбор решения

Имя result связывается с новым списком в каждом вызове. `append` изменяет именно этот новый объект. Так функция имеет понятный договор: получить данные, вернуть отбор и сохранить вход.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [-1, 2, 0, 3] | обычный случай | [2, 3]<br>[-1, 2, 0, 3] |
| [] | пустой вход | []<br>[] |
| [-2, 0] | пустой отбор | []<br>[-2, 0] |

**Ответ:** для первого теста — [2, 3]; [-1, 2, 0, 3].

### Задача 3. Расчёт отдельно от ввода

#### Условие

Сначала вводится n ≥ 0, затем n целых результатов. Выведите количество результатов не ниже 60 и их сумму. Разделите программу на read_numbers(), summarize(numbers) и main().

#### Как рассуждать

Чтение зависит от формата ввода, расчёт — от списка, а вывод — от требуемого ответа. Разделим эти обязанности. summarize должна возвращать два числа, не читая клавиатуру и не печатая: так её можно проверить отдельно.

#### Алгоритм

1. Соберите ввод в функции чтения.
2. В вычислительной функции обновите два накопителя и верните кортеж.
3. В main свяжите чтение, расчёт и вывод.

#### Решение

```python
def read_numbers():
    n = int(input())
    numbers = []
    for _ in range(n):
        numbers.append(int(input()))
    return numbers

def summarize(numbers):
    count = 0
    total = 0
    for number in numbers:
        if number >= 60:
            count += 1
            total += number
    return count, total

def main():
    numbers = read_numbers()
    count, total = summarize(numbers)
    print(count, total)

main()
```

#### Разбор решения

`return count, total` возвращает пару, которую main распаковывает. Все накопители локальны, поэтому повторный расчёт не наследует старые значения. Граница 60 включена. Этот способ разбиения пригодится и для экзаменационных файловых задач.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3; 59; 60; 80 | обычный случай | 2 140 |
| 0 | пустой ввод | 0 0 |
| 1; 60 | точная граница | 1 60 |

**Ответ:** для первого теста — 2 140.
