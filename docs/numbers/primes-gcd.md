Простое число больше 1 и имеет ровно два делителя. НОД удобно искать алгоритмом Евклида.

!!! abstract "Фокус"
    - **Нужно уметь:** проверить простоту и объяснить Евклида.

```python
def is_prime(number):
    if number < 2:
        return False
    d = 2
    while d * d <= number:
        if number % d == 0:
            return False
        d += 1
    return True
```

Разложение: пока число делится на текущий `d`, сохраняйте `d` и делите число; затем переходите к следующему делителю.

```python
while b != 0:
    a, b = b, a % b
print(a)
```

НОД не меняется, если заменить пару `(a,b)` на `(b,a%b)`, а остатки уменьшаются до нуля.

## Проверка простоты

Числа 0 и 1 не простые по определению. Если найден хотя бы один делитель от 2 до корня, можно сразу вернуть `False`: второй множитель уже существует. Если цикл завершился без делителя, число простое.

Для 49 проверки доходят до 7 и находят делитель. Для 47 ни одно число до 6 включительно не делит его, а больший нетривиальный делитель не мог бы существовать без меньшего парного.

## Разложение и Евклид

При разложении один делитель проверяют несколько раз: `while number % d == 0`. Например, у 72 множитель 2 встречается трижды. После окончания процесса остаток больше 1 сам является простым множителем.

Трассировка НОД для 48 и 18: `(48, 18) → (18, 12) → (12, 6) → (6, 0)`. Последнее ненулевое значение 6. Для НОК положительных чисел можно использовать `a * b // gcd(a, b)`, учитывая возможные ограничения на большие числа.

## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Проверка простоты

#### Условие

Введите целое n от 0 до 10⁶. Выведите True, если число простое, иначе False.

#### Как рассуждать

Числа меньше 2 исключаются по определению. Для остальных ищем хотя бы один делитель от 2 до корня. Если его нет, у числа не может быть нетривиальной пары множителей.

#### Алгоритм

1. Отдельно отвергните n < 2.
2. Проверяйте делители, пока d*d ≤ n.
3. При первом делителе верните False, после цикла — True.

#### Решение

```python
def is_prime(number):
    if number < 2:
        return False
    d = 2
    while d * d <= number:
        if number % d == 0:
            return False
        d += 1
    return True

n = int(input())
print(is_prime(n))
```

#### Разбор решения

Для 2 цикл пуст, и это правильно: число простое. Для 49 необходимо проверить d = 7, поэтому граница включающая. Ранний return False экономит оставшиеся проверки, когда делитель уже найден.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 49 | квадрат простого | False |
| 2 | наименьшее простое | True |
| 1 | исключение по определению | False |
| 47 | нет делителей до корня | True |

**Ответ:** для первого теста — False.

### Задача 2. НОД и НОК

#### Условие

Введите два положительных целых a и b. Найдите их НОД алгоритмом Евклида, затем НОК. Выведите два результата через пробел.

#### Как рассуждать

При переходе от пары (a,b) к (b,a%b) общий набор делителей не меняется. Остаток уменьшается до нуля. Для НОК понадобятся исходные числа, поэтому алгоритм запускаем на копиях.

#### Алгоритм

1. Сохраните входные числа.
2. В копиях выполняйте шаги Евклида до нулевого остатка.
3. По НОД вычислите a*b//НОД.
4. Выведите НОД и НОК.

#### Решение

```python
a = int(input())
b = int(input())
x = a
y = b
while y != 0:
    x, y = y, x % y
gcd = x
lcm = a * b // gcd
print(gcd, lcm)
```

#### Разбор решения

Копии x и y меняются, а a и b сохраняются для произведения. Положительность гарантирует ненулевой НОД. Для взаимно простых чисел НОД равен 1, а НОК — произведению.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 48; 18 | обычный случай | 6 144 |
| 7; 7 | равные числа | 7 7 |
| 3; 5 | взаимно простые | 1 15 |

**Ответ:** для первого теста — 6 144.

### Задача 3. Разложение с повторениями

#### Условие

Введите натуральное n от 1 до 10⁶. Выведите список простых множителей в неубывающем порядке, с повторениями. Для n = 1 выведите пустой список.

#### Как рассуждать

После обнаружения делителя нельзя сразу переходить к следующему: тот же множитель может входить несколько раз. Делим рабочее число, пока оно кратно d. Если после проверки до корня остался остаток больше 1, он сам простой.

#### Алгоритм

1. Создайте пустой список множителей.
2. Для каждого d многократно делите рабочее число, сохраняя d.
3. После цикла добавьте остаток больше 1.
4. Выведите список.

#### Решение

```python
n = int(input())
factors = []
d = 2
while d * d <= n:
    while n % d == 0:
        factors.append(d)
        n //= d
    d += 1
if n > 1:
    factors.append(n)
print(factors)
```

#### Разбор решения

Для 72 двойка добавляется три раза, затем тройка два раза: `[2, 2, 2, 3, 3]`. Граница использует уменьшающееся n. Оставшийся множитель добавляется отдельно, иначе простой исходный ввод дал бы пустой ответ.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 72 | обычный случай | [2, 2, 2, 3, 3] |
| 13 | простое исходное число | [13] |
| 1 | множителей нет | [] |
| 49 | повтор корневого множителя | [7, 7] |

**Ответ:** для первого теста — [2, 2, 2, 3, 3].
