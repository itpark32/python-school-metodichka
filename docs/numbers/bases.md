# Системы счисления через Python

<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>

Система счисления задаёт основание и допустимые цифры. Python умеет читать записи и переводить число обратно.

!!! abstract "Фокус"
    - **Нужно знать:** `int(text, base)`, `bin`, `oct`, `hex`.
    - **Нужно уметь:** вручную переводить из десятичной системы в основание 2–9.

```python
print(int("101101", 2))  # 45
print(bin(45))            # 0b101101
```

```python
number = 45
base = 2
result = ""
while number > 0:
    result = str(number % base) + result
    number //= base
print(result)
```

Остатки появляются справа налево, поэтому новая цифра добавляется в начало. Для исходного нуля результат должен быть `"0"`.

## Из записи в число

Запись `101101₂` означает `1·2⁵ + 0·2⁴ + 1·2³ + 1·2² + 0·2 + 1 = 45`. Удобный ручной алгоритм читает цифры слева направо: умножить накопленный результат на основание и прибавить новую цифру.

```python
value = 0
for digit in "101101":
    value = value * 2 + int(digit)
```

После каждого шага `value` равен значению уже прочитанного префикса.

## Проверяем цифры и префиксы

В системе с основанием `base` допустимы цифры от 0 до `base - 1`. Для оснований выше 10 появляются буквы, поэтому учебную функцию проще сначала ограничить основаниями 2–9. `bin`, `oct`, `hex` возвращают строки с префиксами `0b`, `0o`, `0x`; при подсчёте цифр учитывайте префикс или используйте срез `[2:]`.

Для перевода из десятичной системы сохраняйте исходное число, если оно понадобится: цикл деления доведёт рабочую копию до нуля.

### Задача 1. Из двоичной записи

#### Условие

Введите непустую корректную двоичную запись неотрицательного числа без префикса 0b. Выведите десятичное значение.

#### Как рассуждать

Основание определяет вес цифр. Python умеет читать позиционную запись через int с явным основанием. Сам текст не нужно заранее превращать в десятичное целое: это уничтожило бы смысл исходного основания.

#### Алгоритм

1. Прочитайте строку.
2. Передайте строку и основание 2 в int.
3. Выведите число.

#### Решение

```python
text = input()
number = int(text, 2)
print(number)
```

#### Разбор решения

Второй аргумент 2 задаёт двоичную систему, а не количество знаков. Ведущие нули допустимы и не меняют значение. Цифры кроме 0 и 1 исключены условием.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 10110 | обычный случай | 22 |
| 0 | ноль | 0 |
| 001 | ведущие нули | 1 |

**Ответ:** для первого теста — 22.

### Задача 2. Перевод в основание от 2 до 9

#### Условие

Введите целое number ≥ 0 и основание base от 2 до 9. Выведите запись числа в этом основании без префикса.

#### Как рассуждать

Последовательные остатки дают цифры от младшей к старшей. Каждую цифру добавляем в начало результата. Для нуля цикл деления пуст, поэтому его запись зададим отдельно.

#### Алгоритм

1. Проверьте исходный ноль.
2. Иначе берите остаток от деления на base и добавляйте слева.
3. Делите рабочее число на base нацело до нуля.
4. Выведите запись.

#### Решение

```python
number = int(input())
base = int(input())
result = ""
if number == 0:
    result = "0"
while number > 0:
    result = str(number % base) + result
    number //= base
print(result)
```

#### Разбор решения

При основаниях до 9 каждый остаток превращается в одну обычную цифру через str. Если добавлять справа, получится обратная запись. Рабочая переменная number разрушается; если исходное значение понадобится, его следует сохранить.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 25; 2 | обычный случай | 11001 |
| 0; 3 | особый ноль | 0 |
| 8; 3 | другое основание | 22 |
| 9; 9 | переход в следующий разряд | 10 |

**Ответ:** для первого теста — 11001.

### Задача 3. Цифры выражения в системе счисления

#### Условие

Вычислите 3⁵ + 2·3³ + 1. Найдите число цифр 0 в троичной записи результата. Выведите количество. Дополнительно проверьте сам алгоритм для чисел 0 и 9.

#### Как рассуждать

Большое выражение сначала вычисляется как целое число. Затем каждый остаток от деления на 3 — очередная троичная цифра. Строить всю строку не обязательно: достаточно считать нулевые остатки. Запись самого нуля состоит из одной нулевой цифры.

#### Алгоритм

1. Вычислите выражение.
2. Для нуля задайте счётчик 1.
3. Для положительного числа переберите остатки при делении на 3.
4. Посчитайте нулевые цифры.

#### Решение

```python
number = 3 ** 5 + 2 * 3 ** 3 + 1
count = 0
if number == 0:
    count = 1
while number > 0:
    if number % 3 == 0:
        count += 1
    number //= 3
print(count)
```

#### Разбор решения

Выражение имеет троичную запись `102001`, в ней три нуля. Остаток `% 3` проверяется до уменьшения числа. После последней старшей цифры цикл завершается: бесконечные ведущие нули не считаются.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3⁵ + 2·3³ + 1 | обычный случай | 3 |
| 0 | запись нуля | 1 |
| 9 = 100₃ | несколько младших нулей | 2 |

**Ответ:** для первого теста — 3.
