Число `d` — делитель `number`, если `number % d == 0`.

!!! abstract "Фокус"
    - **Нужно уметь:** перебрать делители сначала полностью, затем до квадратного корня.

```python
divisors = []
for d in range(1, number + 1):
    if number % d == 0:
        divisors.append(d)
```

Делители образуют пары: если `d` делит число, второй равен `number // d`. Поэтому достаточно идти, пока `d * d <= number`:

```python
divisors = []
d = 1
while d * d <= number:
    if number % d == 0:
        divisors.append(d)
        if d != number // d:
            divisors.append(number // d)
    d += 1
divisors.sort()
```

Проверка `!=` не добавляет квадратный корень дважды.

## Почему достаточно корня

Если `d` делит `number`, то существует парный делитель `number // d`. В каждой паре хотя бы один множитель не больше квадратного корня. Поэтому после проверки всех `d`, для которых `d * d <= number`, новых пар уже не появится.

Для 36 пары такие: `(1, 36)`, `(2, 18)`, `(3, 12)`, `(4, 9)`, `(6, 6)`. Последняя пара объясняет проверку от двойного добавления.

## Счётчики без списка

Если нужны количество или сумма делителей, хранить список необязательно. Для обычной пары прибавляйте два значения, для квадратного корня — одно. В задачах №25 часто требуется вывести только числа с заданным количеством делителей или несколько наибольших нетривиальных делителей.

Сначала реализуйте полный перебор до `number`, проверьте на малых значениях, затем оптимизируйте до корня. Так легче отделить математическую идею от ошибки в границе.

### Задача 1. Все делители числа

#### Условие

Введите натуральное n ≤ 10000. Выведите список его положительных делителей по возрастанию.

#### Как рассуждать

Кандидат d является делителем, когда остаток n % d равен нулю. Полный перебор от 1 до n не пропускает ни единицу, ни само число. При движении слева направо список сразу будет упорядочен.

#### Алгоритм

1. Создайте пустой список.
2. Переберите d от 1 до n включительно.
3. Добавьте делители и выведите список.

#### Решение

```python
n = int(input())
divisors = []
for d in range(1, n + 1):
    if n % d == 0:
        divisors.append(d)
print(divisors)
```

#### Разбор решения

Начинать с нуля нельзя: остаток от деления на 0 не определён. Граница n + 1 включает само n. Для единицы список состоит из одного элемента.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 12 | обычный случай | [1, 2, 3, 4, 6, 12] |
| 1 | минимальное натуральное | [1] |
| 7 | простое число | [1, 7] |

**Ответ:** для первого теста — [1, 2, 3, 4, 6, 12].

### Задача 2. Количество делителей без повторения корня

#### Условие

Введите натуральное n ≤ 10⁶. Найдите число его положительных делителей, перебирая кандидаты только до квадратного корня.

#### Как рассуждать

У найденного d есть парный делитель n // d. Обычно это два разных числа, но у полного квадрата пара в середине совпадает. Такой корень нужно посчитать один раз.

#### Алгоритм

1. Начните с d = 1.
2. Пока d*d ≤ n, проверяйте делимость.
3. При совпадении пары добавляйте 1, иначе 2.
4. Выведите счётчик.

#### Решение

```python
n = int(input())
count = 0
d = 1
while d * d <= n:
    if n % d == 0:
        if d == n // d:
            count += 1
        else:
            count += 2
    d += 1
print(count)
```

#### Разбор решения

Условие с `<=` включает корень. Для 36 пары 1–36, 2–18, 3–12, 4–9 дают восемь делителей, а 6–6 добавляет один: всего 9. Список создавать не нужно, ведь требуется только количество.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 36 | полный квадрат | 9 |
| 12 | все пары различны | 6 |
| 1 | корень совпадает с единственным делителем | 1 |

**Ответ:** для первого теста — 9.

### Задача 3. Ровно два нетривиальных делителя

#### Условие

На отрезке от 10 до 20 включительно найдите числа с ровно двумя положительными делителями, не считая 1 и самого числа. Для каждого выведите число и его два делителя по возрастанию.

#### Как рассуждать

Для маленького диапазона надёжнее полный перебор. Список нетривиальных делителей собираем заново для каждого числа. Условие «ровно два» проверяем после завершения внутреннего цикла, когда известны все делители.

#### Алгоритм

1. Переберите числа диапазона.
2. Для каждого проверьте кандидаты от 2 до числа - 1.
3. При длине списка 2 выведите число и делители.

#### Решение

```python
left = 10
right = 20
for number in range(left, right + 1):
    divisors = []
    for d in range(2, number):
        if number % d == 0:
            divisors.append(d)
    if len(divisors) == 2:
        print(number, divisors[0], divisors[1])
```

#### Разбор решения

Полный перебор здесь допустим из-за малого учебного отрезка. Для больших чисел применяют парный перебор до корня из второй задачи. Нет смысла останавливаться сразу после второго делителя: позже может появиться третий, и число окажется неподходящим.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [10;20] | обычный случай | 10 2 5<br>14 2 7<br>15 3 5 |
| [8;9] | куб и квадрат | 8 2 4 |
| [11;13] | подходящих нет | нет строк вывода |

**Ответ:** для первого теста — 10 2 5; 14 2 7; 15 3 5.
