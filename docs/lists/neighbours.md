# Соседние элементы, пары и тройки
<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>

У списка длины `n` есть `n-1` соседняя пара и `n-2` тройки.
!!! abstract "Фокус"
    - **Нужно уметь:** выбрать безопасные границы индексов.
```python
maximum = None
for i in range(len(numbers) - 1):
    a, b = numbers[i], numbers[i + 1]
    if a % 2 == 0 or b % 2 == 0:
        pair_sum = a + b
        if maximum is None or pair_sum > maximum:
            maximum = pair_sum
```
Для троек используйте `range(len(numbers)-2)` и элементы `i`, `i+1`, `i+2`. `or` означает «хотя бы один», `and` — «оба».

## Выводим границу, а не запоминаем

Если фрагмент содержит `k` элементов, его начальная позиция может доходить до `len(numbers) - k`. Поэтому диапазон начал — `range(len(numbers) - k + 1)`. Для пары получается `range(n - 1)`, для тройки — `range(n - 2)`.

На каждом шаге полезно разделять две проверки: подходит ли пара и как она влияет на ответ. Сначала вычислите признаки элементов, затем условие, затем обновите счётчик или экстремум.

```python
count = 0
for i in range(len(numbers) - 1):
    left = numbers[i]
    right = numbers[i + 1]
    if left * right < 0:
        count += 1
```

Произведение отрицательно только для разных знаков, если нули не считаются ни положительными, ни отрицательными.

## Особые случаи

В списке из одного элемента нет пар, а из двух — ровно одна. Если ни одна пара не подходит, `maximum` останется `None`; вывод для такого случая должен быть указан в условии задачи. В задачах ЕГЭ внимательно различайте «хотя бы один», «ровно один» и «оба» элемента пары.
## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

Если данные заданы прямо в коде, для дополнительных тестов заменяйте начальные значения на данные из таблицы.

### Задача 1. Перемена знака

#### Условие

Для списка `numbers = [-2, 3, 0, -4, 5]` посчитайте соседние пары с разными знаками. Ноль не является ни положительным, ни отрицательным.

#### Как рассуждать

Произведение двух чисел отрицательно ровно при разных ненулевых знаках. Поэтому одна проверка заменяет два симметричных случая. Проверяем соседей, а не все возможные пары.

#### Алгоритм

1. Переберите начала пар.
2. Проверьте знак произведения соседей.
3. Посчитайте отрицательные произведения.

#### Решение

```python
numbers = [-2, 3, 0, -4, 5]
count = 0
for i in range(len(numbers) - 1):
    if numbers[i] * numbers[i + 1] < 0:
        count += 1
print(count)
```

#### Разбор решения

Нулевая пара даёт произведение 0 и не проходит строгое `< 0`. Граница `len - 1` оставляет место для второго элемента. У одного числа и у пустого списка соседних пар нет.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [-2, 3, 0, -4, 5] | обычный случай | 2 |
| [0, -1] | ноль исключён | 0 |
| [5] | пар нет | 0 |

**Ответ:** для первого теста — 2.

### Задача 2. Возрастающие тройки

#### Условие

Для списка `numbers = [1, 2, 3, 2, 4, 6]` посчитайте соседние тройки со строгим возрастанием. Пересекающиеся тройки допустимы.

#### Как рассуждать

Тройку определяют начальный индекс и ещё две позиции. Нужно, чтобы первое число было меньше второго, а второе меньше третьего. Равенство разрывает строгое возрастание.

#### Алгоритм

1. Переберите начала троек до len - 3 включительно.
2. Проверьте цепочку двух сравнений.
3. Выведите число подходящих троек.

#### Решение

```python
numbers = [1, 2, 3, 2, 4, 6]
count = 0
for i in range(len(numbers) - 2):
    if numbers[i] < numbers[i + 1] < numbers[i + 2]:
        count += 1
print(count)
```

#### Разбор решения

`range(len - 2)` допускает обращение к `i + 2`. Для списка `[1, 2, 3, 4]` подходят две пересекающиеся тройки. Список длины два не имеет ни одной.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [1, 2, 3, 2, 4, 6] | обычный случай | 2 |
| [1, 2, 3, 4] | пересечение | 2 |
| [1, 1, 2] | строгое сравнение | 0 |
| [1, 2] | слишком коротко | 0 |

**Ответ:** для первого теста — 2.

### Задача 3. Отбор пар и максимум суммы

#### Условие

В списке `numbers = [5, 2, 7, 10, -5]` посчитайте соседние пары, в которых хотя бы один элемент кратен 5. Также найдите наибольшую сумму такой пары. Выведите количество и максимум; если пар нет — `0 нет пар`.

#### Как рассуждать

Сначала определим, подходит ли пара, затем обновим два показателя. Максимум нельзя начинать с нуля: все подходящие суммы могут быть отрицательными. Значение None позволит отличить отсутствие ответа от настоящего числа.

#### Алгоритм

1. Переберите соседние пары.
2. Объедините проверки делимости через or.
3. Для подходящих пар увеличьте количество и обновите максимум суммы.
4. Обработайте отсутствие ответа.

#### Решение

```python
numbers = [5, 2, 7, 10, -5]
count = 0
maximum = None
for i in range(len(numbers) - 1):
    a = numbers[i]
    b = numbers[i + 1]
    if a % 5 == 0 or b % 5 == 0:
        count += 1
        pair_sum = a + b
        if maximum is None or pair_sum > maximum:
            maximum = pair_sum
if maximum is None:
    print(0, "нет пар")
else:
    print(count, maximum)
```

#### Разбор решения

`or` означает «хотя бы один», поэтому пара с двумя кратными тоже считается один раз. Сумма вычисляется только после отбора. Для первого подходящего результата None заменяется любой суммой, в том числе отрицательной.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [5, 2, 7, 10, -5] | обычный случай | 3 17 |
| [-10, -5] | максимум отрицательный | 1 -15 |
| [1, 2, 3] | отбор пуст | 0 нет пар |
| [] | пустой список | 0 нет пар |

**Ответ:** для первого теста — 3 17.
