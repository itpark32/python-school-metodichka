# Соседние элементы, пары и тройки
<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>
<div class="tags"><span class="tag">9–11 класс</span><span class="tag tag--ege">ЕГЭ</span></div>
У списка длины `n` есть `n-1` соседняя пара и `n-2` тройки.
!!! abstract "Фокус"
    - **Нужно уметь:** выбрать безопасные границы индексов.
```python
maximum = None
for i in range(len(numbers) - 1):
    a, b = numbers[i], numbers[i + 1]
    if a % 2 == 0 or b % 2 == 0:
        pair_sum = a + b
        if maximum is None or pair_sum > maximum:
            maximum = pair_sum
```
Для троек используйте `range(len(numbers)-2)` и элементы `i`, `i+1`, `i+2`. `or` означает «хотя бы один», `and` — «оба».

## Выводим границу, а не запоминаем

Если фрагмент содержит `k` элементов, его начальная позиция может доходить до `len(numbers) - k`. Поэтому диапазон начал — `range(len(numbers) - k + 1)`. Для пары получается `range(n - 1)`, для тройки — `range(n - 2)`.

На каждом шаге полезно разделять две проверки: подходит ли пара и как она влияет на ответ. Сначала вычислите признаки элементов, затем условие, затем обновите счётчик или экстремум.

```python
count = 0
for i in range(len(numbers) - 1):
    left = numbers[i]
    right = numbers[i + 1]
    if left * right < 0:
        count += 1
```

Произведение отрицательно только для разных знаков, если нули не считаются ни положительными, ни отрицательными.

## Особые случаи

В списке из одного элемента нет пар, а из двух — ровно одна. Если ни одна пара не подходит, `maximum` останется `None`; вывод для такого случая должен быть указан в условии задачи. В задачах ЕГЭ внимательно различайте «хотя бы один», «ровно один» и «оба» элемента пары.
## Мини-практика
1. Посчитайте пары разных знаков. 2. Найдите максимум суммы пары. 3. Посчитайте возрастающие тройки. 4. Найдите пары с ровно одним чётным. 5. Найдите минимальное произведение подходящей пары. 6. Посчитайте четвёрки с суммой больше 100.
