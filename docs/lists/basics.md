# Списки и индексы

<div class="tags"><span class="tag">9 класс</span><span class="tag tag--oge">ОГЭ</span><span class="tag tag--ege">ЕГЭ</span></div>

Отдельная переменная удобна для одного значения. Но если нужно хранить оценки всего класса, температуры за неделю или результаты соревнования, десятки переменных быстро становятся неудобными. Список объединяет несколько значений и позволяет обращаться к каждому по его позиции.

!!! abstract "Фокус"
    - **Нужно знать:** как создать список, получить его длину и обратиться к элементу по индексу.
    - **Нужно уметь:** добавлять, заменять и удалять элементы, отличать индекс от значения.
    - **Полезно знать:** отрицательные индексы отсчитывают элементы с конца списка.

## 1. Создание списка

Элементы списка записывают в квадратных скобках через запятую.

```python
scores = [5, 4, 3, 5]
temperatures = [-3, 0, 2, 1, -1]
students = ["Анна", "Борис", "Вика"]
```

Обычно в одном списке хранят данные одного смысла: только оценки, только температуры или только имена. Python позволяет смешивать типы, но начинающему программисту такой список сложнее правильно обработать.

Пустой список создают так:

```python
results = []
```

Сейчас в нём нет элементов, но позже их можно добавить. Количество элементов возвращает функция `len`.

```python
scores = [5, 4, 3, 5]
print(len(scores))  # 4
```

## 2. Индекс — это позиция элемента

У каждого элемента есть порядковый номер, который называется индексом. В Python индексация начинается с нуля.

| Индекс | `0` | `1` | `2` | `3` |
|---|---:|---:|---:|---:|
| Значение | `5` | `4` | `3` | `5` |

```python
scores = [5, 4, 3, 5]

print(scores[0])  # первый элемент: 5
print(scores[2])  # третий элемент: 3
```

Важно не путать человеческий номер и индекс. Второй элемент имеет индекс `1`, а четвёртый — индекс `3`.

Индекс последнего элемента на единицу меньше длины списка:

```python
last_index = len(scores) - 1
print(scores[last_index])
```

В Python последний элемент также можно получить индексом `-1`, предпоследний — индексом `-2`.

```python
print(scores[-1])  # 5
print(scores[-2])  # 3
```

!!! warning "У пустого списка нет первого элемента"
    Обращение к `results[0]` допустимо только тогда, когда в списке уже есть хотя бы один элемент.

## 3. Список можно изменять

Строку нельзя изменить по одному символу, а элемент списка заменить можно.

```python
scores = [5, 4, 3]
scores[1] = 5
print(scores)  # [5, 5, 3]
```

Слева от `=` указано место, куда записывается новое значение. Длина списка не изменилась: второй элемент был заменён.

Проследим несколько команд подряд.

```python
numbers = [10, 20, 30]
numbers[0] = 15
numbers.append(40)
numbers.pop(1)
print(numbers)
```

| После команды | Список |
|---|---|
| создание | `[10, 20, 30]` |
| `numbers[0] = 15` | `[15, 20, 30]` |
| `numbers.append(40)` | `[15, 20, 30, 40]` |
| `numbers.pop(1)` | `[15, 30, 40]` |

Ответ программы: `[15, 30, 40]`.

## 4. Добавление элементов

Метод `append` добавляет один элемент в конец.

```python
guests = []
guests.append("Анна")
guests.append("Борис")
print(guests)  # ['Анна', 'Борис']
```

Метод `insert` вставляет элемент перед указанным индексом.

```python
guests.insert(1, "Вика")
print(guests)  # ['Анна', 'Вика', 'Борис']
```

В `insert(1, "Вика")` число `1` — позиция, а строка `"Вика"` — новое значение. Остальные элементы сдвигаются вправо.

## 5. Удаление: по индексу или по значению

Методы `pop` и `remove` решают разные задачи.

| Метод | Что указываем | Что происходит |
|---|---|---|
| `pop(index)` | индекс | удаляет и возвращает элемент на этой позиции |
| `pop()` | ничего | удаляет и возвращает последний элемент |
| `remove(value)` | значение | удаляет первое совпадающее значение |

```python
scores = [5, 4, 3, 5]

deleted = scores.pop(1)
print(deleted)  # 4
print(scores)   # [5, 3, 5]
```

`pop(1)` удалил элемент с индексом `1`. Метод не ищет значение `1`.

```python
scores.remove(5)
print(scores)  # [3, 5]
```

В списке было две пятёрки, но `remove(5)` удалил только первую найденную.

## 6. Значение и индекс

Представьте список городов:

```python
cities = ["Брянск", "Орёл", "Курск"]
```

- `cities[1]` — значение `"Орёл"`;
- `1` — индекс этого значения;
- `len(cities)` — количество элементов, равное `3`;
- индекс `3` уже находится за границей списка, последний допустимый индекс равен `2`.

Эта разница особенно важна в задачах поиска. Вопрос «какой город записан вторым?» требует значение. Вопрос «на какой позиции находится Орёл?» требует индекс.

## 7. Частые ошибки

### Индекс за границами списка

```python
numbers = [10, 20, 30]
print(numbers[3])  # IndexError
```

Допустимые индексы здесь: `0`, `1`, `2`. Перед обращением по вычисленному индексу убедитесь, что он меньше `len(numbers)`.

### Перепутаны `pop` и `remove`

```python
numbers = [10, 20, 30]
numbers.remove(1)  # ошибка: значения 1 в списке нет
```

Чтобы удалить второй элемент, нужен `numbers.pop(1)`. Чтобы удалить значение `20`, нужен `numbers.remove(20)`.

### Ожидание нового списка от `append`

```python
numbers = [1, 2]
result = numbers.append(3)
print(result)  # None
```

`append` меняет существующий список и ничего полезного не возвращает. После команды нужно смотреть на `numbers`, а не на `result`.

### Изменение несуществующего элемента

В пустой список нельзя записать `numbers[0] = 10`: позиции `0` ещё нет. Первый элемент добавляют командой `numbers.append(10)`.

## 8. Мини-практика

1. **Расписание.** Создайте список из пяти названий уроков. Выведите первый и последний уроки.
2. **Исправление оценки.** Дан список `[5, 3, 4, 5]`. Замените тройку на четвёрку по индексу.
3. **Очередь.** Создайте список из трёх имён, добавьте нового человека в конец и ещё одного человека на вторую позицию.
4. **Удаление.** Из списка `[12, 7, 12, 9]` сначала удалите элемент с индексом `1`, затем первое значение `12`. Предскажите результат до запуска.
5. **Последние результаты.** Дан список баллов. Выведите два последних значения с помощью отрицательных индексов.
6. **Безопасное обращение.** Введите индекс и выведите элемент списка только тогда, когда индекс находится в допустимых границах.
