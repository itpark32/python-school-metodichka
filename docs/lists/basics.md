# Списки и индексы

Список — изменяемая последовательность значений.
!!! abstract "Фокус"
    - **Нужно знать:** индексы, `len`, `append`, `insert`, `pop`, `remove`.
    - **Нужно уметь:** отличать значение от позиции.
```python
scores = [5, 4, 3]
scores.append(5)
scores[1] = 5
last = scores.pop()
```
`remove(5)` удаляет первое значение 5, а `pop(1)` — элемент с индексом 1 и возвращает его. Пустой список создают как `[]`.
## Мини-практика
1. Добавьте три температуры. 2. Замените вторую. 3. Удалите последний элемент.
