# Перебор и обработка списка

По элементам перебирают для вычислений, по индексам — когда важна позиция или изменение.
!!! abstract "Фокус"
    - **Нужно уметь:** считать, суммировать и строить новый список обычным циклом.
```python
positive = []
for number in numbers:
    if number > 0:
        positive.append(number)

for i in range(len(numbers)):
    numbers[i] *= 2
```
Сумму, минимум и максимум сначала реализуйте накопителями. В обычном коде после этого допустимы `sum`, `min`, `max`.

## Три результата одного прохода

Цикл может считать значение, изменять исходный список или строить новый — важно не смешивать цели. `append` добавляет элемент в конец нового списка. Изменение `numbers[i]` меняет исходный список, и это должно быть намеренно.

```python
squares_of_even = []
for number in numbers:
    if number % 2 == 0:
        squares_of_even.append(number ** 2)
```

Порядок действий совпадает с условием: проверить, преобразовать, добавить. После каждого шага результат содержит квадраты всех подходящих уже просмотренных элементов.

Если удалять элементы из списка во время прямого перебора, позиции сдвигаются и часть данных может быть пропущена. Безопаснее построить новый список или перебрать копию.

## Выбираем вид цикла

Перебор по значениям нужен для суммы, фильтра и проверок. Индексы нужны для замены на месте и обращения к соседям. `enumerate(numbers)` даёт одновременно индекс и значение, когда нужны оба. Сначала напишите прозрачный цикл, затем при желании сократите его.
!!! info "Python+"
    `[x for x in numbers if x > 0]` — краткая запись, но она не заменяет понимание цикла.
## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

Если данные заданы прямо в коде, для дополнительных тестов заменяйте начальные значения на данные из таблицы.

### Задача 1. Квадраты значений

#### Условие

Для списка `numbers = [-2, 0, 3]` постройте новый список квадратов в исходном порядке. Исходный список не изменяйте.

#### Как рассуждать

Значения достаточно перебирать напрямую: их позиции не нужны. Каждый квадрат добавим в новый список. Для пустого набора новый список также останется пустым.

#### Алгоритм

1. Создайте пустой список результата.
2. Для каждого числа вычислите квадрат и добавьте его.
3. Выведите результат и исходный список.

#### Решение

```python
numbers = [-2, 0, 3]
squares = []
for number in numbers:
    squares.append(number * number)
print(squares)
print(numbers)
```

#### Разбор решения

`append` вызывается у нового списка, поэтому исходный не меняется. Отрицательное число даёт неотрицательный квадрат. Порядок добавления совпадает с порядком чтения.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [-2, 0, 3] | обычный случай | [4, 0, 9]<br>[-2, 0, 3] |
| [] | пустой набор | []<br>[] |

**Ответ:** для первого теста — [4, 0, 9]; [-2, 0, 3].

### Задача 2. Исправление отрицательных

#### Условие

В списке `numbers = [4, -2, -7, 0]` замените все отрицательные значения нулями. Длину и порядок остальных значений сохраните.

#### Как рассуждать

Теперь нужно менять исходные элементы, поэтому перебираем индексы. Простое изменение переменной цикла number не заменило бы элемент списка. Удалять элементы тоже нельзя: позиции должны остаться.

#### Алгоритм

1. Переберите индексы.
2. Проверьте значение на каждой позиции.
3. Замените отрицательное на ноль и выведите список.

#### Решение

```python
numbers = [4, -2, -7, 0]
for i in range(len(numbers)):
    if numbers[i] < 0:
        numbers[i] = 0
print(numbers)
```

#### Разбор решения

Присваивание идёт в `numbers[i]`, то есть в сам список. Нулевые и положительные значения проходят без изменения. Изменяется содержимое, но не размер, поэтому границы range остаются верными.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [4, -2, -7, 0] | обычный случай | [4, 0, 0, 0] |
| [-1] | первый и последний — один элемент | [0] |
| [] | пустой список | [] |

**Ответ:** для первого теста — [4, 0, 0, 0].

### Задача 3. Выше среднего

#### Условие

Для непустого списка `numbers = [2, 8, 5, 9]` найдите среднее всех значений, затем создайте список элементов строго выше среднего, сохранив порядок. Выведите новый список.

#### Как рассуждать

Среднее зависит от всего набора, поэтому сначала завершим суммирование, а затем сделаем второй проход для отбора. Один проход с меняющимся средним решал бы другую задачу.

#### Алгоритм

1. Найдите сумму и разделите на длину.
2. Создайте пустой результат.
3. Добавьте элементы строго выше найденного среднего.

#### Решение

```python
numbers = [2, 8, 5, 9]
total = 0
for number in numbers:
    total += number
average = total / len(numbers)
result = []
for number in numbers:
    if number > average:
        result.append(number)
print(result)
```

#### Разбор решения

Для исходных данных среднее равно 6, поэтому остаются 8 и 9. Условие строгое: равные среднему не входят. Непустота задана в условии и защищает деление на длину.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [2, 8, 5, 9] | обычный случай | [8, 9] |
| [4, 4] | ни одного выше среднего | [] |
| [-8, -2] | отрицательные значения | [-2] |

**Ответ:** для первого теста — [8, 9].
