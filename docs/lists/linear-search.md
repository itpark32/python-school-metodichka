# Линейный поиск
<p class="reading-time">Чтение: 6 минут · Практика: 15 минут</p>

Линейный поиск проверяет элементы по порядку и работает даже без сортировки.
!!! abstract "Фокус"
    - **Нужно знать:** флаг, индекс `-1`, досрочный `break`.
```python
target = 7
position = -1
for i in range(len(numbers)):
    if numbers[i] == target:
        position = i
        break
print(position)
```
`-1` означает «не найдено». Без `break` можно собрать все позиции. После ручного алгоритма: `target in numbers`; `.index(target)` требует заранее знать, что значение существует.
## Мини-практика
1. Найдите первое отрицательное. 2. Соберите все индексы нулей. 3. Проверьте наличие оценки 2.
## Проверьте себя
Зачем `break`? Что означает `-1`? Нужна ли сортировка?
