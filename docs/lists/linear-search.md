# Линейный поиск
<p class="reading-time">Чтение: 12–15 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag">9–11 класс</span><span class="tag tag--ege">ЕГЭ</span></div>
Линейный поиск проверяет элементы по порядку и работает даже без сортировки.
!!! abstract "Фокус"
    - **Нужно знать:** флаг, индекс `-1`, досрочный `break`.
```python
target = 7
position = -1
for i in range(len(numbers)):
    if numbers[i] == target:
        position = i
        break
print(position)
```
`-1` означает «не найдено». Без `break` можно собрать все позиции. После ручного алгоритма: `target in numbers`; `.index(target)` требует заранее знать, что значение существует.

## Что именно требуется найти

До кода уточните результат: факт наличия, первый индекс, последний индекс, количество или все позиции. Для факта достаточно флага `found`; для первого индекса нужен `break`; для последнего перебор продолжают и обновляют позицию.

```python
positions = []
for i in range(len(numbers)):
    if numbers[i] == target:
        positions.append(i)
```

Этот вариант сохраняет все найденные позиции. Пустой список естественно означает отсутствие совпадений.

## Почему поиск линейный

В худшем случае проверяется каждый элемент: искомое значение находится в конце или отсутствует. Сортировка не нужна, поэтому метод надёжен для любого порядка. Если список уже отсортирован и запросов много, позже можно применить бинарный поиск.

Проверьте случаи: значение в начале, в конце, встречается несколько раз и отсутствует. Они показывают, правильно ли выбран `break` и значение «не найдено».
## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

Если данные заданы прямо в коде, для дополнительных тестов заменяйте начальные значения на данные из таблицы.

### Задача 1. Первый отрицательный

#### Условие

Для списка `numbers = [4, -2, -7]` найдите индекс первого отрицательного элемента. Если его нет, выведите -1.

#### Как рассуждать

Нужна первая позиция, поэтому после находки поиск можно остановить. До начала ответ равен -1, что означает отсутствие находки, а не обращение к последнему элементу.

#### Алгоритм

1. Начните с position = -1.
2. Перебирайте индексы до первого отрицательного.
3. Сохраните индекс, завершите цикл и выведите результат.

#### Решение

```python
numbers = [4, -2, -7]
position = -1
for i in range(len(numbers)):
    if numbers[i] < 0:
        position = i
        break
print(position)
```

#### Разбор решения

Без `break` ответ менялся бы на каждый новый отрицательный индекс и стал бы последним. Для пустого списка цикл не выполняется, поэтому -1 остаётся корректным признаком отсутствия.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [4, -2, -7] | обычный случай | 1 |
| [-3] | находка в начале | 0 |
| [] | ничего не найдено | -1 |

**Ответ:** для первого теста — 1.

### Задача 2. Все позиции нулей

#### Условие

Дан список `numbers = [0, 5, 0, 0]`. Соберите индексы всех нулевых элементов в новый список и выведите его.

#### Как рассуждать

Каждый ноль представляет отдельную находку. Останавливаться на первом нельзя. Индексы будем добавлять в порядке обхода, поэтому результат сразу получится возрастающим.

#### Алгоритм

1. Создайте пустой список позиций.
2. Переберите все индексы.
3. При нуле добавьте индекс и выведите список.

#### Решение

```python
numbers = [0, 5, 0, 0]
positions = []
for i in range(len(numbers)):
    if numbers[i] == 0:
        positions.append(i)
print(positions)
```

#### Разбор решения

Здесь сохраняем i, а не `numbers[i]`: иначе результат состоял бы только из нулей. Пустой список позиций естественно означает отсутствие совпадений.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [0, 5, 0, 0] | находки на обоих краях | [0, 2, 3] |
| [1, 2] | нулей нет | [] |
| [] | пустой исходный список | [] |

**Ответ:** для первого теста — [0, 2, 3].

### Задача 3. Последний индекс максимума

#### Условие

Для непустого списка `numbers = [7, 2, 7, 1]` найдите индекс последнего вхождения наибольшего значения.

#### Как рассуждать

Нужно одновременно искать лучшее значение и соблюдать правило равенства. Более крупное число заменяет максимум; равное тоже обновляет позицию, ведь более поздний индекс предпочтительнее.

#### Алгоритм

1. Возьмите первый элемент как максимум, индекс 0 как ответ.
2. Переберите остальные позиции.
3. При значении не меньше максимума обновите оба результата.
4. Выведите индекс.

#### Решение

```python
numbers = [7, 2, 7, 1]
maximum = numbers[0]
position = 0
for i in range(1, len(numbers)):
    if numbers[i] >= maximum:
        maximum = numbers[i]
        position = i
print(position)
```

#### Разбор решения

Знак `>=` реализует требование «последний». С `>` сохранялось бы первое вхождение. `break` использовать нельзя: в конце может оказаться значение ещё больше или равный максимум.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [7, 2, 7, 1] | обычный случай | 2 |
| [-5, -2, -2] | отрицательный максимум в конце | 2 |
| [9] | один элемент | 0 |

**Ответ:** для первого теста — 2.
