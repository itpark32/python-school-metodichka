# Классы и объекты

<p class="reading-time">Чтение: 10–12 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag">10–11 класс</span><span class="tag tag--plus">Python+</span></div>

Класс описывает общий вид объектов, объект хранит конкретные значения. Атрибут — данные объекта, метод — действие.

!!! abstract "Фокус"
    - **Нужно знать:** класс, объект, `self`, `__init__`.

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def is_passed(self):
        return self.score >= 60

masha = Student("Маша", 78)
print(masha.is_passed())
```

`__init__` настраивает новый объект. `self` — тот объект, у которого вызван метод. У Маши и Пети свои значения `name` и `score`.

## Данные и поведение вместе

Класс полезен, когда несколько значений описывают одну сущность и над ними выполняются связанные действия. Вместо параллельных списков имён и баллов создаётся список объектов `Student`: так меньше риска перепутать позиции.

Метод вызывается как `masha.is_passed()`, а Python передаёт `masha` параметром `self`. Атрибут `self.score` принадлежит конкретному объекту; локальная переменная `score` без `self` исчезнет после выполнения метода.

```python
petya = Student("Петя", 55)
petya.score += 10
print(petya.is_passed())
```

Изменение Пети не влияет на Машу. Для одной короткой вычислительной задачи функции и коллекции понятнее; класс оправдан, если модель сущности делает код яснее. Наследование на этом уровне не требуется.

### Задача 1. Книга как объект

#### Условие

Создайте класс Book с атрибутами title и pages. Создайте книгу "Алгоритмы" на 120 страниц и выведите название и число страниц через пробел.

#### Как рассуждать

Одна книга объединяет два связанных значения. Конструктор принимает данные конкретного экземпляра и сохраняет их в атрибутах self. Печать относится к основной программе, а не к созданию объекта.

#### Алгоритм

1. Опишите __init__ с двумя данными.
2. Сохраните поля через self.
3. Создайте объект и выведите его атрибуты.

#### Решение

```python
class Book:
    def __init__(self, title, pages):
        self.title = title
        self.pages = pages

book = Book("Алгоритмы", 120)
print(book.title, book.pages)
```

#### Разбор решения

`self.title` принадлежит экземпляру и остаётся доступным после завершения __init__. Обычная локальная переменная title без присваивания полю не сохранила бы атрибут. Каждый объект получает свои значения.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| Алгоритмы, 120 | обычный случай | Алгоритмы 120 |
| Черновик, 0 | нулевое число страниц | Черновик 0 |

**Ответ:** для первого теста — Алгоритмы 120.

### Задача 2. Остаток страниц

#### Условие

Опишите класс Reading с полями pages и read_pages. Метод read(count) увеличивает прочитанное, но не больше общего числа страниц. Метод remaining() возвращает остаток. Все количества неотрицательны. Создайте две книги на 10 страниц, прочитайте 7 страниц только первой и выведите остатки.

#### Как рассуждать

Прочитанные страницы — состояние конкретного объекта. Изменение первой книги не должно затронуть вторую. После прибавления ограничим поле общим количеством, чтобы остаток не стал отрицательным.

#### Алгоритм

1. В конструкторе задайте общее и нулевое прочитанное.
2. В read увеличьте поле и ограничьте сверху.
3. В remaining верните разность.
4. Проверьте два независимых экземпляра.

#### Решение

```python
class Reading:
    def __init__(self, pages):
        self.pages = pages
        self.read_pages = 0

    def read(self, count):
        self.read_pages += count
        if self.read_pages > self.pages:
            self.read_pages = self.pages

    def remaining(self):
        return self.pages - self.read_pages

first = Reading(10)
second = Reading(10)
first.read(7)
print(first.remaining(), second.remaining())
```

#### Разбор решения

Оба поля создаются в __init__ через self, а не общей переменной класса. Метод remaining возвращает число, чтобы его можно было использовать в вычислениях. Чтение 20 страниц при объёме 10 завершит книгу, но не создаст отрицательный остаток.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| у первой прочитано 7 из 10 | обычный случай | 3 10 |
| у первой запрошено 20 страниц | превышение общего числа | 0 10 |
| не прочитано ни страницы | нулевое действие | 10 10 |

**Ответ:** для первого теста — 3 10.

### Задача 3. Выбор лучшего участника

#### Условие

Создайте класс Participant с именем и баллом, а также метод passed(), возвращающий score ≥ 60. Из списка объектов выберите участника с наибольшим баллом среди прошедших. При равенстве оставьте первого в списке. Если прошедших нет, выведите `нет участников`.

#### Как рассуждать

Нужно сочетать поведение одного объекта с алгоритмом отбора коллекции. passed отвечает только за допуск, основной цикл — за выбор лучшего. Начальное None позволяет корректно описать отсутствие кандидата.

#### Алгоритм

1. Опишите класс и метод допуска.
2. Переберите список объектов.
3. Среди прошедших сохраните первый либо строго лучший балл.
4. Выведите имя и балл или сообщение.

#### Решение

```python
class Participant:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def passed(self):
        return self.score >= 60

participants = [Participant("Аня", 59), Participant("Борис", 80), Participant("Вера", 80)]
best = None
for participant in participants:
    if participant.passed():
        if best is None or participant.score > best.score:
            best = participant
if best is None:
    print("нет участников")
else:
    print(best.name, best.score)
```

#### Разбор решения

В best сохраняется объект целиком, поэтому имя и балл не расходятся. Строгое `>` оставляет первого при равенстве. Вызов `participant.passed()` передаёт текущий объект как self автоматически.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| Аня 59, Борис 80, Вера 80 | равенство лучших результатов | Борис 80 |
| только 60 баллов | граница допуска | Лев 60 |
| только 59 баллов | нет прошедших | нет участников |
| пустой список | нет объектов | нет участников |

**Ответ:** для первого теста — Борис 80.
