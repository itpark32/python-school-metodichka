# Модули и несколько файлов

<p class="reading-time">Чтение: 10–12 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag tag--plus">Python+</span></div>

Каждый `.py`-файл можно использовать как модуль. Разделяйте программу, когда функции образуют понятные группы.

!!! abstract "Фокус"
    - **Нужно знать:** `import module`, `from module import function`.
    - **Нужно уметь:** вызвать функцию из соседнего файла.

```text
project/
├── main.py
└── math_utils.py
```

```python
# math_utils.py
def is_even(number):
    return number % 2 == 0
```

```python
# main.py
from math_utils import is_even

number = int(input())
print(is_even(number))
```

При `import math_utils` вызов будет `math_utils.is_even(number)`, и происхождение функции видно сразу.

## Граница модуля

Модуль объединяет функции одной темы: работу с числами, чтение данных или форматирование. Не выносите каждую функцию в отдельный файл. Имя файла должно быть коротким и допустимым именем Python без пробелов и дефисов.

Импорт модуля целиком делает происхождение имён явным. Импорт конкретной функции короче в маленьком проекте. Запись `from module import *` скрывает источник имён и обычно не нужна.

При первом импорте Python выполняет верхнеуровневый код файла. Поэтому демонстрационные вызовы помещают под защиту точки запуска, а определения функций оставляют снаружи. Запускайте `main.py` из папки проекта; при `ModuleNotFoundError` проверьте имя файла и рабочую папку.

!!! info "Точка запуска"
    Код внутри `if __name__ == "__main__":` выполняется при прямом запуске файла, но не при импорте.

## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Функция из соседнего файла

#### Условие

Создайте units.py с функцией minutes_to_seconds(minutes), возвращающей число секунд. В main.py импортируйте функцию, считайте целое неотрицательное число минут и выведите результат. Оба файла положите в одну папку, запускайте main.py.

#### Как рассуждать

Модуль отвечает за одно преобразование величины, основная программа — за ввод и вывод. При импорте определение функции становится доступно по имени. В самом units.py читать данные не нужно.

#### Алгоритм

1. В units.py опишите функцию без input.
2. В main.py импортируйте её по имени.
3. Прочитайте минуты и выведите вызов функции.

#### Решение

Файл `units.py`:

```python
def minutes_to_seconds(minutes):
    return minutes * 60
```

Файл `main.py`:

```python
from units import minutes_to_seconds

minutes = int(input())
print(minutes_to_seconds(minutes))
```

#### Разбор решения

Имя модуля в from записывается без расширения .py. Вызов использует то же имя функции. Отсутствие верхнеуровневого ввода в модуле позволяет импортировать его без неожиданного ожидания клавиатуры.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| minutes = 3 | обычный случай | 180 |
| minutes = 0 | нулевая величина | 0 |
| minutes = 1 | одна единица | 60 |

**Ответ:** для первого теста — 180.

### Задача 2. Импорт без демонстрационного вывода

#### Условие

В numbers_tools.py опишите is_multiple(number, divisor). Она проверяет делимость, divisor > 0. Добавьте демонстрацию для 12 и 3, которая печатается только при прямом запуске этого модуля. В main.py импортируйте модуль целиком, прочитайте number и divisor с разных строк и выведите результат проверки.

#### Как рассуждать

Код верхнего уровня выполняется при первом импорте. Демонстрацию нужно спрятать под проверку __name__, иначе она добавит лишний вывод к основной программе. При импорте целиком происхождение функции видно в вызове.

#### Алгоритм

1. Опишите функцию в модуле.
2. Демонстрационный print поместите под точку запуска.
3. В main.py вызовите функцию через имя модуля.

#### Решение

Файл `numbers_tools.py`:

```python
def is_multiple(number, divisor):
    return number % divisor == 0

if __name__ == "__main__":
    print(is_multiple(12, 3))
```

Файл `main.py`:

```python
import numbers_tools

number = int(input())
divisor = int(input())
print(numbers_tools.is_multiple(number, divisor))
```

#### Разбор решения

При запуске main.py значение __name__ в импортированном файле не равно "__main__", поэтому демонстрация пропускается. Вывод содержит ровно один результат пользовательского вызова. При прямом запуске `python numbers_tools.py` получится True.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 12; 3 при запуске main.py | нет лишней демонстрационной строки | True |
| 10; 3 | обычный случай | False |
| 0; 5 | нулевое кратное | True |

**Ответ:** для первого теста — True.

### Задача 3. Модуль статистики оценок

#### Условие

В grades.py опишите summarize(scores), возвращающую среднее оценок и число пятёрок. Для пустого списка возвращайте None и 0. В main.py прочитайте n ≥ 0, затем n оценок от 2 до 5 с разных строк, выведите среднее и число пятёрок либо `нет оценок`.

#### Как рассуждать

Отделим вычислительный договор от формата ввода. Модуль не должен знать, откуда пришли оценки. Пустой набор выделяем до деления на длину. Возвращаем пару значений, чтобы основная программа сама выбрала формат вывода.

#### Алгоритм

1. В модуле подсчитайте сумму и пятёрки.
2. Верните пару или особый результат пустого списка.
3. В main.py соберите оценки и вызовите модуль.
4. Выведите ответ по договору.

#### Решение

Файл `grades.py`:

```python
def summarize(scores):
    if len(scores) == 0:
        return None, 0
    total = 0
    fives = 0
    for score in scores:
        total += score
        if score == 5:
            fives += 1
    return total / len(scores), fives
```

Файл `main.py`:

```python
from grades import summarize

n = int(input())
scores = []
for _ in range(n):
    scores.append(int(input()))
average, fives = summarize(scores)
if average is None:
    print("нет оценок")
else:
    print(average, fives)
```

#### Разбор решения

Возврат None сигнализирует отсутствие среднего, а не оценку 0. В grades.py нет input и print, поэтому функцию легко повторно использовать. Имена собственных модулей не совпадают с именами стандартной библиотеки.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3; 5; 4; 3 | обычный случай | 4.0 1 |
| 0 | пустой список | нет оценок |
| 2; 5; 5 | все оценки максимальные | 5.0 2 |

**Ответ:** для первого теста — 4.0 1.
