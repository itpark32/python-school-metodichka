# Исключения

<p class="reading-time">Чтение: 10–12 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag tag--plus">Python+</span></div>

Исключение сообщает, что во время выполнения возникла ситуация, которую код не смог обработать обычным путём.

!!! abstract "Фокус"
    - **Нужно знать:** `try`, `except` и конкретные типы ошибок.

```python
try:
    number = int(input("Введите целое число: "))
except ValueError:
    print("Нужно ввести именно целое число")
```

Ловите только ожидаемую ошибку возле опасной операции. `ZeroDivisionError` возникает при делении на ноль, `FileNotFoundError` — при отсутствии файла. Пустой `except:` скрывает в том числе ошибки самого программиста и затрудняет отладку.

## Узкая зона ответственности

В `try` помещают минимальный код, который действительно может дать ожидаемую ошибку. Тогда `except ValueError` означает именно неверное преобразование.

```python
while True:
    try:
        age = int(input("Возраст: "))
    except ValueError:
        print("Введите число")
        continue
    break
```

После успешного преобразования цикл завершается. Проверка диапазона возраста — обычное условие, а не исключение.

Блок `else` выполняется, если исключения не было; `finally` — в любом случае. При работе с файлами `with` обычно лучше ручного закрытия в `finally`. Не используйте исключения вместо простой ожидаемой проверки вроде `if divisor != 0`.

## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Одно безопасное преобразование

#### Условие

Введите строку. Если её можно преобразовать в целое число, выведите удвоенное значение; иначе `нужно целое число`. Повторять ввод не нужно.

#### Как рассуждать

Ошибка может возникнуть именно в int, а не в обычном удвоении. Поместим преобразование в короткий try и обработаем ожидаемый ValueError. Вычисление выполним в else, когда преобразование успешно.

#### Алгоритм

1. Попробуйте преобразовать ввод.
2. При ValueError выведите сообщение.
3. При успехе выведите удвоение.

#### Решение

```python
text = input()
try:
    number = int(text)
except ValueError:
    print("нужно целое число")
else:
    print(number * 2)
```

#### Разбор решения

Конкретный except не скрывает другие ошибки программы. Строка "3.5" не является корректным целым вводом и тоже попадёт в обработчик. Отрицательное целое преобразуется успешно.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 12 | обычный случай | 24 |
| три | текст вместо числа | нужно целое число |
| 3.5 | дробная запись | нужно целое число |
| -2 | допустимое отрицательное | -4 |

**Ответ:** для первого теста — 24.

### Задача 2. Отсутствующий файл

#### Условие

Прочитайте весь файл note.txt в UTF-8 и выведите число символов, включая пробелы и переводы строк. Если файла нет, выведите `файл не найден`. Другие ошибки не скрывайте.

#### Как рассуждать

Отсутствие файла — ожидаемая ситуация, поэтому обработаем FileNotFoundError возле открытия. Пустой существующий файл отличается от отсутствующего: его длина равна нулю, и это успешный результат.

#### Алгоритм

1. Попробуйте открыть и прочитать файл через with.
2. Обработайте только FileNotFoundError.
3. При успехе выведите длину текста.

#### Решение

```python
try:
    with open("note.txt", encoding="utf-8") as file:
        text = file.read()
except FileNotFoundError:
    print("файл не найден")
else:
    print(len(text))
```

#### Разбор решения

with закроет успешно открытый файл. Ошибку доступа или кодировки не подменяем сообщением об отсутствии. `len` считается по символам строки, а не по байтам файла.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| note.txt: кот и перевод строки | обычный случай | 4 |
| пустой note.txt | файл есть, символов нет | 0 |
| note.txt отсутствует | ожидаемая ошибка открытия | файл не найден |

**Ответ:** для первого теста — 4.

### Задача 3. Ввод балла до успеха

#### Условие

Запрашивайте строки, пока не будет введено целое число от 0 до 100 включительно. Для нечислового ввода выводите `нужно число`, для целого вне диапазона — `вне диапазона`. При успехе выведите `принято` и число. В тестах корректное значение обязательно появится.

#### Как рассуждать

Преобразование и проверка диапазона — разные этапы. ValueError относится к неверной записи числа; значение 101 успешно преобразуется, но не проходит обычное условие. После каждой ошибки нужно продолжить цикл, не используя старый или отсутствующий score.

#### Алгоритм

1. В цикле прочитайте и преобразуйте строку.
2. При ошибке преобразования сообщите и продолжите.
3. Отдельно проверьте допустимый диапазон.
4. При успехе выведите число и завершите цикл.

#### Решение

```python
while True:
    text = input()
    try:
        score = int(text)
    except ValueError:
        print("нужно число")
        continue
    if score < 0 or score > 100:
        print("вне диапазона")
        continue
    print("принято", score)
    break
```

#### Разбор решения

В try находится только операция, которая может дать ожидаемый ValueError. Первый continue не допускает перехода к проверке неопределённого score. Второй отделяет неверное значение от ошибки выполнения. Обе границы допускаются.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| abc; 101; 60 | обычный случай | нужно число<br>вне диапазона<br>принято 60 |
| 0 | нижняя граница | принято 0 |
| -1; 100 | ошибка диапазона и верхняя граница | вне диапазона<br>принято 100 |

**Ответ:** для первого теста — нужно число; вне диапазона; принято 60.
