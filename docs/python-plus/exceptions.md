# Исключения

<p class="reading-time">Чтение: 10–12 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag tag--plus">Python+</span></div>

Исключение сообщает, что во время выполнения возникла ситуация, которую код не смог обработать обычным путём.

!!! abstract "Фокус"
    - **Нужно знать:** `try`, `except` и конкретные типы ошибок.

```python
try:
    number = int(input("Введите целое число: "))
except ValueError:
    print("Нужно ввести именно целое число")
```

Ловите только ожидаемую ошибку возле опасной операции. `ZeroDivisionError` возникает при делении на ноль, `FileNotFoundError` — при отсутствии файла. Пустой `except:` скрывает в том числе ошибки самого программиста и затрудняет отладку.

## Узкая зона ответственности

В `try` помещают минимальный код, который действительно может дать ожидаемую ошибку. Тогда `except ValueError` означает именно неверное преобразование.

```python
while True:
    try:
        age = int(input("Возраст: "))
    except ValueError:
        print("Введите число")
        continue
    break
```

После успешного преобразования цикл завершается. Проверка диапазона возраста — обычное условие, а не исключение.

Блок `else` выполняется, если исключения не было; `finally` — в любом случае. При работе с файлами `with` обычно лучше ручного закрытия в `finally`. Не используйте исключения вместо простой ожидаемой проверки вроде `if divisor != 0`.

## Мини-практика

1. Обработайте неверный ввод. 2. Обработайте деление на ноль. 3. Сообщите об отсутствующем файле.
4. Повторяйте ввод до целого числа. 5. Отделите проверку диапазона от `try`. 6. Объясните, какие ошибки нельзя скрывать общим `except`.
