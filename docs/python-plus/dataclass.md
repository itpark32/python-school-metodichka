# `dataclass`

<p class="reading-time">Чтение: 10–12 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag tag--plus">Python+</span></div>

`dataclass` сокращает служебный код класса, основная роль которого — хранить данные.

!!! abstract "Фокус"
    - **Нужно знать:** декоратор `@dataclass` и аннотации полей.

```python
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    score: int

masha = Student("Маша", 78)
masha.score = 85
print(masha)
```

Python создаёт `__init__` и удобное текстовое представление. `str` и `int` — аннотации ожидаемых типов, но сами по себе не проверяют ввод во время выполнения.

## Что сокращает декоратор

Обычному классу-хранилищу пришлось бы вручную написать конструктор и присвоить поля. `@dataclass` создаёт этот служебный код по аннотациям; объекты также удобно сравниваются по значениям.

```python
@dataclass
class Book:
    title: str
    pages: int
    read: bool = False
```

Теперь `Book("Капитанская дочка", 160)` создаёт непрочитанную книгу. Поля со значениями по умолчанию записывают после обязательных. Аргументы можно передавать по именам.

`dataclass` хорош для прозрачной структуры данных. Если создание требует сложной проверки или поведение важнее полей, обычный класс может быть яснее. Аннотация помогает читателю и инструментам, но неверный тип автоматически не запрещает.

## Мини-практика

1. Опишите книгу. 2. Создайте список учеников. 3. Измените поле и отсортируйте объекты функцией-ключом.
4. Добавьте поле со значением по умолчанию. 5. Создайте объект именованными аргументами. 6. Сравните два объекта с одинаковыми полями.
