# Графы и их хранение

Граф описывает объекты и связи: города и дороги, страницы и ссылки, этапы и переходы.

!!! abstract "Фокус"
    - **Нужно знать:** вершина, ребро, путь, цикл, вес, направление.
    - **Нужно уметь:** прочитать список смежности.

```python
graph = {
    1: [2, 3],
    2: [4],
    3: [4],
    4: []
}
```

Ключ — вершина, список — её соседи. В ориентированном графе ребро `1 → 2` не означает `2 → 1`. У неориентированного ребро обычно записывают в обоих списках.

```python
weighted = {
    1: [(2, 5), (3, 2)],
    2: [(4, 3)],
    3: [(4, 7)],
    4: []
}
```

Пара `(2, 5)` означает ребро к вершине 2 веса 5. DAG — ориентированный граф без циклов. В файле ребро удобно хранить строкой `from to weight`.

## Частые ошибки

- считать ориентированное ребро двусторонним;
- путать число рёбер с числом вершин;
- считать длиной пути число вершин вместо суммы весов;
- забывать вершины без исходящих рёбер.

## Мини-практика

1. Нарисуйте граф по словарю. 2. Запишите дороги между четырьмя городами. 3. Найдите веса двух путей.
