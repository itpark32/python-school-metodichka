Граф описывает объекты и связи: города и дороги, страницы и ссылки, этапы и переходы.

!!! abstract "Фокус"
    - **Нужно знать:** вершина, ребро, путь, цикл, вес, направление.
    - **Нужно уметь:** прочитать список смежности.

```python
graph = {
    1: [2, 3],
    2: [4],
    3: [4],
    4: []
}
```

Ключ — вершина, список — её соседи. В ориентированном графе ребро `1 → 2` не означает `2 → 1`. У неориентированного ребро обычно записывают в обоих списках.

```python
weighted = {
    1: [(2, 5), (3, 2)],
    2: [(4, 3)],
    3: [(4, 7)],
    4: []
}
```

Пара `(2, 5)` означает ребро к вершине 2 веса 5. DAG — ориентированный граф без циклов. В файле ребро удобно хранить строкой `from to weight`.

## Из условия в модель

Сначала решите, что является вершинами, а что рёбрами. В карте вершины — города, рёбра — дороги. В задаче о переходах вершинами могут быть числа или состояния программы. Направление и вес добавляют только тогда, когда они есть в условии.

Для неориентированной дороги `a—b` нужны две записи: `graph[a].append(b)` и `graph[b].append(a)`. Для ориентированного перехода добавляется только `a → b`. Петля соединяет вершину с собой; цикл — путь, возвращающийся в исходную вершину.

## Три формы хранения

Список рёбер удобен для чтения файла и перебора всех связей. Список смежности быстро даёт соседей выбранной вершины. Матрица смежности позволяет мгновенно проверить конкретное ребро, но занимает память порядка `n²`. Для разреженных школьных графов чаще используют списки смежности.

Проверяйте модель на вершине без соседей, двусторонней дороге и повторном ребре. Подпишите, считаются ли номера вершин с нуля или с единицы.

## Частые ошибки

- считать ориентированное ребро двусторонним;
- путать число рёбер с числом вершин;
- считать длиной пути число вершин вместо суммы весов;
- забывать вершины без исходящих рёбер.

## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

Если данные заданы прямо в коде, для дополнительных тестов заменяйте начальные значения на данные из таблицы.

### Задача 1. Исходящие связи

#### Условие

Дан ориентированный граф `graph = {1: [2, 3], 2: [3], 3: [], 4: []}`. Для каждой вершины выведите её номер и число исходящих рёбер в порядке записи ключей.

#### Как рассуждать

Значения словаря уже являются списками исходящих соседей. Их длина и есть искомое количество. Вершины с пустыми списками не нужно пропускать: у них результат ноль.

#### Алгоритм

1. Переберите пары вершина–соседи через items.
2. Для каждой вершины найдите длину списка.
3. Выведите номер и количество.

#### Решение

```python
graph = {1: [2, 3], 2: [3], 3: [], 4: []}
for vertex, neighbours in graph.items():
    print(vertex, len(neighbours))
```

#### Разбор решения

Запись 1 → 2 не добавляет обратного ребра 2 → 1. Предполагается, что списки не содержат повторных рёбер. Изолированная вершина 4 присутствует в словаре и поэтому тоже выводится.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| исходный граф | обычный случай | 1 2<br>2 1<br>3 0<br>4 0 |
| только вершина 1 | изолированная вершина | 1 0 |
| пустой граф | вершин нет | нет строк вывода |

**Ответ:** для первого теста — 1 2; 2 1; 3 0; 4 0.

### Задача 2. Из дорог в список смежности

#### Условие

Даны вершины 1, 2, 3, 4 и неориентированные дороги `edges = [(1, 2), (2, 3)]`. Постройте словарь списков смежности и выведите для каждой вершины номер и список соседей. Петель и повторных дорог нет.

#### Как рассуждать

Сначала создадим запись для каждой вершины, даже изолированной. Каждая неориентированная дорога добавляет двух соседей: конец в список начала и начало в список конца. Порядок соседей оставляем по вводу дорог.

#### Алгоритм

1. Создайте четыре пустых списка в словаре.
2. Для каждой дороги добавьте оба направления.
3. Выведите списки всех вершин.

#### Решение

```python
vertices = [1, 2, 3, 4]
edges = [(1, 2), (2, 3)]
graph = {}
for vertex in vertices:
    graph[vertex] = []
for a, b in edges:
    graph[a].append(b)
    graph[b].append(a)
for vertex in vertices:
    print(vertex, graph[vertex])
```

#### Разбор решения

Список для каждой вершины создаётся отдельно, поэтому изменения соседей не затрагивают другие записи. Если добавить только a → b, получится ориентированная модель другой задачи. У вершины 4 список остаётся пустым.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| дороги 1—2, 2—3 | обычный случай | 1 [2]<br>2 [1, 3]<br>3 [2]<br>4 [] |
| дорог нет | все вершины изолированы | 1 []<br>2 []<br>3 []<br>4 [] |

**Ответ:** для первого теста — 1 [2]; 2 [1, 3]; 3 [2]; 4 [].

### Задача 3. Стоимость заданного маршрута

#### Условие

Дан ориентированный взвешенный граф `graph = {1: [(2, 4), (3, 10)], 2: [(3, 5)], 3: []}` и маршрут `route = [1, 2, 3]`. Выведите сумму весов, если все переходы существуют; иначе `нет маршрута`. Маршрут непустой, все его вершины есть в графе, параллельных рёбер нет.

#### Как рассуждать

Маршрут уже задан, искать кратчайший пока не нужно. Для каждой соседней пары вершин маршрута найдём ребро в списке исходящих связей. Если хотя бы одно отсутствует, сумма уже не имеет смысла.

#### Алгоритм

1. Начните с нулевой стоимости и признака допустимости.
2. Для каждого перехода найдите его вес.
3. При отсутствии ребра остановитесь.
4. Выведите сумму или сообщение.

#### Решение

```python
graph = {1: [(2, 4), (3, 10)], 2: [(3, 5)], 3: []}
route = [1, 2, 3]
total = 0
valid = True
for i in range(len(route) - 1):
    start = route[i]
    finish = route[i + 1]
    weight = None
    for neighbour, cost in graph[start]:
        if neighbour == finish:
            weight = cost
            break
    if weight is None:
        valid = False
        break
    total += weight
if valid:
    print(total)
else:
    print("нет маршрута")
```

#### Разбор решения

None обозначает отсутствие ребра и не путается с допустимым нулевым весом. Направление учитывается: наличие 1 → 2 не разрешает 2 → 1. Маршрут из одной вершины имеет стоимость 0, потому что переходов нет.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| маршрут [1,2,3] | обычный случай | 9 |
| маршрут [2,1] | нет обратного ребра | нет маршрута |
| маршрут [1,3] | прямой переход | 10 |
| маршрут [3] | нет переходов | 0 |

**Ответ:** для первого теста — 9.
