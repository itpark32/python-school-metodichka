Кортеж хранит неизменяемую последовательность, множество — уникальные элементы.
!!! abstract "Фокус"
    - **Нужно знать:** распаковку и операции множеств.
```python
point = (3, 5)
x, y = point
a = {1, 2, 3}
b = {3, 4}
print(a & b)  # пересечение
print(a | b)  # объединение
print(a - b)  # разность
```
В множество добавляют через `add`; `discard` безопасен для отсутствующего значения, `remove` вызовет ошибку. `len(set(values))` даёт число разных значений, но порядок не гарантируется.

## Выбираем коллекцию по смыслу

Кортеж подходит для одной составной записи: координаты точки, дата, пара «результат и индекс». Его нельзя изменить по элементам, поэтому он подчёркивает постоянство структуры. Кортеж из одного элемента записывают с запятой: `(5,)`.

Множество отвечает на вопросы «встречалось ли значение?» и «какие значения уникальны?». Проверка `value in seen` обычно быстра и не требует ручного перебора.

```python
seen = set()
duplicates = set()
for number in numbers:
    if number in seen:
        duplicates.add(number)
    seen.add(number)
```

## Операции множеств как задачи

Пересечение `a & b` — элементы в обоих наборах, объединение `a | b` — хотя бы в одном, разность `a - b` — только в первом. Порядок операндов важен для разности. Если нужен стабильный вывод, примените `sorted` к результату.

Не используйте множество, если важны повторы или исходный порядок: при превращении списка в `set` эта информация теряется.

### Задача 1. Координаты точки

#### Условие

Дан кортеж `point = (3, -4)`. Распакуйте координаты и выведите квадрат расстояния до начала координат: x² + y².

#### Как рассуждать

Кортеж хранит одну запись из двух связанных значений. Распаковка даст понятные имена x и y. Квадрат расстояния можно вычислить арифметикой, без извлечения корня.

#### Алгоритм

1. Распакуйте точку в x и y.
2. Вычислите сумму квадратов.
3. Выведите результат.

#### Решение

```python
point = (3, -4)
x, y = point
print(x * x + y * y)
```

#### Разбор решения

Число переменных должно совпадать с числом компонентов кортежа. Исходная точка не изменяется. Отрицательная координата при возведении в квадрат даёт положительный вклад.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| (3, -4) | обычный случай | 25 |
| (0, 0) | начало координат | 0 |
| (0, 5) | точка на оси | 25 |

**Ответ:** для первого теста — 25.

### Задача 2. Участники кружков

#### Условие

Даны множества `art = {1, 2, 3}` и `robot = {3, 4}`. Выведите количество общих участников и количество участников только первого кружка через пробел.

#### Как рассуждать

Повторы внутри кружка не нужны: важен сам факт участия. Пересечение даст участников обоих кружков, разность — первого без второго. Порядок элементов в множестве для количества не важен.

#### Алгоритм

1. Найдите пересечение.
2. Найдите разность art - robot.
3. Выведите длины двух множеств.

#### Решение

```python
art = {1, 2, 3}
robot = {3, 4}
common = art & robot
only_art = art - robot
print(len(common), len(only_art))
```

#### Разбор решения

`&` оставляет общие элементы; `art - robot` исключает участников второго кружка. Менять операнды разности местами нельзя. Для пустого множества используйте `set()`, потому что `{}` создаёт словарь.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| {1,2,3}; {3,4} | обычный случай | 1 2 |
| оба пусты | нет участников | 0 0 |
| одинаковые множества | все общие | 2 0 |

**Ответ:** для первого теста — 1 2.

### Задача 3. Разные повторяющиеся значения

#### Условие

Для списка `numbers = [4, 2, 4, 4, 2, 7]` найдите количество различных значений, которые встретились не менее двух раз.

#### Как рассуждать

Нужно отличать число повторных вхождений от числа повторяющихся значений. Первое множество запоминает всё встреченное, второе — значения, которые уже встречались раньше. Добавление в множество не увеличивает результат повторно.

#### Алгоритм

1. Создайте множества seen и duplicates.
2. Если число уже в seen, добавьте его в duplicates.
3. В любом случае добавьте число в seen.
4. Выведите размер duplicates.

#### Решение

```python
numbers = [4, 2, 4, 4, 2, 7]
seen = set()
duplicates = set()
for number in numbers:
    if number in seen:
        duplicates.add(number)
    seen.add(number)
print(len(duplicates))
```

#### Разбор решения

Проверка выполняется до `seen.add`, иначе любое число считалось бы повтором. Для трёх четвёрок во второе множество всё равно попадёт только одно значение 4. Исходный порядок и частоты не сохраняем, поскольку они не нужны для ответа.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| [4, 2, 4, 4, 2, 7] | обычный случай | 2 |
| [5, 5, 5] | много вхождений одного значения | 1 |
| [1, 2] | повторов нет | 0 |
| [] | пустой набор | 0 |

**Ответ:** для первого теста — 2.
