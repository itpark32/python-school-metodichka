Словарь связывает уникальный ключ со значением; частотный словарь считает повторы.
!!! abstract "Фокус"
    - **Нужно уметь:** добавлять ключи и перебирать пары `.items()`.
```python
frequency = {}
for char in text:
    frequency[char] = frequency.get(char, 0) + 1
for char, count in frequency.items():
    print(char, count)
```
`get(char, 0)` возвращает ноль для нового ключа. Обращение `frequency[char]` к отсутствующему ключу вызовет `KeyError`; сначала проверяйте `in` или используйте `get`.

## Модель «ключ → значение»

В списке значение ищут по целому индексу, в словаре — по выбранному ключу. Например, ключом может быть имя ученика, а значением — балл. Ключи уникальны: повторное присваивание заменяет прежнее значение.

Частотный словарь строится одним проходом. До обработки символа `frequency` содержит точные частоты уже просмотренной части текста; `get` возвращает прежнюю частоту либо ноль, после чего прибавляется единица.

```python
best_char = None
best_count = 0
for char, count in frequency.items():
    if count > best_count:
        best_char = char
        best_count = count
```

При равной частоте нужно заранее решить правило: оставить первый, выбрать меньший ключ или вывести все. Словарь сам по себе не определяет такое правило задачи.

## Когда словарь не нужен

Для десяти цифр можно использовать список из десяти счётчиков. Словарь удобнее, когда множество ключей заранее неизвестно или ключи — строки. Если нужен только факт наличия без связанного значения, достаточно множества.
## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Сколько раз встретилась буква

#### Условие

Введите строку. Постройте частотный словарь и выведите количество строчных латинских букв a. Регистр учитывается.

#### Как рассуждать

Ключом будет символ, значением — число его появлений. Для нового символа прежняя частота равна нулю. Если a не встретилась, при выводе тоже нужен безопасный ноль.

#### Алгоритм

1. Обойдите строку и обновите частоты.
2. Получите частоту a через get.
3. Выведите количество.

#### Решение

```python
text = input()
frequency = {}
for char in text:
    frequency[char] = frequency.get(char, 0) + 1
print(frequency.get("a", 0))
```

#### Разбор решения

`get(char, 0)` избегает KeyError при первом появлении. Буквы A и a — разные ключи. В пустом тексте словарь остаётся пустым, а итоговый get возвращает 0.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| banana | обычный случай | 3 |
| AAA | учёт регистра | 0 |
| пустая строка | нет ключа a | 0 |

**Ответ:** для первого теста — 3.

### Задача 2. Частоты слов

#### Условие

Введите строку из слов без знаков препинания. Не учитывая регистр, выведите каждое слово и его количество в порядке первого появления.

#### Как рассуждать

Сначала нормализуем регистр и разделим строку. Словарь свяжет слово с частотой. Обычный словарь Python сохраняет порядок первого добавления ключей; повторное обновление этот порядок не меняет.

#### Алгоритм

1. Примените lower и split.
2. Посчитайте частоты слов через get.
3. Переберите items и выведите слово и количество.

#### Решение

```python
text = input()
frequency = {}
for word in text.lower().split():
    frequency[word] = frequency.get(word, 0) + 1
for word, count in frequency.items():
    print(word, count)
```

#### Разбор решения

`.items()` даёт пару ключ–значение, которую распаковываем в две переменные. Разделение по пробелам не убирает пунктуацию, поэтому её нет в допустимом вводе. Пустая строка не создаёт ни одного слова.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| Кот пёс кот | обычный случай | кот 2<br>пёс 1 |
| ДА да ДА | объединение регистра | да 3 |
| пустая строка | слов нет | нет строк вывода |

**Ответ:** для первого теста — кот 2; пёс 1.

### Задача 3. Все лидеры по частоте

#### Условие

Введите строку. Выведите максимальную частоту символа, затем все символы с этой частотой, по одному на строке в порядке первого появления. Для пустой строки выведите только 0.

#### Как рассуждать

Сначала нужно узнать все частоты. Затем отдельным проходом найдём лучшую частоту и ещё одним — все ключи с ней. Выбор одного самого частого символа потерял бы остальные при равенстве.

#### Алгоритм

1. Постройте словарь частот.
2. Найдите максимум частот, начав с нуля.
3. Выведите максимум и все ключи с такой частотой.

#### Решение

```python
text = input()
frequency = {}
for char in text:
    frequency[char] = frequency.get(char, 0) + 1
maximum = 0
for count in frequency.values():
    if count > maximum:
        maximum = count
print(maximum)
for char, count in frequency.items():
    if count == maximum:
        print(char)
```

#### Разбор решения

`.values()` перебирает только значения словаря, то есть частоты. Начальный ноль корректен: у существующего символа частота положительна. Последний проход решает случай нескольких лидеров без сортировки.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| abacbc | три равных лидера | 2<br>a<br>b<br>c |
| аааб | один лидер | 3<br>а |
| пустая строка | нет ключей | 0 |

**Ответ:** для первого теста — 2; a; b; c.
