# Вложенные циклы

<p class="reading-time">Чтение: 6 минут · Практика: 15 минут</p>
<div class="tags"><span class="tag">8–9 класс</span><span class="tag tag--ege">ЕГЭ</span></div>

Для каждого шага внешнего цикла внутренний выполняется полностью. Так перебирают таблицы, координаты и пары вариантов.

!!! abstract "Фокус"
    - **Нужно знать:** порядок выполнения двух циклов.
    - **Нужно уметь:** перечислить пары `(x, y)`.
    - **Полезно знать:** два цикла часто означают около `n²` действий.

## 1. Пары значений

```python
for x in range(3):
    for y in range(2):
        print(x, y)
```

Получатся `(0,0)`, `(0,1)`, затем пары для `x = 1` и `x = 2`. Внутренний `y` каждый раз начинает диапазон заново.

```python
for row in range(1, 4):
    for column in range(1, 4):
        print(row * column, end=" ")
    print()
```

Внешний цикл создаёт строки таблицы, внутренний — значения внутри строки.

## 2. Частые ошибки

- ожидать, что оба счётчика меняются одновременно;
- неверно располагать отступы;
- ставить переход строки во внутреннем цикле;
- использовать полный двойной перебор для соседних элементов, где достаточно одного цикла.
