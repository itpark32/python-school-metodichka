# Вложенные циклы

<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>
<div class="tags"><span class="tag">8–9 класс</span><span class="tag tag--ege">ЕГЭ</span></div>

Для каждого шага внешнего цикла внутренний выполняется полностью. Так перебирают таблицы, координаты и пары вариантов.

Удобная модель: внешний цикл выбирает строку или первый объект, внутренний перебирает все столбцы или все варианты второго объекта. После завершения внутреннего цикла внешний делает один шаг, а внутренний начинается заново.

!!! abstract "Фокус"
    - **Нужно знать:** порядок выполнения двух циклов.
    - **Нужно уметь:** перечислить пары `(x, y)`.
    - **Полезно знать:** два цикла часто означают около `n²` действий.

## 1. Пары значений

```python
for x in range(3):
    for y in range(2):
        print(x, y)
```

Получатся `(0,0)`, `(0,1)`, затем пары для `x = 1` и `x = 2`. Внутренний `y` каждый раз начинает диапазон заново.

```python
for row in range(1, 4):
    for column in range(1, 4):
        print(row * column, end=" ")
    print()
```

Внешний цикл создаёт строки таблицы, внутренний — значения внутри строки.

## 2. Ограничиваем лишний перебор

Если нужны не все упорядоченные пары, границы можно сузить. Для всех пар разных элементов без повторов:

```python
numbers = [4, 7, 9, 12]

for i in range(len(numbers)):
    for j in range(i + 1, len(numbers)):
        print(numbers[i], numbers[j])
```

Условие `j > i` не допускает пару элемента с самим собой и не повторяет `(4, 7)` как `(7, 4)`. Сначала всегда решите, важен ли порядок пары.

## 3. Сколько будет действий

Диапазоны длины 3 и 4 дают `3 · 4 = 12` выполнений тела. Для двух циклов по `n` элементов получается примерно `n²`. При `n = 1000` это уже миллион сравнений, поэтому для больших данных ищут более быстрый алгоритм.

## 4. Частые ошибки

- ожидать, что оба счётчика меняются одновременно;
- неверно располагать отступы;
- ставить переход строки во внутреннем цикле;
- использовать полный двойной перебор для соседних элементов, где достаточно одного цикла.

## 5. Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Сетка координат

#### Условие

Введите число строк r и столбцов c, оба от 0 до 10. Выведите все пары индексов клеток, начиная с нуля, в порядке строк: сначала все столбцы строки 0, затем строки 1 и так далее.

#### Как рассуждать

Внешний цикл фиксирует строку, внутренний перебирает её столбцы. Для каждой новой строки внутренний диапазон начинается заново. Число выведенных пар равно r · c.

#### Алгоритм

1. Прочитайте размеры.
2. Переберите строки внешним циклом.
3. Для каждой строки переберите столбцы и выведите пару.

#### Решение

```python
rows = int(input())
columns = int(input())
for row in range(rows):
    for column in range(columns):
        print(row, column)
```

#### Разбор решения

`print` находится внутри обоих циклов, поэтому выполняется для каждой клетки. При нулевом числе строк или столбцов пар не будет. Здесь индексы — числа диапазонов; двумерный список создавать не требуется.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 2; 2 | обычный случай | 0 0<br>0 1<br>1 0<br>1 1 |
| 1; 1 | одна клетка | 0 0 |
| 2; 0 | столбцов нет | нет строк вывода |

**Ответ:** для первого теста — 0 0; 0 1; 1 0; 1 1.

### Задача 2. Прямоугольный треугольник

#### Условие

Введите n от 0 до 10. Выведите n строк из звёздочек: в первой одна, во второй две, в последней n. Пробелы между звёздочками не нужны.

#### Как рассуждать

Длина строки зависит от её номера. Внешний цикл выбирает длину от 1 до n, а внутренний печатает столько звёздочек. Переход строки нужен только после завершения внутреннего цикла.

#### Алгоритм

1. Переберите длины строк от 1 до n.
2. Выведите нужное число звёздочек без переноса.
3. После каждой строки выполните пустой print().

#### Решение

```python
n = int(input())
for length in range(1, n + 1):
    for _ in range(length):
        print("*", end="")
    print()
```

#### Разбор решения

`end=""` отменяет перевод строки после отдельной звёздочки. Последний `print()` имеет отступ внешнего тела, поэтому завершает целую строку. Если перенести его внутрь второго цикла, каждая звёздочка окажется на своей строке.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3 | обычный случай | *<br>**<br>*** |
| 1 | минимальный непустой рисунок | * |
| 0 | пустой рисунок | нет строк вывода |

**Ответ:** для первого теста — *; **; ***.

### Задача 3. Два вида жетонов

#### Условие

Введите s от 0 до 30. Найдите все пары неотрицательных целых x и y, для которых 3*x + 5*y = s. Выводите x и y через пробел в порядке возрастания x. Если вариантов нет, выведите `нет решений`.

#### Как рассуждать

x и y — количества жетонов стоимостью 3 и 5. Каждое количество не больше s: этого достаточно для полного, хотя и небольшого избыточного перебора. Каждую пару проверяем один раз и считаем найденные решения.

#### Алгоритм

1. Переберите x и y от 0 до s.
2. Проверьте общую стоимость.
3. Выведите подходящие пары и увеличьте счётчик.
4. Если счётчик остался нулём, сообщите об отсутствии решений.

#### Решение

```python
s = int(input())
count = 0
for x in range(s + 1):
    for y in range(s + 1):
        if 3 * x + 5 * y == s:
            print(x, y)
            count += 1
if count == 0:
    print("нет решений")
```

#### Разбор решения

Оба диапазона включают ноль: покупка может состоять из жетонов одного вида. Проверка равенства отсеивает лишние пары. Для больших s диапазоны стоит сужать, но при s ≤ 30 число проверок не превышает 961.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 15 | два решения на краях диапазонов | 0 3<br>5 0 |
| 1 | невозможная сумма | нет решений |
| 0 | оба количества нулевые | 0 0 |

**Ответ:** для первого теста — 0 3; 5 0.
