# Трассировка программ

Трассировка — ручное пошаговое выполнение программы с записью значений переменных.

Её цель — не переписать код на бумагу, а зафиксировать состояние программы в ключевых точках. Таблица снимает нагрузку с памяти и показывает первый шаг, на котором рассуждение расходится с кодом.

!!! abstract "Фокус"
    - **Нужно знать:** значения записывают после выполнения строки.
    - **Нужно уметь:** построить таблицу шагов цикла.
    - **Полезно знать:** трассировка полезнее попытки «угадать» ответ.

## 1. Цикл `for`

```python
x = 3
count = 0

for i in range(4):
    x += i
    if x % 2 == 0:
        count += 1
```

| шаг | i | x после `x += i` | `x` чётное | count |
|---:|---:|---:|---|---:|
| 1 | 0 | 3 | нет | 0 |
| 2 | 1 | 4 | да | 1 |
| 3 | 2 | 6 | да | 2 |
| 4 | 3 | 9 | нет | 2 |

## 2. Цикл `while`

Сначала выпишите стартовые значения, затем для каждой итерации: результат проверки, изменения в теле и значение перед следующим условием. Отдельно отметьте шаг, на котором условие стало ложным.

```python
x = 10
steps = 0

while x > 1:
    x //= 2
    steps += 1
```

| проверка | `x` после деления | `steps` |
|---|---:|---:|
| `10 > 1` | 5 | 1 |
| `5 > 1` | 2 | 2 |
| `2 > 1` | 1 | 3 |
| `1 > 1` — ложь | — | 3 |

Последнюю ложную проверку отмечают, но тело для неё не выполняют.

## 3. Трассировка как отладка

Сначала выберите минимальный пример, затем заведите столбец для каждой меняющейся переменной. Записывайте значение после той строки, где оно изменилось. Для ветвления добавьте столбец с результатом условия. Если интересует только ответ, не нужно расписывать неизменные части программы.

Особенно полезны граничные примеры: пустой диапазон, один элемент, равенство на границе, ни одного подходящего элемента.

## 4. Частые ошибки

- пропускать значение 0 в `range(4)`;
- проверять условие до изменения `x`, хотя в коде оно стоит после;
- держать несколько шагов в голове вместо таблицы;
- записывать только изменившуюся переменную и терять состояние.

## 5. Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Удвоения по шагам

#### Условие

Введите n от 0 до 10. Начиная с x = 1, выполните n удвоений и выведите x. Для n = 3 заранее составьте трассу.

#### Как рассуждать

Перед первым повтором x равно 1. После каждого умножения оно удваивается; номер повтора не прибавляется к x. Трасса для трёх шагов: старт 1, затем 2, 4, 8.

#### Алгоритм

1. Прочитайте n и задайте x = 1.
2. Выполните n умножений на 2.
3. Выведите конечное x.

#### Решение

```python
n = int(input())
x = 1
for _ in range(n):
    x *= 2
print(x)
```

#### Разбор решения

Нулевая итерация диапазона — настоящий первый повтор, а не пропуск. При n = 0 значение остаётся начальным. Сравнение с ручной трассой позволяет проверить число повторений.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3: 1 → 2 → 4 → 8 | обычный случай | 8 |
| 0: только старт | ни одного изменения | 1 |
| 1: 1 → 2 | один шаг | 2 |

**Ответ:** для первого теста — 8.

---

### Задача 2. Проверка после изменения

#### Условие

Введите начальное целое x. Для i от 1 до 3 включительно сначала прибавляйте i к x, затем увеличивайте count, если новое x чётно. Выведите x и count.

#### Как рассуждать

Порядок действий важен: условие проверяет уже увеличенное число. Для старта 0 состояния после прибавления: 1, 3, 6. Только последнее чётно, поэтому счётчик равен 1.

#### Алгоритм

1. Обнулите count.
2. На каждом шаге сначала измените x.
3. Проверьте чётность нового значения.
4. Выведите оба результата.

#### Решение

```python
x = int(input())
count = 0
for i in range(1, 4):
    x += i
    if x % 2 == 0:
        count += 1
print(x, count)
```

#### Разбор решения

Полезная таблица имеет столбцы i, новое x, истинность проверки и count. Для x = 1 новые значения 2, 4, 7, поэтому счётчик 2. Если перенести if перед сложением, трасса и результат изменятся.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 0: (1,1,0), (2,3,0), (3,6,1) | обычный случай | 6 1 |
| 1: новые x равны 2, 4, 7 | другой результат ветвления | 7 2 |
| -6 | переход к нулю | 0 1 |

**Ответ:** для первого теста — 6 1.

### Задача 3. Подбор входа по результату

#### Условие

Найдите наименьшее положительное начальное x, при котором цикл `while x < 20: x = 2*x + 1` выполнится ровно три раза. Затем напишите программу, которая для введённого x от 1 до 100 выводит конечное значение и число повторов.

#### Как рассуждать

Проследим три последовательных изменения: после них x станет 8*x₀ + 7. Для остановки нужно 8*x₀ + 7 ≥ 20; чтобы третий шаг состоялся, после двух шагов должно быть 4*x₀ + 3 < 20. Подходят целые 2, 3, 4, минимум — 2.

#### Алгоритм

1. Прочитайте начальное x и обнулите шаги.
2. Пока x < 20, обновляйте x, затем счётчик.
3. Выведите конечное x и число повторов.

#### Решение

```python
x = int(input())
steps = 0
while x < 20:
    x = 2 * x + 1
    steps += 1
print(x, steps)
```

#### Разбор решения

Для x₀ = 2 трасса 2 → 5 → 11 → 23: три успешные проверки и одна ложная. Для x₀ = 1 потребуется четыре шага. Счётчик увеличивается только после выполненного тела, последняя ложная проверка не считается.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 2: 2 → 5 → 11 → 23 | обычный случай | 23 3 |
| 1: 1 → 3 → 7 → 15 → 31 | перед минимальным ответом | 31 4 |
| 20 | условие сразу ложно | 20 0 |

**Ответ:** для первого теста — 23 3.

Третья задача — учебный вариант школьного анализа числа повторений. Наименьший вход — **2**. Дополнительную трассировку циклов можно выполнить в [тестах Полякова](https://kpolyakov.spb.ru/school/test8a/py23.htm).
