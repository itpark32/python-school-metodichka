# `for` и `range`

<p class="reading-time">Чтение: 12–15 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag">8 класс</span><span class="tag tag--oge">ОГЭ</span><span class="tag tag--ege">ЕГЭ</span></div>

`for` удобен, когда известны элементы или количество повторов.

!!! abstract "Фокус"
    - **Нужно знать:** `range(stop)`, `range(start, stop, step)`.
    - **Нужно уметь:** выбрать правильные границы.
    - **Полезно знать:** правая граница не включается.

## 1. Диапазоны

```python
for i in range(5):       # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):    # 1, 2, 3, 4, 5
    print(i)

for i in range(10, 0, -2):
    print(i)             # 10, 8, 6, 4, 2
```

`range(n)` даёт ровно `n` значений от 0. Чтобы перебрать от 1 до `n` включительно, нужна граница `n + 1`.

В общем виде `range(start, stop, step)` начинает с `start`, прибавляет `step` и останавливается до `stop`.

| выражение | значения |
|---|---|
| `range(4)` | 0, 1, 2, 3 |
| `range(2, 6)` | 2, 3, 4, 5 |
| `range(1, 8, 2)` | 1, 3, 5, 7 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 |

Для движения назад шаг должен быть отрицательным, а начало — больше конца. `range(1, 5, -1)` пуст: единица с таким шагом не приближается к пятёрке.

```python
n = int(input())
total = 0

for _ in range(n):
    total += int(input())

print(total)
```

Имя `_` показывает: номер повтора нам не нужен.

## 2. Номер или значение

Если элементы уже находятся в коллекции, обычно перебирают значения: `for temperature in temperatures`. Индекс нужен, когда важна позиция или сосед: `for i in range(len(temperatures))`. Не берите индекс автоматически: цикл по значениям короче и не выходит за границу.

В задаче с накоплением сформулируйте смысл переменной. Перед каждой итерацией `total` хранит сумму уже прочитанных чисел. Если это утверждение верно в начале и сохраняется после шага, алгоритм устроен правильно.

## 3. Частые ошибки

- ожидать включения правой границы;
- забывать отрицательный шаг при движении назад;
- путать `range(n)` и `range(1, n + 1)`;
- менять счётчик цикла вручную без необходимости.

## 4. Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Номера в обратном порядке

#### Условие

Введите n ≥ 0. Циклом for выведите номера от n до 1, каждый с новой строки.

#### Как рассуждать

Число повторов известно: ровно n. Диапазон начинается с n и движется с шагом -1. Конец должен быть 0, поскольку stop не включается.

#### Алгоритм

1. Прочитайте n.
2. Создайте range(n, 0, -1).
3. Выведите каждое значение диапазона.

#### Решение

```python
n = int(input())
for number in range(n, 0, -1):
    print(number)
```

#### Разбор решения

Отрицательный шаг задаёт движение назад. При n = 1 диапазон содержит единицу; при n = 0 пуст. Если сделать stop равным 1, единица пропадёт из ответа.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3 | обычный случай | 3<br>2<br>1 |
| 1 | последняя граница | 1 |
| 0 | пустой диапазон | нет строк вывода |

**Ответ:** для первого теста — 3; 2; 1.

### Задача 2. Сумма квадратов

#### Условие

Введите n ≥ 0. Найдите сумму 1² + 2² + … + n². При n = 0 ответ равен нулю.

#### Как рассуждать

Храним сумму уже обработанных квадратов. Каждый новый номер i даёт одно слагаемое i². Чтобы включить n, правая граница range должна быть n + 1.

#### Алгоритм

1. Начните сумму с нуля.
2. Переберите номера от 1 до n включительно.
3. Добавляйте квадрат номера и выведите сумму.

#### Решение

```python
n = int(input())
total = 0
for i in range(1, n + 1):
    total += i * i
print(total)
```

#### Разбор решения

`total` создаётся до цикла, иначе накопление каждый раз начиналось бы заново. При n = 3 состояние суммы меняется как 0 → 1 → 5 → 14. Пустой диапазон естественно оставляет ноль.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3 | обычный случай | 14 |
| 1 | единственное слагаемое | 1 |
| 0 | слагаемых нет | 0 |

**Ответ:** для первого теста — 14.

### Задача 3. Результаты измерений

#### Условие

Сначала дано n ≥ 0, затем n целых чисел, каждое на новой строке. Посчитайте числа, которые больше 10 и делятся на 3.

#### Как рассуждать

Нужно прочитать ровно n значений; while до нуля здесь не подходит, ведь ноль может быть обычным измерением. Счётчик увеличиваем только при совпадении двух признаков.

#### Алгоритм

1. Прочитайте n и обнулите счётчик.
2. Повторите ввод числа ровно n раз.
3. Проверьте границу и делимость, обновите счётчик.
4. Выведите количество.

#### Решение

```python
n = int(input())
count = 0
for _ in range(n):
    number = int(input())
    if number > 10 and number % 3 == 0:
        count += 1
print(count)
```

#### Разбор решения

Переменная `_` не используется в вычислениях: нужен только повтор ввода. `and` объединяет требования. Список не нужен, поскольку к прошлым измерениям не возвращаемся.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 4; 9; 12; 15; 10 | обычный случай | 2 |
| 3; 10; 11; 12 | значения около границы | 1 |
| 0 | измерений нет | 0 |

**Ответ:** для первого теста — 2.
