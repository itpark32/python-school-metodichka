Последовательность можно обрабатывать по одному числу, не сохраняя весь список.

Сначала определите формат входа, затем смысл каждого накопителя. Это отделяет чтение данных от условия задачи и помогает не включить служебное значение в ответ.

!!! abstract "Фокус"
    - **Нужно знать:** два формата ввода — N чисел и ввод до стоп-значения.
    - **Нужно уметь:** совместить условие и накопитель.
    - **Полезно знать:** список не нужен, если к прошлым значениям не возвращаемся.

## 1. Сначала дано N

```python
n = int(input())
count = 0
total = 0

for _ in range(n):
    number = int(input())
    if number > 0 and number % 3 == 0:
        count += 1
        total += number

print(count, total)
```

## 2. До нуля

```python
count = 0
number = int(input())

while number != 0:
    if number < 0:
        count += 1
    number = int(input())

print(count)
```

Ноль управляет окончанием и не обрабатывается. Если нужно сравнивать соседей, храните предыдущее значение; если обращаться ко всем элементам позже — создайте список.

## 3. Соседние элементы в потоке

Для сравнения с предыдущим элементом весь список не нужен:

```python
previous = int(input())
count = 0
current = int(input())

while current != 0:
    if current > previous:
        count += 1
    previous = current
    current = int(input())

print(count)
```

Перед шагом `previous` хранит последний обработанный элемент, а `current` — новый. Первый элемент только задаёт предыдущий, поэтому сравнения начинаются со второго. Проверьте отдельно последовательность из одного числа.

## 4. Как спроектировать решение

1. Запишите, что завершает ввод.
2. Сформулируйте условие подходящего элемента.
3. Выберите накопители и начальные значения.
4. Решите, нужен ли предыдущий элемент или весь список.
5. Проверьте пустой набор подходящих данных.

## 5. Частые ошибки

- путать `for` для N элементов и `while` до признака;
- включать стоп-значение в результат;
- забывать следующий ввод;
- хранить большой список без необходимости.

## 6. Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Длина потока

#### Условие

Целые ненулевые числа вводятся до завершающего нуля. Выведите количество чисел перед ним. Ноль гарантирован.

#### Как рассуждать

Нужно отличать данные от служебного признака конца. Счётчик увеличиваем только внутри цикла, когда уже проверили, что число ненулевое. Хранить все числа не требуется.

#### Алгоритм

1. Прочитайте первое число.
2. Пока оно ненулевое, увеличивайте счётчик и читайте следующее.
3. Выведите счётчик.

#### Решение

```python
count = 0
number = int(input())
while number != 0:
    count += 1
    number = int(input())
print(count)
```

#### Разбор решения

Начальный ноль остановит обработку без единого увеличения. Отрицательное число — такие же данные, как положительное: знак на длину не влияет. Память постоянна, поскольку сохраняется только текущее значение.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 4; -2; 8; 0 | обычный случай | 3 |
| 0 | пустой поток | 0 |
| -1; 0 | один отрицательный элемент | 1 |

**Ответ:** для первого теста — 3.

### Задача 2. Сколько раз результат вырос

#### Условие

Дано n ≥ 1, затем n целых измерений с разных строк. Посчитайте, сколько измерений, начиная со второго, строго больше предыдущего.

#### Как рассуждать

Для сравнения соседей достаточно двух переменных. Первое измерение только запоминаем: перед ним нет соседа. После сравнения текущее обязательно становится предыдущим, даже если роста не было.

#### Алгоритм

1. Прочитайте n и первое измерение.
2. Прочитайте остальные n - 1 измерений.
3. Сравните с предыдущим, обновите счётчик и предыдущее значение.
4. Выведите количество ростов.

#### Решение

```python
n = int(input())
previous = int(input())
count = 0
for _ in range(n - 1):
    current = int(input())
    if current > previous:
        count += 1
    previous = current
print(count)
```

#### Разбор решения

Присваивание `previous = current` стоит после проверки и вне if. Иначе после падения мы сравнивали бы не с соседом, а с более старым значением. Равенство не является ростом.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 5; 2; 4; 1; 3; 3 | обычный случай | 2 |
| 1; 9 | соседей нет | 0 |
| 3; 5; 4; 3 | только падения | 0 |

**Ответ:** для первого теста — 2.

### Задача 3. Длинная серия одинаковых

#### Условие

Дано n ≥ 1 и затем n целых чисел. Найдите длину самой длинной серии равных соседних чисел.

#### Как рассуждать

Храним предыдущее число, длину текущей серии и лучшую длину. При равенстве серия продолжается; при различии новое число начинает серию длины один. Максимум нужно обновлять на каждом шаге, чтобы не потерять серию в конце.

#### Алгоритм

1. Примите первое число за серию длины 1.
2. Для каждого следующего числа продлите серию или начните новую.
3. Обновите максимум и предыдущее число.
4. Выведите максимальную длину.

#### Решение

```python
n = int(input())
previous = int(input())
current_length = 1
maximum = 1
for _ in range(n - 1):
    number = int(input())
    if number == previous:
        current_length += 1
    else:
        current_length = 1
    if current_length > maximum:
        maximum = current_length
    previous = number
print(maximum)
```

#### Разбор решения

При разрыве сбрасываем в 1, а не в 0: текущее число уже входит в новую серию. `maximum` не сбрасывается. Алгоритм проходит поток один раз и не нуждается в списке; похожее состояние позже пригодится для строковых экзаменационных задач.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 6; 2; 2; 5; 7; 7; 7 | лучшая серия в конце | 3 |
| 1; 4 | один элемент | 1 |
| 3; 1; 2; 3 | совпадений нет | 1 |

**Ответ:** для первого теста — 3.
