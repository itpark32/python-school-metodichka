# Счётчик, сумма, минимум и максимум

<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>
<div class="tags"><span class="tag">8–9 класс</span><span class="tag tag--oge">ОГЭ</span><span class="tag tag--ege">ЕГЭ</span></div>

Накопитель хранит результат обработки уже просмотренной части данных.

Это главный вопрос при трассировке: что именно означает переменная после каждого шага? `count` — количество подходящих элементов, `total` — их сумма, `maximum` — наибольший из уже просмотренных подходящих элементов.

!!! abstract "Фокус"
    - **Нужно знать:** начальные значения счётчика и суммы — нули.
    - **Нужно уметь:** найти min/max вручную.
    - **Полезно знать:** готовые `sum`, `min`, `max` используют после понимания алгоритма.

## 1. Основные шаблоны

```python
count = 0
total = 0

for number in numbers:
    if number > 0:
        count += 1
        total += number
```

```python
maximum = numbers[0]

for number in numbers:
    if number > maximum:
        maximum = number
```

Нельзя бездумно начинать максимум с нуля: для `[-8, -3, -10]` программа ошибочно оставит 0. Первый элемент — честное начальное значение, если список непуст.

Среднее подходящих значений: `average = total / count`, но сначала надо убедиться, что `count != 0`.

## 2. Максимум по условию

Первый элемент нельзя брать начальным, если он может не подходить. Тогда удобно использовать `None`:

```python
best = None

for number in numbers:
    if number % 5 == 0:
        if best is None or number > best:
            best = number

if best is None:
    print("подходящих чисел нет")
else:
    print(best)
```

Так программа различает настоящий максимум и отсутствие ответа. Искусственные значения вроде `-1000000` работают только при точно известных ограничениях.

### Среднее значение

Для среднего нужны два накопителя: сумма и количество. Сначала обрабатывают весь набор, затем делят. Проверка `count > 0` обязательна — подходящих чисел может не оказаться.

## 3. Обычный Python

Когда алгоритм не является темой задачи: `sum(numbers)`, `min(numbers)`, `max(numbers)`. Для фильтра по условию цикл часто остаётся самым понятным.

## 4. Частые ошибки

- создавать `count = 0` внутри цикла;
- прибавлять к сумме все элементы вместо подходящих;
- начинать максимум с 0;
- делить на `count`, который может остаться нулём.

## 5. Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Сколько и на какую сумму

#### Условие

Сначала дано n ≥ 0, затем n целых чисел по одному на строке. Выведите количество и сумму отрицательных чисел через пробел.

#### Как рассуждать

Нужны два разных результата: сколько значений подошло и сколько они дают вместе. Для пустого набора оба результата нулевые. Значение 0 не считается отрицательным.

#### Алгоритм

1. Создайте счётчик и сумму, равные нулю.
2. Прочитайте n значений.
3. Для отрицательного обновите оба накопителя.
4. Выведите количество и сумму.

#### Решение

```python
n = int(input())
count = 0
total = 0
for _ in range(n):
    number = int(input())
    if number < 0:
        count += 1
        total += number
print(count, total)
```

#### Разбор решения

Счётчик увеличивается на 1, сумма — на само число. Эти команды стоят в одной ветви, поэтому учитывают одинаковый набор элементов. Начальные нули корректны и при отсутствии подходящих данных.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 4; -3; 2; -5; 0 | обычный случай | 2 -8 |
| 2; 0; 3 | отрицательных нет | 0 0 |
| 0 | пустой набор | 0 0 |

**Ответ:** для первого теста — 2 -8.

### Задача 2. Максимум без ложного нуля

#### Условие

Сначала дано n ≥ 1, затем n целых чисел с разных строк. Найдите наибольшее.

#### Как рассуждать

Первое число гарантированно существует и может стать начальным максимумом. Затем остаётся n - 1 сравнений. Если начать с нуля, набор только из отрицательных чисел будет обработан неверно.

#### Алгоритм

1. Прочитайте n и первое число как максимум.
2. Прочитайте оставшиеся n - 1 чисел.
3. Заменяйте максимум большим значением.
4. Выведите максимум.

#### Решение

```python
n = int(input())
maximum = int(input())
for _ in range(n - 1):
    number = int(input())
    if number > maximum:
        maximum = number
print(maximum)
```

#### Разбор решения

До каждого шага `maximum` — наибольшее среди уже прочитанных. Первый ввод происходит отдельно и не должен повторяться в цикле. Равные значения не требуют обновления.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3; -8; -3; -10 | все числа отрицательные | -3 |
| 1; -5 | один элемент | -5 |
| 3; 7; 7; 2 | повтор максимума | 7 |

**Ответ:** для первого теста — -3.

### Задача 3. Среднее отобранных результатов

#### Условие

Сначала дано n ≥ 0, затем n целых результатов. Найдите среднее среди положительных чисел, кратных 5. Если таких чисел нет, выведите `нет данных`.

#### Как рассуждать

Среднее нельзя обновлять делением на каждом шаге: понадобятся итоговые сумма и количество. Проверяем и положительность, и кратность. Деление выполняем только после всего ввода и только при ненулевом количестве.

#### Алгоритм

1. Обнулите сумму и счётчик.
2. За один проход отберите нужные числа.
3. Если счётчик положителен, разделите сумму на него.
4. Иначе выведите сообщение.

#### Решение

```python
n = int(input())
count = 0
total = 0
for _ in range(n):
    number = int(input())
    if number > 0 and number % 5 == 0:
        count += 1
        total += number
if count > 0:
    print(total / count)
else:
    print("нет данных")
```

#### Разбор решения

Ноль кратен пяти, но исключён проверкой `number > 0`. `count` защищает деление от нуля. Это тот же приём отбора и накопления, который используется при обработке экзаменационных числовых данных.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 4; 5; -10; 15; 3 | обычный случай | 10.0 |
| 2; 0; 7 | отбор пуст | нет данных |
| 1; 5 | один подходящий элемент | 5.0 |

**Ответ:** для первого теста — 10.0.
