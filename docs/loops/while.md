# Цикл `while`

<p class="reading-time">Чтение: 12–15 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag">8 класс</span><span class="tag tag--oge">ОГЭ</span><span class="tag tag--ege">ЕГЭ</span></div>

`while` повторяет блок, пока условие истинно. Он особенно полезен, когда число повторов заранее неизвестно.

У корректного `while` есть три части: начальное состояние, условие продолжения и изменение состояния. Если изменение не приближает программу к завершению, цикл может стать бесконечным.

!!! abstract "Фокус"
    - **Нужно знать:** старт, условие и изменение состояния.
    - **Нужно уметь:** доказать, что цикл завершится.
    - **Полезно знать:** ввод до специального значения обычно требует `while`.

## 1. Счёт от 1 до 5

```python
number = 1

while number <= 5:
    print(number)
    number += 1
```

Есть начальное значение, проверка и шаг. Без `number += 1` условие навсегда останется истинным — получится бесконечный цикл.

## 2. Последовательность до нуля

```python
count = 0
number = int(input())

while number != 0:
    if number % 2 == 0:
        count += 1
    number = int(input())

print(count)
```

Ноль — признак окончания и не входит в последовательность.

Такой шаблон называют вводом с предусловием: первое значение читается до цикла, следующее — в конце тела. Оба ввода нужны. Другой допустимый вариант — `while True` с проверкой стоп-значения и командой `break`, но первый каркас обычно легче трассировать.

## 3. Как доказать завершение

В примере со счётом `number` на каждом шаге растёт и в конце обязательно станет больше 5. При обработке цифр положительное число уменьшается через `number //= 10` и дойдёт до нуля. Перед запуском спросите: какая переменная меняется и почему условие когда-нибудь станет ложным?

Тело может не выполниться ни разу: условие проверяется до первой итерации. Это важно для пустой последовательности и уже выполненного условия.

## 4. Частые ошибки

- не изменять переменную условия;
- забывать первый ввод до цикла или следующий ввод внутри;
- обрабатывать завершающий ноль как обычное значение;
- применять `while`, когда простой `for` понятнее.

## 5. Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Обратный отсчёт

#### Условие

Введите целое n ≥ 0. Выведите числа от n до 1, каждое с новой строки. При n = 0 ничего не выводите.

#### Как рассуждать

Текущий номер начинается с n и уменьшается на единицу. Пока он положительный, есть что печатать. Для нуля условие ложно сразу — это допустимый случай без повторов.

#### Алгоритм

1. Прочитайте n.
2. Пока n положительно, печатайте его.
3. После печати уменьшайте n.

#### Решение

```python
n = int(input())
while n > 0:
    print(n)
    n -= 1
```

#### Разбор решения

Шаг `n -= 1` приближает значение к нулю. Проверка стоит до тела, поэтому ноль не появится в выводе. Без изменения n цикл при положительном вводе не завершится.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 3 | обычный случай | 3<br>2<br>1 |
| 1 | одна итерация | 1 |
| 0 | тело не выполняется | нет строк вывода |

**Ответ:** для первого теста — 3; 2; 1.

---

### Задача 2. Первый квадрат за границей

#### Условие

Введите целое n ≥ 0. Найдите наименьшее положительное k, для которого k² > n.

#### Как рассуждать

Начнём с кандидата 1. Пока квадрат не превышает n, кандидат ещё не подходит и его нужно увеличить. Когда условие цикла станет ложным, получим первое подходящее число: ни один меньший кандидат не был пропущен.

#### Алгоритм

1. Начните с k = 1.
2. Увеличивайте k, пока k² ≤ n.
3. Выведите k после цикла.

#### Решение

```python
n = int(input())
k = 1
while k * k <= n:
    k += 1
print(k)
```

#### Разбор решения

Равенство включено в условие продолжения: для n = 9 число 3 ещё не подходит. Цикл завершится, поскольку квадраты растут без ограничения. При n = 0 начальный кандидат уже подходит.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 9 | точный квадрат | 4 |
| 8 | перед квадратом | 3 |
| 0 | без повторов | 1 |

**Ответ:** для первого теста — 4.

---

### Задача 3. Показания до остановки

#### Условие

Вводятся целые числа, каждое с новой строки; ввод обязательно заканчивается нулём. Найдите сумму положительных показаний. Завершающий ноль в данные не входит.

#### Как рассуждать

Число показаний заранее неизвестно, поэтому нужен while. Храним только сумму и текущее число. Первое число читается до проверки; следующее — в конце тела, независимо от того, прибавляли мы его или нет.

#### Алгоритм

1. Создайте нулевую сумму и прочитайте число.
2. Пока число не ноль, прибавляйте только положительные значения.
3. Читайте следующее число в каждом повторе.
4. После остановки выведите сумму.

#### Решение

```python
total = 0
number = int(input())
while number != 0:
    if number > 0:
        total += number
    number = int(input())
print(total)
```

#### Разбор решения

Проверка `number != 0` не допускает стоп-значение в обработку. Следующий ввод находится вне if, иначе отрицательное число привело бы к бесконечному повтору. Это учебный вариант школьной задачи на последовательность до признака окончания.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 5; -2; 7; 0 | обычный случай | 12 |
| 0 | пустая последовательность | 0 |
| -3; -1; 0 | подходящих нет | 0 |

**Ответ:** для первого теста — 12.
