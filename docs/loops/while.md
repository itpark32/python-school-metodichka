# Цикл `while`

<p class="reading-time">Чтение: 7 минут · Практика: 15 минут</p>
<div class="tags"><span class="tag">8 класс</span><span class="tag tag--oge">ОГЭ</span><span class="tag tag--ege">ЕГЭ</span></div>

`while` повторяет блок, пока условие истинно. Он особенно полезен, когда число повторов заранее неизвестно.

!!! abstract "Фокус"
    - **Нужно знать:** старт, условие и изменение состояния.
    - **Нужно уметь:** доказать, что цикл завершится.
    - **Полезно знать:** ввод до специального значения обычно требует `while`.

## 1. Счёт от 1 до 5

```python
number = 1

while number <= 5:
    print(number)
    number += 1
```

Есть начальное значение, проверка и шаг. Без `number += 1` условие навсегда останется истинным — получится бесконечный цикл.

## 2. Последовательность до нуля

```python
count = 0
number = int(input())

while number != 0:
    if number % 2 == 0:
        count += 1
    number = int(input())

print(count)
```

Ноль — признак окончания и не входит в последовательность.

## 3. Частые ошибки

- не изменять переменную условия;
- забывать первый ввод до цикла или следующий ввод внутри;
- обрабатывать завершающий ноль как обычное значение;
- применять `while`, когда простой `for` понятнее.
