## №16 — универсальный каркас

Условие: среди N чисел посчитать кратные 4, но не кратные 7.

```python
n = int(input())
count = 0
for _ in range(n):
    number = int(input())
    if number % 4 == 0 and number % 7 != 0:
        count += 1
print(count)
```

`n` задаёт число повторов; `count` живёт вне цикла; `%` проверяет кратность. Для суммы меняется действие: `total += number`. Для количества и суммы обновляйте два накопителя.

## Максимум подходящих

```python
maximum = None
for _ in range(int(input())):
    number = int(input())
    if number % 5 == 0:
        if maximum is None or number > maximum:
            maximum = number
print(maximum)
```

`None` означает, что подходящее число ещё не найдено. Это безопаснее нуля при отрицательных данных.

## Ввод до нуля

```python
count = 0
number = int(input())
while number != 0:
    if number % 2 == 0:
        count += 1
    number = int(input())
print(count)
```

!!! tip "Как выбрать цикл"
    Сначала дано N → обычно `for`. Ввод до специального значения → обычно `while`.

## Практика

??? question "1. Положительные чётные"
    Среди N чисел посчитайте положительные чётные. Решение: `if number > 0 and number % 2 == 0: count += 1`.

??? question "2. Сумма кратных 7"
    Заведите `total = 0`; внутри цикла при `number % 7 == 0` прибавляйте число.

??? question "3. Числа диапазона"
    Посчитайте значения от 10 до 99 включительно: `10 <= number <= 99`.

??? question "4. Количество и сумма"
    Для положительных кратных 3 изменяйте одновременно `count` и `total`.

??? question "5. Максимум подходящих"
    Найдите максимум кратных 5 с начальным значением `None`.

??? question "6. Минимум"
    Используйте то же состояние, но сравнение `number < minimum`.

??? question "7. До нуля"
    Читайте до 0 и посчитайте отрицательные; ноль не обрабатывайте.

??? question "8. Составное условие"
    Посчитайте числа, которые кратны 4 или кратны 6, но не равны нулю. Расставьте скобки.

## Частые ошибки

`input` без `int`, `=` вместо `==`, накопитель внутри цикла, неверная граница `range`, незавершающийся `while`, максимум с нуля и лишний поясняющий текст в выводе.

## Как тренировать один шаблон

Не решайте восемь почти одинаковых задач механически. После первой меняйте одно условие: количество на сумму, `and` на `or`, ввод N чисел на ввод до нуля. Каждый раз вслух формулируйте смысл накопителя и проверяйте случай без подходящих значений.

Перед сдачей программы выполните короткий чек-лист: формат ввода совпадает с условием; стоп-значение не обработано; накопители созданы до цикла; границы входят или не входят правильно; вывод содержит только требуемые значения. Для максимума отдельно проверьте отрицательные данные.
