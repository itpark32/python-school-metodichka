## №16 — рекурсия

```python
def f(n):
    if n <= 2:
        return n
    return f(n - 1) + f(n - 2)
```

Не угадывайте: раскройте `f(5)=f(4)+f(3)` до базовых случаев и соберите значения снизу вверх. Повторите [функции](../functions/basics.md) и [трассировку рекурсии](../recursion/calculations.md).

## №17 — числовая последовательность

```python
numbers = []
with open("17.txt") as file:
    for line in file:
        numbers.append(int(line))

count = 0
maximum = None
for i in range(len(numbers) - 1):
    a, b = numbers[i], numbers[i + 1]
    if a % 2 == 0 or b % 2 == 0:
        count += 1
        pair_sum = a + b
        if maximum is None or pair_sum > maximum:
            maximum = pair_sum
print(count, maximum)
```

Граница `len-1` сохраняет индекс `i+1`; `or` — хотя бы одно; `maximum` хранит лучший результат. Вариации меняют условие, пары на тройки или сравнивают с максимумом всего файла.

## №24 — строка и состояние

```python
with open("24.txt") as file:
    text = file.read().strip()
current = maximum = 1
for i in range(1, len(text)):
    if text[i] == text[i - 1]:
        current += 1
    else:
        current = 1
    maximum = max(maximum, current)
print(maximum)
```

Это лишь один вид задачи. Общий принцип: проход по строке плюс состояние текущего фрагмента. Другие условия считают соседние комбинации или сбрасывают фрагмент при запрещённой паре.

## №25 — свойства целых чисел

```python
def get_divisors(number):
    result = []
    d = 1
    while d * d <= number:
        if number % d == 0:
            result.append(d)
            if d != number // d:
                result.append(number // d)
        d += 1
    return sorted(result)

for number in range(100, 200):
    divisors = get_divisors(number)
    if len(divisors) == 4:
        print(number, divisors)
```

№25 — семейство задач, а не один шаблон: число делителей, свойства крайних делителей, простота, разложение.

## №26 — обработка после сортировки

```text
прочитать → представить числами/парами → отсортировать
→ пройти в нужном порядке → выбрать/посчитать → вывести
```

У №26 нет универсального решения. Учебные варианты: выбрать максимум объектов при ограничении суммы; обработать границы групп после сортировки; выбрать совместимые пары. `sort()` только упорядочивает данные.

## Графы — ЕГЭ-2027 (проект ФИПИ)

Проектная позиция №23 включает алгоритмические задачи на графы, среди направлений — оптимальный путь и количество путей в DAG. Повторите [хранение графа](../graphs/basics.md), [пути](../graphs/paths.md) и чтение файлов. До финальной спецификации не заучивайте номер.

## Практика

1. Раскройте две рекурсивные функции для малых `n`.
2. Решите три задачи на пары: `or`, `and`, условие суммы.
3. Найдите максимальную серию и число запрещённых пар в строке.
4. Для трёх диапазонов найдите числа с заданным числом делителей.
5. Решите две задачи на выбор после сортировки.
6. **Проект-2027:** посчитайте пути в маленьком DAG и найдите кратчайший маршрут.

## Что не работает

Не заучивайте код без состояния алгоритма, не начинайте с огромного файла, не применяйте двойной цикл автоматически, не считайте `sort()` готовым решением №26 и не путайте номер задания с проверяемой темой.

## Рабочий цикл подготовки

Для каждого типа сначала решите миниатюрный пример вручную, затем напишите прозрачный алгоритм и только после этого запускайте на полном файле. После успешного решения измените один параметр условия и объясните, какая часть состояния должна поменяться. Так шаблон становится переносимым, а не заученным.

В файловых задачах проверяйте три слоя отдельно: чтение и преобразование данных, условие подходящего фрагмента, обновление результата. Если ответ неверен, небольшой встроенный список быстрее показывает ошибку, чем повторный запуск на десятках тысяч строк.

## Самопроверка перед ответом

1. Соответствует ли формат чтения первой строке файла?
2. Безопасна ли граница для пары или тройки?
3. Обработан ли случай без подходящих элементов?
4. Сохранён ли смысл текущей и максимальной серии?
5. Оценено ли число действий до запуска полного перебора?
6. Выводятся ли значения в требуемом порядке и без поясняющего текста?
