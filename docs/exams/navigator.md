## Мини-маршруты

### До ОГЭ осталось мало времени

Условия → `for` → `while` → `%` → накопители → последовательности → трассировка → 10–20 задач №16.

### Я начинаю ЕГЭ

База → строки → списки → функции → рекурсия → файлы → пары/тройки → делители → сортировка → графы по актуальной модели.

### Я знаю Python, но плохо решаю экзамен

Идите по алгоритмам: трассировка → последовательности → строки → целые числа → сортировка → графы. После каждого решения меняйте одно условие и объясняйте, что изменилось в состоянии алгоритма.
