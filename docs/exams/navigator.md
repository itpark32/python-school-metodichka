## Мини-маршруты

### До ОГЭ осталось мало времени

Условия → `for` → `while` → `%` → накопители → последовательности → трассировка → 10–20 задач №16.

### Я начинаю ЕГЭ

База → строки → списки → функции → рекурсия → файлы → пары/тройки → делители → сортировка → графы по актуальной модели.

### Я знаю Python, но плохо решаю экзамен

Идите по алгоритмам: трассировка → последовательности → строки → целые числа → сортировка → графы. После каждого решения меняйте одно условие и объясняйте, что изменилось в состоянии алгоритма.

## Как пользоваться навигатором

Начните не с номера задания, а с диагностики. Возьмите один свежий вариант и отметьте задачи, где вы не смогли объяснить алгоритм без кода. По таблице откройте соответствующую тему, прочитайте разбор и выполните практику от простого задания к сложному. После этого вернитесь к экзаменационной формулировке.

Зелёный статус темы означает: вы можете написать базовый каркас без подсказки и объяснить каждую переменную. Жёлтый — решение получается только по образцу. Красный — непонятно, с чего начать. За одно занятие лучше перевести одну тему из красной в жёлтую, чем поверхностно просмотреть пять глав.

Раз в неделю решайте смешанный набор на время. Ошибки распределяйте по причинам: не понято условие, неверно выбран алгоритм, ошибка Python, граница или формат файла. Повторять нужно причину, а не только номер задания.

## Быстрая самопроверка

1. Могу ли я назвать состояние алгоритма до написания кода?
2. Умею ли проверить решение на минимальном и пограничном примере?
3. Понимаю ли, когда список не нужен?
4. Могу ли оценить полный перебор до запуска?
5. Знаю ли, где проверить актуальную нумерацию экзамена?
