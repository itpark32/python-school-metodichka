# Метод полного перебора

Если вариантов немного, надёжный алгоритм может проверить каждый и оставить подходящие.

!!! abstract "Фокус"
    - **Нужно уметь:** описать пространство вариантов и условие проверки.

```python
for a in range(10):
    for b in range(10):
        number = 10 * a + b
        if number >= 10 and number % 7 == 0:
            print(number)
```

Здесь 100 пар цифр. Проверка `number >= 10` исключает записи с ведущим нулём. Для четырёх цифр будет уже `10⁴` комбинаций; до запуска оцените объём. Уменьшайте диапазон и отбрасывайте невозможное как можно раньше.

!!! info "Python+"
    `itertools.product` может перечислять декартово произведение, но не заменяет понимание вложенных циклов.

## Мини-практика
