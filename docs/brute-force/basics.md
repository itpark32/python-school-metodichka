# Метод полного перебора

<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>
<div class="tags"><span class="tag">9–11 класс</span><span class="tag tag--ege">ЕГЭ</span></div>

Если вариантов немного, надёжный алгоритм может проверить каждый и оставить подходящие.

!!! abstract "Фокус"
    - **Нужно уметь:** описать пространство вариантов и условие проверки.

```python
for a in range(10):
    for b in range(10):
        number = 10 * a + b
        if number >= 10 and number % 7 == 0:
            print(number)
```

Здесь 100 пар цифр. Проверка `number >= 10` исключает записи с ведущим нулём. Для четырёх цифр будет уже `10⁴` комбинаций; до запуска оцените объём. Уменьшайте диапазон и отбрасывайте невозможное как можно раньше.

## Четыре шага проектирования

1. Назовите все независимые варианты.
2. Задайте для каждого точный диапазон.
3. Постройте кандидат.
4. Проверьте ограничения и обновите ответ.

Такое описание помогает доказать полноту: каждый допустимый кандидат будет рассмотрен, а каждый выведенный кандидат проходит проверку.

```python
count = 0
for x in range(1, 10):
    for y in range(10):
        if x + y == 10 and (10 * x + y) % 4 == 0:
            count += 1
print(count)
```

Первая цифра сразу начинается с 1, поэтому отдельная проверка ведущего нуля не нужна.

## Оценка до запуска

Перемножьте размеры диапазонов. Пять десятичных цифр дают 100 000 комбинаций, десять — уже 10 миллиардов. Ограничения лучше отражать в диапазонах и проверять как можно раньше. Но оптимизация не должна исключать допустимые варианты: сначала объясните её математически.

!!! info "Python+"
    `itertools.product` может перечислять декартово произведение, но не заменяет понимание вложенных циклов.

## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

Если данные заданы прямо в коде, для дополнительных тестов заменяйте начальные значения на данные из таблицы.

### Задача 1. Неизвестная цифра

#### Условие

В записи 4x2 символ x — десятичная цифра. Найдите все x, при которых число делится на 9. Выведите найденные цифры по одной на строке.

#### Как рассуждать

Неизвестна одна цифра, значит кандидатов всего десять. Для каждого x построим число по разрядным весам и проверим делимость. Диапазон включает 0 и 9.

#### Алгоритм

1. Переберите x от 0 до 9.
2. Постройте 400 + 10*x + 2.
3. Выведите x при нулевом остатке от деления на 9.

#### Решение

```python
for x in range(10):
    number = 400 + 10 * x + 2
    if number % 9 == 0:
        print(x)
```

#### Разбор решения

Печатается неизвестная цифра, а не всё число. Полнота перебора следует из точного перечисления всех возможных x. Для проверки: 432 делится на 9, а 422 и 442 — нет.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| шаблон 4x2, делитель 9 | обычный случай | 3 |
| тот же шаблон, делитель 2 | дополнительный тест полного диапазона | 0<br>1<br>2<br>3<br>4<br>5<br>6<br>7<br>8<br>9 |
| тот же шаблон, делитель 100 | нет решений | нет строк вывода |

**Ответ:** для первого теста — 3.

### Задача 2. Трёхзначные палиндромы

#### Условие

Найдите все трёхзначные палиндромы, кратные 7. Выведите их количество.

#### Как рассуждать

У палиндрома сотни и единицы совпадают. Можно сразу строить только допустимые формы 100*a + 10*b + a: a от 1 до 9, b от 0 до 9. Вместо 900 чисел проверим 90 кандидатов.

#### Алгоритм

1. Переберите ненулевую первую цифру.
2. Для неё переберите среднюю цифру.
3. Постройте палиндром и проверьте кратность 7.
4. Выведите количество.

#### Решение

```python
count = 0
for a in range(1, 10):
    for b in range(10):
        number = 100 * a + 10 * b + a
        if number % 7 == 0:
            count += 1
print(count)
```

#### Разбор решения

Ограничение a ≥ 1 исключает ведущий ноль до проверки, а не после неё. Каждая трёхзначная палиндромная запись получается ровно один раз. Изменение делителя в тестах проверяет сам каркас перебора.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| делитель 7 | обычный случай | 12 |
| делитель 1 | подходят все кандидаты | 90 |
| делитель 10 | единицы не могут быть нулём | 0 |

**Ответ:** для первого теста — 12.

### Задача 3. Слова с одним особым символом

#### Условие

Сколько трёхбуквенных слов можно составить из букв A, B, C, если A встречается ровно один раз и одинаковые буквы не стоят рядом? Повторения букв в остальном разрешены.

#### Как рассуждать

Три позиции независимы, поэтому нужны три вложенных перебора. После построения слова отдельно проверим частоту A и различие двух соседних пар. Всего 3³ = 27 кандидатов — полный перебор здесь мал.

#### Алгоритм

1. Переберите букву каждой позиции.
2. Соберите слово.
3. Проверьте ровно одну A и отсутствие одинаковых соседей.
4. Посчитайте подходящие слова.

#### Решение

```python
alphabet = "ABC"
count = 0
for first in alphabet:
    for second in alphabet:
        for third in alphabet:
            word = first + second + third
            if word.count("A") == 1 and first != second and second != third:
                count += 1
print(count)
```

#### Разбор решения

Требование ровно одной A не заменяется простым `"A" in word`. Проверяются обе соседние пары; первая и последняя буквы могут совпадать, ведь они не соседи. Разные тройки букв дают разные слова без повторного подсчёта.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| алфавит ABC | обычный случай | 8 |
| алфавит AB | остаётся только BAB | 1 |
| алфавит A | невозможно выполнить ограничения | 0 |

**Ответ:** для первого теста — 8.
