# Числовые данные из файлов

<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>
<div class="tags"><span class="tag">10–11 класс</span><span class="tag tag--ege">ЕГЭ</span></div>

После чтения строки нужно превратить в числа, а затем применить знакомый алгоритм списка или последовательности.

!!! abstract "Фокус"
    - **Нужно уметь:** читать числа по одному и из одной строки.
    - **Полезно знать:** `map` применяет функцию к каждому элементу.

```python
numbers = []
with open("17.txt") as file:
    for line in file:
        numbers.append(int(line))
```

Если числа записаны через пробел:

```python
with open("data.txt") as file:
    parts = file.readline().split()
    numbers = list(map(int, parts))
```

`split()` создаёт строки, `map(int, parts)` превращает каждую в целое, `list` собирает результат. Если нужны только сумма или количество, данные можно обрабатывать построчно без списка. Для соседних пар и сортировки список удобен.

## Поток или список

Решение зависит от будущих действий, а не от размера кода. Для суммы, количества, минимума и максимума достаточно одного прохода. Для сортировки, произвольных соседних пар и повторного обхода нужен список.

```python
count = 0
total = 0
with open("17.txt") as file:
    for line in file:
        number = int(line)
        if number % 7 == 0:
            count += 1
            total += number
```

После чтения каждой строки сразу обновляются накопители, поэтому память не зависит от числа строк.

## Проверяем формат

Частая ошибка — считать первую строку данными, хотя там записано `N`, или наоборот. Составьте крошечный файл вручную и вычислите ожидаемый ответ. Для пустых строк применяйте `strip()` и решайте явно, нужно ли их пропускать.

В задачах на соседние пары список не обязателен: можно хранить `previous`, но список часто делает решение понятнее. На экзамене сначала выбирайте надёжность, затем экономию памяти.

## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Сумма из файла

#### Условие

В data.txt на каждой строке записано одно целое число, без служебного количества и пустых строк. Выведите сумму всех чисел. Файл может быть пустым.

#### Как рассуждать

Строка файла — текст, поэтому перед сложением нужен int. Сумму можно обновлять сразу после чтения: хранить список и возвращаться к прошлым строкам не требуется. Начальный ноль задаёт ответ пустого файла.

#### Алгоритм

1. Откройте файл и обнулите сумму.
2. Преобразуйте каждую строку в целое число.
3. Добавьте число и выведите итог после чтения.

#### Решение

```python
total = 0
with open("data.txt", encoding="utf-8") as file:
    for line in file:
        total += int(line)
print(total)
```

#### Разбор решения

`int` допускает перевод строки после числовой записи. Но пустую строку он не преобразует, поэтому её отсутствие указано в формате. Алгоритм использует постоянную дополнительную память.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| data.txt: 5, -2, 8 | обычный случай | 11 |
| пустой файл | нет слагаемых | 0 |
| одна строка без переноса: -7 | последний перевод необязателен | -7 |

**Ответ:** для первого теста — 11.

---

### Задача 2. Файл со служебным количеством

#### Условие

Первая строка data.txt содержит n ≥ 0, далее ровно n целых чисел по одному на строке. Посчитайте числа от 10 до 20 включительно.

#### Как рассуждать

Первая строка управляет числом чтений и не является измерением. После неё выполняем ровно n вызовов readline. Это важно: если посчитать само n как элемент, результат может измениться.

#### Алгоритм

1. Прочитайте n отдельным readline.
2. Повторите чтение и проверку n раз.
3. Выведите число попаданий на отрезок.

#### Решение

```python
count = 0
with open("data.txt", encoding="utf-8") as file:
    n = int(file.readline())
    for _ in range(n):
        number = int(file.readline())
        if 10 <= number <= 20:
            count += 1
print(count)
```

#### Разбор решения

Счётчик обновляется только для данных после заголовка. Границы включены с обеих сторон. При n = 0 файл всё равно содержит строку `0`, но не содержит измерений.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| 4 / 9 / 10 / 20 / 21 | обе границы и значения снаружи | 2 |
| 0 | только заголовок | 0 |
| 1 / 15 | одно подходящее число | 1 |

**Ответ:** для первого теста — 2.

### Задача 3. Соседние пары из данных

#### Условие

В pairs.txt записаны целые числа по одному на строке, без заголовка. Найдите количество соседних пар, чья сумма кратна 7, и минимальную сумму среди них. Если подходящих пар нет, выведите `0 нет пар`.

#### Как рассуждать

После чтения чисел применим знакомый проход по соседям. Для каждой пары сначала проверим сумму, затем обновим счётчик и минимум. None нужен для отсутствия результата: ни ноль, ни большое условное число не заменяют его надёжно.

#### Алгоритм

1. Прочитайте числа в список.
2. Переберите соседние пары и найдите сумму.
3. Для кратных 7 обновите количество и минимум.
4. Выведите показатели либо сообщение.

#### Решение

```python
numbers = []
with open("pairs.txt", encoding="utf-8") as file:
    for line in file:
        numbers.append(int(line))
count = 0
minimum = None
for i in range(len(numbers) - 1):
    pair_sum = numbers[i] + numbers[i + 1]
    if pair_sum % 7 == 0:
        count += 1
        if minimum is None or pair_sum < minimum:
            minimum = pair_sum
if minimum is None:
    print(0, "нет пар")
else:
    print(count, minimum)
```

#### Разбор решения

Файл не содержит служебной строки, поэтому каждый ввод попадает в список. Пары могут перекрываться. Отрицательные кратные тоже подходят, например -7. При длине меньше двух цикл не выполняется.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| pairs.txt: 1, 6, 8, -1 | обычный случай | 3 7 |
| -3, -4 | отрицательная сумма | 1 -7 |
| 1, 1 | нет кратных сумм | 0 нет пар |
| пустой файл | нет пар | 0 нет пар |

**Ответ:** для первого теста — 3 7.
