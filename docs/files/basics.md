# Чтение и запись файлов

<p class="reading-time">Чтение: 7 минут · Практика: 15 минут</p>
<div class="tags"><span class="tag">9–11 класс</span><span class="tag tag--ege">ЕГЭ</span></div>

Файл позволяет программе получать данные не с клавиатуры и сохранять результат между запусками.

!!! abstract "Фокус"
    - **Нужно знать:** режимы `r`, `w`, `a` и конструкцию `with`.
    - **Нужно уметь:** прочитать файл целиком или построчно.
    - **Полезно знать:** `encoding="utf-8"` нужен для русского текста.

```python
with open("data.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

`with` автоматически закрывает файл. `read()` получает весь текст, `readline()` — одну строку. `strip()` убирает перевод строки по краям.

```python
with open("result.txt", "w", encoding="utf-8") as file:
    file.write("Готово\n")
```

Режим `w` очищает прежнее содержимое, `a` дописывает в конец. Относительный путь считается от рабочей папки программы.

## Частые ошибки

- файл лежит не в рабочей папке (`FileNotFoundError`);
- забыто преобразование строки в число;
- `\n` остаётся в прочитанной строке;
- важный файл случайно открыт в режиме `w`.
