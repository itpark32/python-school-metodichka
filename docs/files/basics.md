# Чтение и запись файлов

<p class="reading-time">Чтение: 12–15 минут · Практика: 20–30 минут</p>
<div class="tags"><span class="tag">9–11 класс</span><span class="tag tag--ege">ЕГЭ</span></div>

Файл позволяет программе получать данные не с клавиатуры и сохранять результат между запусками.

!!! abstract "Фокус"
    - **Нужно знать:** режимы `r`, `w`, `a` и конструкцию `with`.
    - **Нужно уметь:** прочитать файл целиком или построчно.
    - **Полезно знать:** `encoding="utf-8"` нужен для русского текста.

```python
with open("data.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

`with` автоматически закрывает файл. `read()` получает весь текст, `readline()` — одну строку. `strip()` убирает перевод строки по краям.

```python
with open("result.txt", "w", encoding="utf-8") as file:
    file.write("Готово\n")
```

Режим `w` очищает прежнее содержимое, `a` дописывает в конец. Относительный путь считается от рабочей папки программы.

## Выбираем способ чтения

`read()` нужен, когда весь файл рассматривается как один текст. Цикл `for line in file` удобен для построчной обработки и не загружает всё содержимое в память. `readline()` полезен, когда формат явно задаёт особую первую строку, например количество записей.

```python
with open("data.txt", encoding="utf-8") as file:
    count = int(file.readline())
    for _ in range(count):
        value = int(file.readline())
        print(value)
```

Не смешивайте формат файла с догадками: сначала откройте небольшой пример и выясните, где строки, пробелы и служебное количество.

## Путь и безопасность записи

Относительный путь считается не от файла программы, а от текущей рабочей папки запуска. При `FileNotFoundError` выведите или проверьте эту папку и имя файла. Перед режимом `w` убедитесь, что выбран выходной файл: прежнее содержимое восстановить кодом нельзя.

Метод `write` принимает строку и не добавляет перевод строки сам. Число нужно преобразовать: `file.write(str(answer) + "\n")`.

## Частые ошибки

- файл лежит не в рабочей папке (`FileNotFoundError`);
- забыто преобразование строки в число;
- `\n` остаётся в прочитанной строке;
- важный файл случайно открыт в режиме `w`.

### Задача 1. Количество строк

#### Условие

В файле data.txt находится текст UTF-8. Посчитайте строки, включая пустые, и выведите количество. Подготовьте файл в рабочей папке, из которой запускаете программу.

#### Как рассуждать

Цикл по файлу выдаёт каждую существующую строку. Последняя строка без завершающего переноса тоже считается. Пустой файл не даёт итераций; искать строки через разбиение всего текста не требуется.

#### Алгоритм

1. Откройте data.txt на чтение.
2. Увеличивайте счётчик на каждой строке.
3. После закрытия файла выведите результат.

#### Решение

```python
count = 0
with open("data.txt", encoding="utf-8") as file:
    for line in file:
        count += 1
print(count)
```

#### Разбор решения

Конструкция with закрывает файл после обработки. Пустая строка представлена переводом строки и тоже проходит цикл. UTF-8 позволяет читать русские буквы без зависимости от системной кодировки.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| data.txt: «кот», пустая строка, «пёс» | последняя строка без переноса | 3 |
| пустой data.txt | строк нет | 0 |
| одна пустая строка | пустая строка отличается от пустого файла | 1 |

**Ответ:** для первого теста — 3.

### Задача 2. Таблица в новом файле

#### Условие

Введите n от 0 до 10. Создайте squares.txt: для каждого числа от 1 до n запишите число и его квадрат через пробел, по одной паре на строке. На экран ничего не выводите.

#### Как рассуждать

Нужна запись, а не печать в консоль. Формируем каждую строку текстом; перевод строки добавляем самостоятельно. При n = 0 файл должен существовать, но быть пустым.

#### Алгоритм

1. Откройте squares.txt в режиме w.
2. Переберите числа от 1 до n.
3. Запишите пару и символ перевода строки.

#### Решение

```python
n = int(input())
with open("squares.txt", "w", encoding="utf-8") as file:
    for number in range(1, n + 1):
        file.write(f"{number} {number * number}\n")
```

#### Разбор решения

Режим w заменяет содержимое выходного файла при каждом запуске. `write` принимает строку, поэтому используем f-строку. Без `\n` все пары склеились бы в одну строку.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| n = 3 | обычный случай | нет строк вывода; `squares.txt`: '1 1\n2 4\n3 9\n' |
| n = 0 | пустой выходной файл | нет строк вывода; `squares.txt`: '' |

**Ответ:** для первого теста — нет строк вывода. Результат записи в файл указан в таблице.

### Задача 3. Отбор строк при копировании

#### Условие

Из input.txt прочитайте строки UTF-8. Уберите пробелы и переводы строк по краям, пропустите пустые результаты и запишите остальные в clean.txt, по одному на строке. Выведите число записанных строк.

#### Как рассуждать

Это сочетание файлового прохода, строкового преобразования и отбора. Источник и результат имеют разные имена, чтобы режим записи не очистил данные. Счётчик обновляем только после действительной записи.

#### Алгоритм

1. Откройте источник на чтение и новый файл на запись.
2. Для каждой строки примените strip.
3. Непустой результат запишите с переносом и посчитайте.
4. Выведите количество записей.

#### Решение

```python
count = 0
with open("input.txt", encoding="utf-8") as source:
    with open("clean.txt", "w", encoding="utf-8") as target:
        for line in source:
            text = line.strip()
            if text != "":
                target.write(text + "\n")
                count += 1
print(count)
```

#### Разбор решения

Вложенные with гарантируют закрытие обоих файлов. Пустые и состоящие из пробелов строки отсекаются после strip. Внутренние пробелы текста сохраняются. В памяти хранится только текущая строка, а не весь файл.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| input.txt: «␠кот␠», пустая, «два слова» | обычный случай | 2; `clean.txt`: 'кот\nдва слова\n' |
| только пробелы и переносы | отбор пуст | 0; `clean.txt`: '' |
| пустой файл | цикл не выполнится | 0; `clean.txt`: '' |

**Ответ:** для первого теста — 2. Результат записи в файл указан в таблице.
