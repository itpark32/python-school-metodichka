# Текстовые файлы

<p class="reading-time">Чтение: 12–15 минут · Практика: 25–35 минут</p>
<div class="tags"><span class="tag">10–11 класс</span><span class="tag tag--ege">ЕГЭ</span></div>

Текст из файла становится обычной строкой, к которой применимы индексы, циклы и алгоритмы серий.

!!! abstract "Фокус"
    - **Нужно уметь:** прочитать текст и отделить полезные данные от перевода строки.

```python
with open("24.txt") as file:
    text = file.read().strip()

count = 0
for i in range(len(text) - 1):
    if text[i:i + 2] == "AB":
        count += 1
print(count)
```

Для очень большого файла чтение по частям экономит память, но в типовых школьных задачах файл часто содержит одну строку. Следите: `strip()` убирает символы по краям, но не внутри текста.

## От файла к строковому алгоритму

Разделите решение на два этапа: сначала надёжно получите строку, затем забудьте о файле и примените обычный алгоритм. Это упрощает тестирование: строковую часть можно проверить на коротких литералах.

Для пары `text[i:i + 2]` допустимы начала до предпоследней позиции, поэтому используется `range(len(text) - 1)`. Срез короче двух символов не вызовет ошибки, но правильная граница яснее показывает алгоритм.

```python
current = maximum = 0
for char in text:
    if char in "ABC":
        current += 1
        maximum = max(maximum, current)
    else:
        current = 0
```

Так ищется максимальная серия символов из разрешённого набора. Обновлять максимум нужно во время серии, иначе серия в самом конце может потеряться.

## Несколько строк

Если переносы строк не являются данными, их можно убрать или обрабатывать каждую строку отдельно. Если серия может продолжаться через границу строк, простой построчный алгоритм должен сохранять состояние между итерациями. Всегда исходите из формата задания.

## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Буква во всём файле

#### Условие

Файл data.txt содержит текст UTF-8. Посчитайте все латинские буквы A без учёта регистра. Переносы строк не удаляйте: на число букв они не влияют.

#### Как рассуждать

Прочитанный файл становится обычной строкой. Чтобы A и a считались вместе, нормализуем регистр. Подсчитываем конкретный символ, а не слова или строки.

#### Алгоритм

1. Прочитайте весь текст.
2. Приведите к верхнему регистру.
3. Посчитайте A и выведите результат.

#### Решение

```python
with open("data.txt", encoding="utf-8") as file:
    text = file.read()
print(text.upper().count("A"))
```

#### Разбор решения

`read` получает в том числе внутренние переносы, но `.count("A")` их не учитывает. Русская А — другой символ и по условию не подходит. Пустой файл даёт нулевой результат.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| Aa / BA | обычный случай | 3 |
| русская А | другой алфавит | 0 |
| пустой файл | нет символов | 0 |

**Ответ:** для первого теста — 3.

---

### Задача 2. Пары через границу строк

#### Условие

В data.txt находятся строки из символов A и B. Удалите только переводы строк, считайте оставшийся текст одной последовательностью и найдите число пар AB. Пара может начинаться в одной строке и заканчиваться в следующей.

#### Как рассуждать

По условию перенос разделяет запись, но не саму последовательность. Сначала объединим строки без переносов, затем проверим соседние пары. Независимый подсчёт в каждой строке потерял бы пограничные пары.

#### Алгоритм

1. Прочитайте строки и соедините их без переводов строк.
2. Переберите начала пар в общей строке.
3. Посчитайте срезы AB.

#### Решение

```python
text = ""
with open("data.txt", encoding="utf-8") as file:
    for line in file:
        text += line.rstrip("\n")
count = 0
for i in range(len(text) - 1):
    if text[i:i + 2] == "AB":
        count += 1
print(count)
```

#### Разбор решения

`rstrip("
")` убирает перевод строки справа; в отличие от strip, он не удаляет другие символы. В данном формате есть только A и B, поэтому они сохраняются полностью. Файл с одной буквой пары не создаёт.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| первая строка A, вторая BA | пара проходит через перенос | 1 |
| AB / AB | обычный случай | 2 |
| A | одна буква | 0 |

**Ответ:** для первого теста — 1.

### Задача 3. Самая длинная серия X

#### Условие

В series.txt записана одна строка из латинских X, Y, Z, возможно с завершающим переносом. Найдите длину самой длинной серии X. Файл может быть пустым или не содержать X.

#### Как рассуждать

При X текущая серия растёт, при другой букве сбрасывается. Лучший результат обновляется прямо при росте. Такое решение учитывает серию перед концом файла без дополнительного символа-разделителя.

#### Алгоритм

1. Прочитайте строку и уберите крайний перенос.
2. Обнулите текущую длину и максимум.
3. На X продлевайте серию, иначе сбрасывайте в 0.
4. Выведите максимум.

#### Решение

```python
with open("series.txt", encoding="utf-8") as file:
    text = file.read().strip()
current = 0
maximum = 0
for char in text:
    if char == "X":
        current += 1
        if current > maximum:
            maximum = current
    else:
        current = 0
print(maximum)
```

#### Разбор решения

`strip` здесь безопасен, потому что полезный алфавит не содержит пробелов. Максимум не сбрасывается вместе с текущей серией. Начальные нули дают корректный ответ и для пустого файла, и для отсутствия X.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| XXYXXX | лучшая серия в конце | 3 |
| YZ | X нет | 0 |
| X | одна буква | 1 |
| пустой файл | нет данных | 0 |

**Ответ:** для первого теста — 3.
