# Строки, индексы и перебор

Строка — неизменяемая последовательность символов. Индексы начинаются с нуля, отрицательные считаются с конца.
!!! abstract "Фокус"
    - **Нужно знать:** `len`, индексы, `in`.
    - **Нужно уметь:** перебирать символы и индексы.
    - **Полезно знать:** индекс нужен для сравнения соседей.
```python
word = "python"
print(word[0], word[-1], len(word))
for char in word:
    print(char)
for i in range(len(word)):
    print(i, word[i])
```
Изменить `word[0]` нельзя: постройте новую строку. Частые ошибки — индекс `len(word)`, обращение к пустой строке и путаница символа с индексом.
## Мини-практика
1. 🟢 Выведите первый и последний символы. 2. 🔵 Посчитайте буквы `а`. 3. 🔴 Найдите соседние одинаковые символы.
