Строка — неизменяемая последовательность символов. Индексы начинаются с нуля, отрицательные считаются с конца.
!!! abstract "Фокус"
    - **Нужно знать:** `len`, индексы, `in`.
    - **Нужно уметь:** перебирать символы и индексы.
    - **Полезно знать:** индекс нужен для сравнения соседей.
```python
word = "python"
print(word[0], word[-1], len(word))
for char in word:
    print(char)
for i in range(len(word)):
    print(i, word[i])
```
Изменить `word[0]` нельзя: постройте новую строку. Частые ошибки — индекс `len(word)`, обращение к пустой строке и путаница символа с индексом.

## Как устроены индексы

Для строки длины 6 допустимы индексы от `0` до `5` и от `-1` до `-6`. Выражение `word[len(word)]` ошибочно: это позиция сразу после последнего символа. Перед обращением к первому или последнему символу убедитесь, что строка не пустая.

Цикл по символам выбирайте для подсчёта и проверки каждого знака. Цикл по индексам нужен, если важна позиция, соседний символ или фрагмент. Например, безопасная граница для пары `word[i]` и `word[i + 1]` — `range(len(word) - 1)`.

```python
vowels = 0
for char in word.lower():
    if char in "аеёиоуыэюя":
        vowels += 1
```

Здесь `char` — сам символ, а не его номер. Строка после `lower()` новая; исходное значение не изменяется.

## Строим новую строку

```python
result = ""
for char in word:
    if char != " ":
        result += char
```

Так неизменяемость превращается в понятный алгоритм: читаем исходную строку и накапливаем результат. Для школьных строк этого достаточно; для очень больших текстов позже применяют список частей и `join`.
## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Края строки

#### Условие

Введите строку, возможно пустую. Для непустой выведите первый и последний символ через пробел, для пустой — `пусто`.

#### Как рассуждать

Индексы 0 и -1 обращаются к краям, но в пустой строке таких позиций нет. Поэтому сначала проверяем длину, и только затем берём символы. У строки из одного символа оба края совпадают.

#### Алгоритм

1. Прочитайте строку.
2. Если длина равна нулю, сообщите об этом.
3. Иначе выведите символы по индексам 0 и -1.

#### Решение

```python
text = input()
if len(text) == 0:
    print("пусто")
else:
    print(text[0], text[-1])
```

#### Разбор решения

Проверка до индексов предотвращает ошибку. `text[-1]` возвращает символ, а не длину. Пробел тоже символ строки: ввод здесь не обрезаем.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| кот | обычный случай | к т |
| Я | единственный символ | Я Я |
| пустая строка | безопасность индексов | пусто |

**Ответ:** для первого теста — к т.

### Задача 2. Индексы восклицаний

#### Условие

Введите строку. Выведите индексы всех символов `!`, каждый с новой строки. Если их нет, ничего не выводите.

#### Как рассуждать

Нужна позиция, а не только сам символ, поэтому переберём индексы. Каждая позиция проверяется независимо: после первого восклицания поиск не заканчивается. Нумерация начинается с нуля.

#### Алгоритм

1. Переберите индексы от 0 до длины минус 1.
2. Сравните символ на каждом индексе с !.
3. Выведите индекс при совпадении.

#### Решение

```python
text = input()
for i in range(len(text)):
    if text[i] == "!":
        print(i)
```

#### Разбор решения

`range(len(text))` не включает недопустимую позицию len. Для пустой строки диапазон пуст. Здесь не нужен `break`: он оставил бы только первое совпадение.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| !да! | первый и последний символы | 0<br>3 |
| тихо | совпадений нет | нет строк вывода |
| пустая строка | нет позиций | нет строк вывода |

**Ответ:** для первого теста — 0; 3.

### Задача 3. Соседние равные символы

#### Условие

Введите строку. Посчитайте соседние пары одинаковых символов; пары могут пересекаться. Для `ААА` ответ 2.

#### Как рассуждать

Сравниваем символ на позиции i со следующим. Последний возможный i — длина минус 2. Пересечение не мешает: пары на позициях 0–1 и 1–2 считаются отдельно. Это простой шаг к экзаменационной обработке строк.

#### Алгоритм

1. Обнулите счётчик.
2. Переберите начала соседних пар.
3. Сравните два символа и обновите счётчик.
4. Выведите результат.

#### Решение

```python
text = input()
count = 0
for i in range(len(text) - 1):
    if text[i] == text[i + 1]:
        count += 1
print(count)
```

#### Разбор решения

Граница `len(text) - 1` нужна, потому что внутри есть `i + 1`. Для длины 0 или 1 диапазон не даёт повторов и ответ равен нулю. Подсчитываются пары, а не длина серии.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| АААББ | пересекающиеся пары | 3 |
| А | один символ | 0 |
| пустая строка | пар нет | 0 |

**Ответ:** для первого теста — 3.
