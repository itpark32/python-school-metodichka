# Методы строк и срезы

Методы возвращают новую строку: `lower`, `upper`, `strip`, `find`, `count`, `replace`, `split`; `join` собирает строку, `isdigit` и `isalpha` проверяют состав.
!!! abstract "Фокус"
    - **Нужно знать:** `text[start:stop:step]`.
    - **Нужно уметь:** нормализовать ввод и делить текст на слова.
    - **Полезно знать:** срез не включает правую границу.
```python
text = "  Python для школы  ".strip().lower()
words = text.split()
print(" | ".join(words))
word = "algorithm"
print(word[:4], word[4:], word[::2], word[::-1])
```
Палиндром проверяется как `word == word[::-1]`. `find` возвращает `-1`, если фрагмент не найден. Не забывайте присвоить результат метода: строка сама не меняется.

## Сначала задача, потом метод

Методы удобно объединять в конвейер: убрать пробелы по краям, привести регистр, затем разделить на слова. Внутренние пробелы `strip()` не удаляет.

```python
raw = "  Маша, Петя, Оля  "
names = raw.strip().split(",")
for name in names:
    print(name.strip())
```

`split` превращает одну строку в список частей, `join` выполняет обратную операцию. Разделитель у `join` стоит слева: `", ".join(names)`.

## Срез как диапазон индексов

Срез `text[start:stop:step]` следует тем же правилам, что `range`: начало включается, конец нет. Пропущенные границы означают начало или конец строки. В отличие от отдельного индекса, слишком широкая граница среза не вызывает ошибку.

| срез | смысл |
|---|---|
| `text[:3]` | первые три символа |
| `text[3:]` | от индекса 3 до конца |
| `text[::2]` | каждый второй символ |
| `text[::-1]` | строка наоборот |

`find` подходит, когда нужна позиция. Для простой проверки наличия яснее писать `part in text`. Если `find` вернул `-1`, использовать это значение как обычный индекс нельзя.
## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Нормализация названия

#### Условие

Введите название, в котором возможны пробелы по краям и разный регистр. Выведите его без крайних пробелов и строчными буквами. Внутренние пробелы сохраните.

#### Как рассуждать

У задачи два независимых преобразования: strip убирает края, lower меняет регистр. Оба возвращают новые строки, поэтому результат сохраняем. Удалять все пробелы через replace нельзя: внутренние нужны.

#### Алгоритм

1. Прочитайте строку.
2. Уберите крайние пробелы.
3. Приведите к нижнему регистру и выведите.

#### Решение

```python
text = input()
normalized = text.strip().lower()
print(normalized)
```

#### Разбор решения

Цепочка вызывает lower у результата strip. Исходная строка не изменяется. Если введены только пробелы, результат пуст; `print` всё равно завершает строку вывода.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| ␠␠PyThOn клуб␠ | обычный случай | python клуб |
| ШКОЛА | без крайних пробелов | школа |
| только пробелы | пустой результат | нет строк вывода |

**Ответ:** для первого теста — python клуб.

### Задача 2. Аккуратные пробелы

#### Условие

Введите строку со словами, разделёнными любым числом пробелов. Выведите слова с одним пробелом между ними и без крайних пробелов.

#### Как рассуждать

split без аргумента выделит слова и пропустит лишние пробельные разделители. Затем join соединит части ровно одним пробелом. Так не нужно угадывать, сколько раз заменять двойной пробел.

#### Алгоритм

1. Разделите ввод на слова методом split.
2. Соедините их через один пробел.
3. Выведите новую строку.

#### Решение

```python
text = input()
words = text.split()
result = " ".join(words)
print(result)
```

#### Разбор решения

После split получаем список слов, уже знакомый по теории этой статьи. Пустой ввод даст пустой список, а join — пустую строку. Разделитель записывается слева от `.join`.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| ␠один␠␠␠два␠ | обычный случай | один два |
| слово | одна часть | слово |
| пустая строка | слов нет | нет строк вывода |

**Ответ:** для первого теста — один два.

### Задача 3. Палиндром с пробелами

#### Условие

Введите фразу из букв и пробелов, без знаков препинания. Определите, читается ли она одинаково в обе стороны, если убрать пробелы и не учитывать регистр. Выведите True или False. Пустую нормализованную строку считаем палиндромом.

#### Как рассуждать

Сначала приведём данные к одному виду: нижний регистр и удаление пробелов. Затем сравним строку с обратным срезом. Простое сравнение исходной фразы дало бы ложный результат из-за регистра и пробелов.

#### Алгоритм

1. Приведите ввод к нижнему регистру.
2. Удалите пробелы через replace.
3. Сравните со срезом [::-1].

#### Решение

```python
text = input()
normalized = text.lower().replace(" ", "")
print(normalized == normalized[::-1])
```

#### Разбор решения

`replace(" ", "")` убирает именно пробелы по всему тексту, в отличие от strip. Срез с шагом -1 строит обратную строку и безопасен для пустого ввода. Знаки препинания здесь не обрабатываются по условию.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| А роза упала на лапу Азора | обычный случай | True |
| Python | не палиндром | False |
| пустая строка | договорённый пустой случай | True |

**Ответ:** для первого теста — True.
