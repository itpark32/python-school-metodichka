Проход по строке хранит состояние текущего фрагмента: счётчик, построенный результат или длину серии.
!!! abstract "Фокус"
    - **Нужно знать:** текущая и максимальная серии.
    - **Нужно уметь:** сбрасывать состояние при нарушении условия.
```python
text = "AAABBCCCCDAA"
current = maximum = 1
for i in range(1, len(text)):
    if text[i] == text[i - 1]:
        current += 1
    else:
        current = 1
    if current > maximum:
        maximum = current
print(maximum)
```
`current` описывает серию, заканчивающуюся в текущей позиции; `maximum` — лучшую из уже увиденных. Для пустой строки нужен отдельный случай. Похожим проходом считают пары и строят новую строку через накопление.

## Состояние одного прохода

Перед каждой итерацией сформулируйте смысл переменных. `current` хранит длину подходящей серии, которая заканчивается на текущем символе; `maximum` — лучший результат среди просмотренных позиций. При нарушении условия новая серия начинается с длины 1, а не 0.

Для серии символов из разрешённого набора логика немного другая:

```python
current = 0
maximum = 0

for char in text:
    if char in "0123456789":
        current += 1
        maximum = max(maximum, current)
    else:
        current = 0
```

Здесь неподходящий символ не начинает новую серию, поэтому сброс идёт в ноль. Это различие стоит вывести из смысла переменной, а не запоминать.

## Пары и состояние

Для подсчёта пар цикл заканчивается перед последним символом. Для поиска длинного фрагмента иногда удобнее хранить его начало, длину или факт, что уже встретился специальный символ. Не добавляйте все данные сразу: выберите минимальное состояние, достаточное для следующего решения.

Проверьте алгоритм на пустой строке, одном символе, серии в самом начале и серии в самом конце. Последний случай обнаруживает решения, которые обновляют максимум только при разрыве серии.
