Проход по строке хранит состояние текущего фрагмента: счётчик, построенный результат или длину серии.
!!! abstract "Фокус"
    - **Нужно знать:** текущая и максимальная серии.
    - **Нужно уметь:** сбрасывать состояние при нарушении условия.
```python
text = "AAABBCCCCDAA"
current = maximum = 1
for i in range(1, len(text)):
    if text[i] == text[i - 1]:
        current += 1
    else:
        current = 1
    if current > maximum:
        maximum = current
print(maximum)
```
`current` описывает серию, заканчивающуюся в текущей позиции; `maximum` — лучшую из уже увиденных. Для пустой строки нужен отдельный случай. Похожим проходом считают пары и строят новую строку через накопление.

## Состояние одного прохода

Перед каждой итерацией сформулируйте смысл переменных. `current` хранит длину подходящей серии, которая заканчивается на текущем символе; `maximum` — лучший результат среди просмотренных позиций. При нарушении условия новая серия начинается с длины 1, а не 0.

Для серии символов из разрешённого набора логика немного другая:

```python
current = 0
maximum = 0

for char in text:
    if char in "0123456789":
        current += 1
        maximum = max(maximum, current)
    else:
        current = 0
```

Здесь неподходящий символ не начинает новую серию, поэтому сброс идёт в ноль. Это различие стоит вывести из смысла переменной, а не запоминать.

## Пары и состояние

Для подсчёта пар цикл заканчивается перед последним символом. Для поиска длинного фрагмента иногда удобнее хранить его начало, длину или факт, что уже встретился специальный символ. Не добавляйте все данные сразу: выберите минимальное состояние, достаточное для следующего решения.

Проверьте алгоритм на пустой строке, одном символе, серии в самом начале и серии в самом конце. Последний случай обнаруживает решения, которые обновляют максимум только при разрыве серии.
## Разбор задач

Начнём с прямого применения темы, затем объединим знакомые приёмы и разберём более сложную задачу.

### Задача 1. Сколько фрагментов АБА

#### Условие

Введите строку из русских заглавных букв. Посчитайте вхождения фрагмента `АБА`, включая пересекающиеся.

#### Как рассуждать

Для тройки символов нужны начала до len - 3 включительно. Проверим каждое начало срезом длины три. Шаг остаётся равным одному: так фрагменты в `АБАБА` на позициях 0 и 2 оба попадут в ответ.

#### Алгоритм

1. Создайте нулевой счётчик.
2. Переберите все начала троек.
3. Сравните срез с образцом и посчитайте совпадения.

#### Решение

```python
text = input()
count = 0
for i in range(len(text) - 2):
    if text[i:i + 3] == "АБА":
        count += 1
print(count)
```

#### Разбор решения

Обычный `count` строки не учитывает пересекающиеся вхождения, поэтому здесь нужен свой проход. Для длины меньше трёх диапазон пуст. Правая граница среза не включается.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| АБАБА | пересечение | 2 |
| АБА | вся строка — образец | 1 |
| АБ | слишком коротко | 0 |

**Ответ:** для первого теста — 2.

### Задача 2. Самая длинная серия цифр

#### Условие

Введите строку. Найдите максимальное количество подряд идущих десятичных цифр от 0 до 9. Если цифр нет, выведите 0.

#### Как рассуждать

Текущая длина растёт только на цифре; любой другой символ разрывает серию. Лучший результат хранится отдельно. Обновлять его нужно на каждой цифре, чтобы серия в конце тоже была учтена.

#### Алгоритм

1. Обнулите текущую и лучшую длины.
2. На цифре увеличьте текущую длину и обновите лучшую.
3. На другом символе сбросьте текущую в ноль.
4. Выведите лучшую длину.

#### Решение

```python
text = input()
current = 0
maximum = 0
for char in text:
    if char in "0123456789":
        current += 1
        if current > maximum:
            maximum = current
    else:
        current = 0
print(maximum)
```

#### Разбор решения

Сброс равен нулю, поскольку неподходящий символ не входит в серию цифр. `maximum` переживает разрывы. Условие проверяет конкретный набор 0–9, а не все возможные символы Unicode, похожие на цифры.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| a12b345 | лучшая серия в конце | 3 |
| abc | цифр нет | 0 |
| пустая строка | нет символов | 0 |

**Ответ:** для первого теста — 3.

### Задача 3. Фрагмент без равных соседей

#### Условие

Введите строку из букв A, B, C. Найдите длину самого длинного фрагмента, в котором каждые два соседних символа различны. Пустой строке соответствует 0.

#### Как рассуждать

При различии соседей текущий фрагмент продолжается. Если символы совпали, старый фрагмент завершён, но текущий символ начинает новый длины один. Для непустой строки стартовая длина тоже один.

#### Алгоритм

1. Отдельно обработайте пустую строку.
2. Переберите символы со второго.
3. Продлите фрагмент или сбросьте длину в 1.
4. Обновляйте и выведите максимум.

#### Решение

```python
text = input()
if len(text) == 0:
    print(0)
else:
    current = 1
    maximum = 1
    for i in range(1, len(text)):
        if text[i] != text[i - 1]:
            current += 1
        else:
            current = 1
        if current > maximum:
            maximum = current
    print(maximum)
```

#### Разбор решения

При совпадении сброс в 1 сохраняет текущую букву как начало новой цепочки. Для `ABBCAB` длины равны 1, 2, 1, 2, 3, 4. В учебном варианте читаем строку с клавиатуры; файловый ввод появится в модуле о файлах.

#### Проверка

| Данные | Почему проверяем | Результат |
|---|---|---|
| ABBCAB | обычный случай | 4 |
| AAA | все соседи равны | 1 |
| A | один символ | 1 |
| пустая строка | отдельная база | 0 |

**Ответ:** для первого теста — 4.
